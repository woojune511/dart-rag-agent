# 표제·기간 보존 실험의 ‘까지’ 토큰 대조

2026-10-15 · `COMPLETE_REVIEWED_TOKEN_CONTROL` · provider-free

**양쪽 BM25에서 `까지` 토큰을 동일하게 제외해도 C10 본표의 순위 개선이 유지됐다.** 표제·기간을 보존하지 않은 입력은 BM25 3위/RRF8위, 보존한 입력은 BM25 1위/RRF4위다. 두 조건 모두12/12문항의 필수 근거가 충분하며, 근거 회귀0건이다. 새 답변 생성이나 Dense 재임베딩은 실행하지 않았다.

[직전 실험](linked_title_search_ablation.md)의 C10 점수 증가가 우연한 `까지` 일치에 전적으로 의존하는지는 이번 대조에서 배제됐다. 다만 남은 효과에도 어휘 빈도·길이·IDF 변화가 포함되므로, 의미 이해나 일반 성능 향상의 증거로 확대하지 않는다.

## 대조 설계와 실행

두 조건 모두 기존 tokenizer를 먼저 실행한 후 **정확히 `까지`인 토큰만** 문서 색인과 질문에서 제거했다.

```python
tokens = [token for token in original_tokenizer(text) if token != "까지"]
```

원문 문자열을 삭제하거나 다시 토큰화하지 않았다. `자리까지`에서 발생하는 `리까`, `만기까지`의 `기까` 등 다른 bigram은 원래 순서·빈도 그대로다. 원문·metadata·답변 입력의 질문은 수정하지 않았다.

- **A:** 원래 canonical 검색 입력 + `까지` 제외.
- **B:** 직전 실험의 원본 연결 표제·기간 입력 + 동일한 `까지` 제외.

직전 실험의723개 연결·추가 텍스트를 그대로 재사용했다. 새로운 연결 규칙, 추가 stopword, 키워드 접두어 제거를 적용하지 않았다. 2,240청크·12질문·접수번호 필터·Dense16·BM2524·`k1=1.5,b=0.75,epsilon=0.25`·RRF60/동일 가중치/top8·원래 출처 텍스트·65,536-byte packet 제한을 고정했다. 기본 앱과 store는 변경하지 않았다.

토큰을 문서에서도 제거하므로 문서 길이·평균 길이와 평균 IDF의 epsilon 보정값은 자연스럽게 재계산된다. 별도 조건을 조정하지 않았으며 이 변화를 기록했다.

| 확인 항목 | A 원래 입력 | B 표제·기간 보존 |
| --- | ---: | ---: |
| `까지`가 제거된 문서 | 61개 | 73개 |
| 제거한 문서 토큰 수 | 123개 | 159개 |
| 제거한 질문 토큰 수 | 3개 | 3개 |
| 제거 후 평균 문서 토큰 길이 | 323.966518 | 326.657143 |

질문에서는 N03·C09·C10에서 각각1개가 제거됐다. 두 조건의 적용 횟수가 다른 것은 보존된 원본 기간 문맥에 `까지`가 더 있기 때문이며, 필터 규칙은 같다.

## C10: 점수 차이는 감소하고 순위 개선은 유지

| 조건 | 표제·기간 없음 | 표제·기간 보존 |
| --- | --- | --- |
| 직전 비교: `까지` 포함 | BM25 **3위**, RRF **8위** | BM25 **1위**, RRF **4위** |
| 이번 대조: `까지` 제외 | BM25 **3위**, RRF **8위** | BM25 **1위**, RRF **4위** |
| 이번 BM25 점수 | 65.060739 | 68.409189 |

필요한 연결 현금흐름표 `104:5`의 BM25 점수 차이는 직전 **+6.927312**에서 이번 **+3.348450**으로 줄었다. `까지`의 점수 기여는0이다. 남은 관측 점수를 수식으로 재구성하면 `름표`의 증가분 약+2.493, `원` +0.962, `2025` +0.836, `단위` +0.746 등이 있으며, 다른 토큰은 길이·IDF 변화로 감소하기도 한다. 이 값들은 두 관측 조건의 점수 분해이며 각 요소를 따로 변경한 실험은 아니다.

원문35,544,145,039원·617,510,076,654원과 기존 단위·범위는 동일한 `104:5`에서 확인된다. C10의 최종 출처 목록과 실제 packet은 각 조건의 직전 결과와 동일하다. 개선 후에도 다음 한계는 남는다.

- 값 없는 표제 `400:295`, `748:261`이 두 검색 채널에 모두 등장해 최종1·2위다. 주당이익 표제 `395:290`도3위다.
- 별도 현금흐름표 `486:4`도 BM254→2위/RRF10→6위로 올라온다. 그 값은 연결 기준 질문의 대체 정답으로 인정하지 않았다.
- 표제가 연결된 조정 상세표는 여전히 BM2524 후보 밖이다. Dense는 고정돼 있으므로 그 표현 변경 효과를 측정한 결과가 아니다.

N03의 필요 출처 `998:2`는 표제·기간 보존 없이도 토큰 제외만으로 BM255→4위/RRF10→8위에 들어온다. 기존 상위 후보 `701:165`는 교환사채 조건 표이며 `만기까지`가 있다. 토큰 제외 후 BM253→5위/RRF6→10위로 내려간다. 요청한 매출·영업이익 근거가 아닌 이 표의 이탈은 근거 회귀로 세지 않았다.

따라서 직전의 N03 회복을 표제·기간 보존만의 고유한 효과로 주장할 수 없다. 이번 대조에서 보존의 추가 효과는 필요 출처의 **RRF8→6위** 상승이며, 필수 근거 충분성의 추가 증가는 없다. 원문 값·연결 제목·기간·백만원 단위는 두 조건 모두 남는다.

## 검증과 종료

- 실행 전 프로토콜·정확 토큰 필터·코드·테스트·의존성을 고정했다. freeze SHA256: `c62dce50906f588d26a91828e37998cca78192fc0d382bf13bde5521931f7023`.
- 직전 두 조건의 Dense/BM25 후보·점수·전체 순위·RRF·실제 packet을 **24/24 재현**한 뒤 토큰 제외2조건을 실행했다. 이전 결과는 덮어쓰지 않았다.
- 두 조건의 실제 tokenizer 호출4,528건을 입력·출력 해시로 확인했다. 문서4,480개 및 질문24개의 token proof가 다른 토큰의 순서·빈도 보존을 검사한다. 질문은 검색 점수와 전체 순위 대조에서 각각 토큰화된다.
- 독립 BM25 계산으로 두 조건의 범위 내 점수·순위 **26,880건**이 일치했다. RRF와 원래 출처로 복원된 실제 packet도 대조했다. 제외 토큰은 양쪽 vocabulary/질문에서 없고 점수 기여0이다.
- 네트워크 차단 상태의 토큰 계약 테스트5개, 문서 계약2개, `git diff --check`가 통과했다. 기존 보호 파일764개를 검증했고 현재 상태 문서2개의 이전 bytes를 보존했다.
- provider 호출·새 임베딩·답변 생성0, 추가 비용0. 기존 C09 계산 절차 불확실성과 C11 추가 해석 오류를 재채점하지 않았다.
