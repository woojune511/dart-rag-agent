## 평가 방법과 비교의 한계

P=충족, F=확인된 오류·누락·인용 지지 실패, U=판정 유보다. 정확도는 실제 답변한 수치·기간·대상·관계를, 필수항목 완전성은 기존33개 그룹을, 출처 충실도·인용 지지는 실제 전달·인용한 근거와 주장을 대조한다. 정확한 부분 답변도 완전성F일 수 있다. 모든 적용 축과 필수 그룹이P이고 중대한 추가 문제가 없어야 엄격P다. 출처 ID·schema 통과를 의미·산술 정확도로 세지 않는다.

## 확인된 사실과 남은 해석

- **확인:** 새 store가 v9 metadata·원문·벡터를 보존했고, 최종 문맥의 기존 충분 근거26개는 모두 유지됐다. U15의 추가 근거와 실제 원인 설명은 복구됐다.
- **확인:** U04의 현재 실패는 후보에 있는 핵심 근거가 최종8개에서 빠지는 문제다. U08·U09·U16의 필수 근거 부족도 지속된다. 수치 표시·비지원 관계·부재 범위 문제는 생성 결과에서 별도로 관측됐다.
- **한계:** 전체 엄격 통과와 반복 안정성 향상은 없다. 개발 노출18문항·회사3개·각2회·assistant 검토로 일반 정확도나 통계적 우열을 주장하지 않는다. 같은 packet에서도 답변이 달라져 파서 인과 효과와 생성 변동을 분리할 수 없다.
- **결정:** 원문 보존 수정의 필요성과 전체 답변 개선 증거를 구분한다. RRF·기본8개·prompt·모델·활성 store를 변경하지 않았다. 후속 호출이나 자동 채택은 수행하지 않는다.
