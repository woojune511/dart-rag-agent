# Located period declarations in saved real sources

Provider-free inspection on baseline `dd540241` found a source-linkage gap in five
saved NAVER disclosure questions. All eight selected numeric cells have fiscal
column headers; their exact dates live in an attached declaration block. An
explicit point-date request could not use that geometry. Reading the fiscal label
alone also hid whether the cell represented a point or a shorter interval.

## Source contract

The existing measurement-period owner now connects a complete reviewed column
period label to the start of its own declaration line. Only label whitespace may
differ. The original header, exact unique quote, quote/label/period spans, document
hash, table locator and cell identity are retained in operand provenance.
Existing attachment validation checks the same document and physical table
relationship. Other columns, foreign tables, ancestor headings, ambiguous quotes
and independently split endpoints cannot supply dates.

Literal dates from that declaration join the existing independent source-axis
checks. Disagreement remains unknown. A point or partial interval cannot satisfy
whole-year coverage. An explicitly linked interval supports the existing annual
label only when its inclusive end is one day before the start's next calendar-year
anniversary, and the existing projected target year agrees. This also handles
non-January starts without inventing a fiscal calendar. Unlabelled calendar
intervals alone still do not establish fiscal-year equivalence.

The suffix grammar lives in reviewed `MEASUREMENT_PERIOD_POLICY`; runtime code
adds no company, metric or question rules. Source candidates, original period
strings, IDs, year projection, exposure limits and V2 wire fields remain unchanged.
V2 already binds the raw attached context and rejects post-compilation mutation.
Only additive `source_period_context_evidence` is projected into operands.

This is a bounded twelve-calendar-month check, not a general fiscal-calendar
resolver. Short fiscal years, 52/53-week calendars, unsupported declaration shapes
and conflicting dates remain unresolved. Fiscal labels without attached geometry
retain the preceding coarse annual compatibility; that is not proof of actual
coverage. Planner still interprets the owned request, and valid source linkage
does not certify that interpretation.
