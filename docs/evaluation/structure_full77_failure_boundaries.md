# Full77 실패 원인 후보 분석

2026-09-28. 기존 답변과 평가를 유지한 오프라인 분석이다. **가장 많이 관측된 실패 위치는 후보 검색 이후의 top-8 선택이었다.** 다만 빠진 근거를 되살렸을 때 실제 답변까지 개선되는지는 아직 평가하지 않았다.

## 대상과 판정 방법

[원래 비교](structure_full77_result.md)의 답변형 55문항 × A/B/C = 165개 응답 중 실패한 **77개 응답**을 분석했다. 서로 다른 실패 문항 77개가 아니다. A는 일반 텍스트, B는 문서 구조, C는 문서+표 구조다. 거절형 57개 응답과 사전 분리한 진단용 9개 응답은 이번 원인 분류에서 제외했다. 거절형 실패 5개도 이 표에 포함하지 않는다.

원문·동결 corpus → dense16/BM25 24 후보 → RRF top8 → 실제 요청 packet → 답변/인용을 대조했다. 기존의 제공 근거 충분성 판정과 답변 판정은 변경하지 않았다. 후보에서 근거를 찾을 때 숫자 일치뿐 아니라 당기/전기, 연결/별도, 대상 회사, 필요한 설명의 의미를 확인했다. 문자열 검색은 위치를 찾는 도구이며 자동 의미 채점이 아니다.

한 응답에 여러 누락이 있으면 **확인된 필수 요소 중 가장 앞 단계의 누락**을 대표 분류로 사용했다. 따라서 상호 배타적인 원인 증명이나 전체 후보의 의미적 완전성 인증이 아니다. 후보 누락 분류는 검토한 필수 근거/요소를 기준으로 하며, 가능한 모든 대체 근거의 부재를 증명하지 않는다.

| --- | ---: | ---: | ---: | ---: |
| ① 필수 근거가 검색 후보에 없음 | 4 | 6 | 6 | **16 (20.8%)** |
| ② 후보에는 있지만 최종 선택에서 누락 | 9 | 15 | 15 | **39 (50.6%)** |
| ③ 근거는 전달됐지만 답변/인용 실패 | 3 | 12 | 2 | **17 (22.1%)** |

동일 질문의 조건별 응답들이므로 77개의 독립 표본으로 통계적 일반화를 하지 않는다. 표현 조건에 따라 청크 경계·길이·prefix·추출 보존이 함께 달라져, 이 분포를 표 구조 하나의 인과 효과로 해석하지 않는다.

### ① 후보 이전의 누락: 16개

**14개는 corpus에 검토한 필수 근거가 있지만 dense/BM25 후보에 들어오지 않은 경우다.** 예를 들어 카카오의 SM 편입과 뮤직 성장의 인과 설명은 A/B/C corpus에 모두 있지만 세 후보 목록에서 빠졌다. 삼성웰스토리의 과징금·소송 설명 역시 세 조건의 후보에서 빠졌다. B 후보에 삼성웰스토리 이름은 등장하지만 사업 소개여서 소송 근거를 대체하지 못했다.

**나머지 2개는 후보 검색보다 앞선 corpus 보존 문제다.** 현대차 배출권 회계 질문에서 원본 HTML과 A에는 무상 배출권, 무형자산 분류, 배출부채 인식 설명이 남아 있지만 B/C corpus에는 해당 회계 문단이 없다. B/C가 검색한 일반 배출권 제도 설명은 회계처리 답변에 충분하지 않았다. 전체 B/C corpus에서 관련 문구를 확인하고 원본 HTML의 해당 문단을 대조했다. 공통 추출/표현 경로의 손실은 확인했지만 어느 parser 코드가 원인인지는 이번에 진단하지 않았다.

따라서 14개는 후보 recall, 2개는 원문 보존을 별도로 다뤄야 한다. 후자의 경우 기존 후보에 reranker만 적용해서는 사라진 원문을 복원할 수 없다.

### ② 후보 이후의 선택 누락: 39개

39개 모두 검토한 유용한 필수 근거가 **RRF 8위 밖**에 남았다. 대표 근거를 하나씩 고정해 보면 BM25-only 34개, dense-only 5개이며, 두 검색에 동시에 잡힌 근거는 없었다. 이것은 39개 전체 후보의 구성 통계가 아니라 39개 누락 근거의 통계다.

| 사례 | 조건 | 필요한 근거 | 후보 순위 → RRF 순위 |
| --- | --- | --- | --- |
| SK하이닉스 외화환산 순손익 | A | 외화환산이익 573,884 | BM25 2 → **14** |
| 삼성전자 배당금 현금유출 | C | 연결 현금흐름의 9,864,474 | BM25 6 → **10** |
| 삼성전자 재고자산평가손실 | C | 당기 5,037,579 | BM25 5 → **13** |
| 카카오뱅크 수수료 수익 | C | 연계대출 17,003 / 연계계좌 15,520 | BM25 1 → **10** |

현재 RRF는 각 검색 순위의 `1/(60+rank)`를 더한다. 이 후보 깊이에서는 두 검색에 모두 잡힌 문서는 어느 한 검색에만 잡힌 문서보다 높은 점수를 받는다. 이 순위 산식과 저장된 231개 top8을 재현했다. 요청의 한 부분에 꼭 필요한 근거가 단일 검색에서만 잡히면, 다른 부분과 관련성이 높은 중복 후보들 뒤로 밀릴 수 있다는 설명과 관측이 일치한다. 이를 RRF 구현 오류나 상수 변경의 효과가 입증됐다는 뜻으로 사용하지 않는다.

①에 배정된 응답 중 4개에서도 별도의 선택 누락이 함께 확인됐다. 카카오 A의 성장률, 삼성 소송 A/B의 바이오로직스 설명, 셀트리온 C의 영업권이다. 이 중복은 39개에 더하지 않았다.

**39개가 전부 개선 가능한 답변이라는 의미는 아니다.** 이 분석은 누락된 유용한 근거의 위치를 확인했으며, 같은 후보 집합에 모든 요청 근거가 충분한지와 이를 전달하면 답변이 맞는지는 별도의 검증 대상이다.

최종 packet의 크기 제한도 확인했다. `MIX_T3_063` C에서 선택된 8개 중 3개가 전달되지 않았지만, 핵심 당기 장부가 근거는 이미 RRF 23위였다. 그 응답의 필수 근거 손실을 byte 제한만의 탓으로 돌리지 않았다.

### ③ 전달 이후의 답변 실패: 17개

기존 제공 근거 충분성 판정이 FULL인 실패는 A3/B12/C2다. 필요한 자료가 이미 입력에 있어 검색 개선만으로 해결된다고 보기 어렵다.

- **인용과 단위 연결 6개:** 모두 B. 올바른 단위 근거가 제공 목록에 있지만 답변의 실제 인용 source는 주장한 화폐 단위를 지지하지 않았다. source ID가 유효하다는 것과 그 source가 단위를 뒷받침한다는 것은 다르다.
- **해석·계산·요청 누락 11개:** 그룹 WM AUM을 세 조건 모두 누락, 회사 성장률 대신 시장 전체 성장률 사용, 감소액을 잔액으로 읽기, 내부거래 조정 전후 범위 혼동, 잘못된 산술/반올림, 원문에 없는 반올림 원인 설명 등이 있었다.

구체적으로 `CEL_T1_013` B는 표시 정밀도에서 52.99가 맞지만 53.00으로 답했다. `MIX_T1_064` B는 피연산자가 맞아도 약90.7005%를 90.64/90.6%로 답했다. `KBF_T2_043`은 세 조건 모두 그룹 WM 전체 AUM 근거를 전달받았지만 답에서 빠뜨렸다. 이들은 같은 종류의 오류가 아니므로 하나의 프롬프트 규칙으로 묶어 해결됐다고 주장할 수 없다.

기본 SimpleRagAgent는 산술 실행, 의미 지지, 요청 누락을 코드로 검증하지 않는다. 이 결과를 근거로 기존 Compiler 검증이 기본 경로에서 작동한다고 설명하거나 자동으로 연결하지 않는다.

### 확정 유보: 5개

- B의 `NAV_T3_007`, `NAV_T1_071`, `MIX_T3_050`, `HYU_T3_036`: 숫자는 맞거나 존재하지만 해당 값과 화폐 단위의 근거 연결이 불명확하다. 다른 표의 단위를 가져와 해당 표의 단위라고 단정하지 않았다.
- A의 `MIX_T3_063`: 평문화된 빈 셀과 행/열 연결 때문에 대상과 장부가의 대응 충분성을 확정하지 않았다.

이들은 표현 손실, 선택 누락, 답변 오류 중 하나로 억지로 배정하지 않았다. 특히 `HYU_T3_036`의 연결 당기 값 2,175,691은 맞으며, 기존 reference의 별도 값 1,569,085와 혼동해 수치 오류로 재분류하지 않았다.

## 개선 우선순위

첫 검증 대상으로는 **후보와 답변 모델을 고정한 채 최종 근거 선택만 비교**하는 것이 타당하다. 39개에서 선택 누락을 직접 관측했기 때문이다. 비용·문서 수·byte 예산을 맞추고 필수 근거 보존, 범위 혼동, 최종 답변 정확/완전/인용 지지를 함께 봐야 한다. 실패 사례만 맞추지 않도록 기존 성공 사례의 회귀도 포함하고, 개발 사례와 별도의 평가 표본을 분리한다.

[기존 별도 선택 비교](evidence_selection_comparison_result.md)는 작성된 6질문 × 3입력에서 일반 의미 선택과 집합 선택 변형이 동일한 문서 집합을 선택했다. 그것은 이 full77 실제 후보에 대한 개선 결과도, 새 독자 reranker의 필요성 증거도 아니다. 기존 방식으로 검증할 수 있는지를 먼저 보며 새 routing/도메인별 규칙을 추가하지 않는다.

원문 회계 문단이 사라진 2개는 별도의 추출 보존 회귀로, 충분한 입력의 17개는 인용 단위·완전성·산술/범위별로 나눠 다룬다. 이번 작업에서 runtime, prompt, parser, 검색 정책, 평가 기준을 바꾸거나 답변을 새로 생성하지 않았다.

## 검증과 산출물

- 저장된 231개 검색 순위의 RRF top8을 기존 순수 병합 함수로 재현했다.
- 실제 생성 요청 231개의 source ID 순서와 본문을 결과 trace 및 동결 corpus와 대조했다.
- 동결 corpus 33개, 사용한 원본 HTML, 읽은 검색/결과/요청 및 기존 최종 리뷰 봉인 파일의 SHA-256을 확인했다.
- 새 provider/embedding 호출 0, 추가 API 비용 0. 무호출 분석이며 새 정답률 평가가 아니다.
- 원래 231개 답변·판정·봉인 보고서는 그대로 유지했다. **검토 메모 오기:** `MIX_T3_048`의 연결 배당금 현금유출은 9,864,474백만원이며, 기존 메모의 9,864,506은 전사 오류다. reference의 반올림된 9조8,645억원 및 A/B/C 실패 판정은 바뀌지 않는다. 원문 메모를 덮어쓰지 않고 여기에서 정정한다.

로컬 제외 산출물은 `benchmarks/results/structure_full77_preparation_2026-09-28/` 아래의 `full77_failure_boundaries.json`, `audit_full77_boundaries.py`, `failure_boundary_tools.py`다. JSON에는 검토 근거의 전체 source text, SHA-256, dense/BM25/RRF 순위, 의미 역할과 보류 이유를 남겼다. 아래 목록의 corpus 누락 근거는 비교용 A source이므로 B/C의 후보 순위로 읽지 않는다.
