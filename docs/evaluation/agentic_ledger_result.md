# 근거 기록 보존 실험: 첫 호출 후 중단

2026-09-28. [실행 전 설계](agentic_ledger_preparation.md). **생성1회 후 원문 인용 검증에서 중단, 나머지5문항 NOT_RUN.** 추정 비용USD0.1261835,13.62초. 검색어 임베딩·추가 검색·답변 생성은0회다. 품질 비교를 완료하거나 성능 개선을 확인한 결과가 아니다.

## 구현과 실행 경계

실험용 컨트롤러에 요구사항별 stable ID, covered/partial/missing, 근거와 주의사항, 변경 이유, 종료 이유를 추가했다. 코드는 이전 요구사항의 무단 삭제/변경, 출처 밖 인용, 설명 없는 근거 수정과 ledger 상태에 모순되는 충분성 선언을 거절한다. 기록은 다음 결정과 답변 입력에 전달하도록 구현했다. LLM이 정한 요구사항 자체의 완전성이나 인용 의미는 검증하지 않는다.

실행 전 최대 경로42회 SDK 모의 호출,15개 중단 control,6개 추가 상태 전이/답변 출처 검증을 통과했다. mock은 작성한 출력이 계약을 지킨다는 확인이지 실제 모델의 인용 복사 능력을 입증한 것은 아니다.

## 실제 중단 원인

첫 카카오 출력은 매출 영향과 무형자산 영향이라는2개 요구사항을 만들고, 모두 partial로 표시했다. 전체 무형자산 감소라는 주의사항도 기록하며 추가 검색을 요청했다. 하지만 `1159:3` 근거를 복사하면서 원문의 `카카 오게임즈`를 `카카오게임즈`로 붙였다. 이 인용은 연속 원문 구간이 아니므로 검증이 거절했다.7개 근거/주의사항 참조 중1개가 불일치했다.

이는 provider HTTP 오류나 schema 거절이 아니다. provider 응답은 completed였고 사용량은 입력45,395/output1,058 tokens였다. **모델의 인용 문자열 재작성과 코드의 정확 원문 계약이 충돌한 것**이다. 글자 수정을 허용하는 정규화나 재시도로 통과시키지 않았다. 원시 출력과 기존 실행 코드는 그대로 보존한다.

모델이 감소 주의사항을 한 번 기록한 것은 관측됐지만, 다음 검색 뒤에도 보존되는지와 최종 답변에 반영되는지는 **NOT_RUN**이다. 삼성·셀트리온·탄소배출권·두 성공 대조 사례도 실행되지 않았다. 이전 Agentic 결과와 정답률·비용 배수 비교를 하지 않는다.

## 후속 로컬 보완

모델이 원문을 복사하는 대신 **출처와 원문 조각의 시작·끝 위치를 선택**하고, 코드가 그 범위의 원문을 그대로 연결하는 별도 후속 구현을 준비한다. 조각은 의미와 무관하게 고정 길이로 나누며 공백/개행을 보존한다. 모델의 짧은 설명은 여전히 검증되지 않은 해석으로 표시한다.

이는 실패 출력을 정규화해 채택하거나 과거 인용을 자동 변환하는 작업이 아니다. 새 위치 선택 schema를 사용하는 새 실행만 이 방식으로 처리할 수 있다. 현재 배치는 consumed이며 자동 재호출·resume하지 않는다. 위치 선택 구현의 무호출 검증은 별도 문서에 기록하며, 새 provider 품질 증거와 구분한다.

Production SimpleRagAgent, 기존 source/store/vector/dataset와 과거 실험 결과는 그대로다. 로컬 제외 산출물은 `benchmarks/results/agentic_ledger_2026-09-28/`의 동결 runner/contract, manifest/checks, 첫 호출 원시 결과, 중단 receipt와 seal이다.
