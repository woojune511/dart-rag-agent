# 동일 근거의 열·헤더 연결 명시 실험

2026-09-29. 사용자가 승인한 첫 실험의 준비·64회 이내 실행·분석 범위다.
기본 앱과 공개 API, 검색·모델·답변 프롬프트는 변경하지 않는다.

## 질문과 비교

기존 LG에너지솔루션·POSCO홀딩스·SK이노베이션·카카오뱅크 2023 보고서에서
새 긍정 문항 12개를 원문 기반으로 작성했다. 보고서별 기간·대상/범위·단위/지표
각 1개이며, 계산 문항은 6개다. 각 회사의 긍정 문항 하나에서 필요한 원문 청크
전체를 제거한 부족 통제 4개를 추가했다. 16개 입력은 독립 질문 16개가 아니다.

A는 현재 원문과 메타데이터, B는 A에 열 위치별 다단 헤더 경로를 추가한다.
추가 정보는 질문과 무관하게 저장된 헤더에서 기계적으로 생성한다. 숫자·기간·
단위·주석·기존 메타데이터·출처·순서를 그대로 보존하고 정답 열을 표시하지 않는다.
중복/빈 헤더도 보존하며, 연도 환산·빈 셀 보완·표 잘라내기를 하지 않는다.
추가 좌표는 펼쳐진 청크 내 위치이지 원본 XML의 물리적 셀 ID가 아니다.

원문과 인접 혼동 자료를 포함한 고정 context에서 읽기를 진단한다. 검색 호출은
없으며 실제 RAG 정확도나 새 회사/보고서 일반화 평가가 아니다. 동일 원문에
정보를 추가하는 효과이므로 입력 토큰 수가 같은 순수 포맷 비교도 아니다.

## 원문 및 준비 검증

- 선택한 13개 청크의 헤더와 본문 배열을 기존 XML 표와 대조했다. 표의 다른
  위치에 동일 배열이 있을 수 있으므로 이 대조를 유일한 물리적 주소 증명으로
  표현하지 않는다. 대상 헤더의 의미는 원문 검토도 수행했다.
- 메타데이터가 데이터 행을 헤더로 담기도 한다. 구조적으로 위치를 찾았다는
  사실만으로 의미상 헤더임을 보증하지 않으며 전체 코퍼스 적격 목록에 구분한다.
- POSCO `60:0`은 본문의 누락된 끝 셀 때문에 직사각형 대응을 확정하지 못해
  사용하지 않았다. 카카오뱅크 `28:3`도 헤더가 청크 본문에 없어 제외했다.
- 첫 준비 시도는 카카오뱅크의 헤더 미포함 청크를 거절했다. 두 번째는 과거 질문
  파일의 상이한 JSON 형식에서 중단됐다. 두 코드 스냅샷을 보존했으며 유료 호출은
  없었다. 질문/프롬프트를 결과에 맞춰 변경한 과정이 아니다.
- full77과 최근 새 12문항에 대해 정확 문자열 및 같은 회사·요구 지표 재진술을
  검토했다. 전 역사에 대한 완전 중복 검사나 학습 미노출·독립 골드 주장은 없다.
- 변환·원문 보존·모호성 거절·통제 제거·프롬프트 고정 등 계약 검사 8개 통과.
  네트워크 차단 아래 64요청 리허설 2회가 요청 바이트 단위로 일치했다.
  비용 초과, 요청 변조, HTTP503, 사용량 누락/초과, 잘못된 인용, 미완료 응답,
  65번째 호출의 8개 오류 통제가 예상 지점에서 중단됐다. 품질 검증은 아니다.

## 고정 실행과 비용

`gpt-5.6-terra`, low reasoning, max output 8,192, store=false, default tier.
16입력 × A/B × 2회 = 64회이며 A/B 순서를 교차한다. 생성 간 상태를 공유하지
않는다. 기존 답변 프롬프트와 `RagAnswer`를 그대로 사용한다.

사용자 승인 상한 USD20, 전체 보수적 예약 USD8.525901. 공식 가격표를 2026-09-29
확인했다. short-context standard 입력 USD2, cache write USD2.5, 출력 USD12
per million이다. 기존 비용 추적과 보수적인 예약을 위해 입력에 최대 USD2.5를
적용하고 캐시 할인을 무시한다. 실청구 금액은 아니다.
[OpenAI 공식 요금표](https://developers.openai.com/api/docs/pricing).

실제 최대 packet은 15,842바이트이며 65,536바이트 한도를 모두 충족한다.
임베딩·수집·모델 탐색용 호출은 없다. 고정된 64개 요청 hash만 허용한다.
첫 provider/사용량/계약/출처/비용/hash 실패 시 나머지는 NOT_RUN으로 남긴다.
재시도·자동 재개·숨은 보정·문항 교체·후속 실험은 없다. heartbeat는 20초마다
남긴다. 소비 표식은 최초 live dispatch 전 생성하고 동일 권한을 재사용하지 않는다.

## 평가와 종료 기준

긍정은 명시 요구 충족·정확성·모든 실질적 주장에 대한 인용 지지·비거절을
함께 판정한다. 부족 통제는 누락 근거를 명시한 거절과 요청값의 비조작을 본다.
기간/대상/단위, 피연산자/연산/산술, 완전성/지원 여부를 나눠 검토하며 출력에서
보이지 않는 선택은 추정하지 않는다. 조건명을 가리고 순서를 섞은 답변을 같은
assistant가 원문과 검토한다. 독립 평가자 또는 완전한 맹검이라고 주장하지 않는다.

답변 가능성을 positive로 삼고 `abstained=false`를 예측 positive로 정의한
confusion matrix와, A/B 정오 대응표를 구분한다. 반복을 독립 표본으로 세지 않는다.
B가 2/2 통과하고 A는 2/2 미만인 긍정 문항 최소 2개, 반대의 안정적 회귀 0개,
통제의 부당한 수치 답변 증가 없음이 후속 검토 기준이다. 통계적 우월성 기준은
아니다. 차이 없음/천장 효과면 판별 불가로 종료하며 같은 질문에 맞춰 재튜닝하지 않는다.

로컬 산출물은 `benchmarks/results/header_link_pilot_2026-09-29/`에 분리한다.
manifest는 기존 원문·코드·이전 실험 등 1,189개 파일을 보호한다. 실험 산출물은
기본 ignore를 유지하며 커밋·푸시·제품 적용은 이번 범위에 없다.
