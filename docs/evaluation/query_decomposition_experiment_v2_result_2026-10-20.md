# 질문 분해 재실험 결과와 근거 선택 병목

2026-10-20의 수정 후 재실행은 **12문항 검색 비교를 오류 없이 완료했지만, 질문 분해의 사전 진행 기준을 충족하지 못했다.** 목표 6문항의 필수 근거 전체를 실제 입력에 전달한 수는 기본 top-8이 0개, 같은 후보에서 top-12가 5개, 질문 분해 후 top-12가 4개, 원래 질문으로 깊게 검색한 top-12가 3개였다.

질문 분해는 깊은 검색 대비 한 회사의 한 문항만 개선했다. 요구한 순증 2문항·2개 회사에 못 미쳐 `NO_EVIDENCE_GAIN`으로 종료했다. 이 상태명은 이번 실험의 진행 기준 미달을 뜻한다. 기본 top-8 대비 관측된 근거 개선까지 없었다는 뜻은 아니다. **답변 생성은 0회이며 답변 정확도 상승은 검증하지 않았다.**

## 비교 조건과 실행

[사전 설계](query_decomposition_experiment_design_2026-10-20.md)의 질문, 평가 기준, 모델, prompt, 후보 수, RRF와 65,536-byte 입력 한도를 유지했다. [첫 실행 중단](query_decomposition_experiment_result_2026-10-20.md)의 원인이었던 source 표현 검증만 승인된 수정안으로 교체했다. 동일 청크의 Dense 원문과 기존 BM25의 trim된 표현을 각각 고정된 그래프와 대조하며, 실제 선택 본문은 다시 쓰지 않는다. 제품 코드는 변경하지 않았다.

| 조건 | 검색 방식 | 최종 선택 한도 |
|---|---|---:|

| C | 원래 질문과 최대2개 하위 질문, 각 Dense16·BM25 최대24, 동일 가중 RRF | 12 |
| D | 원래 질문, Dense48·BM25 최대72 | 12 |

기존 평가에서 선정한 7개 회사·7개 보고서의 12문항이다. 목표 실패 6개, 근거 충분 실패 통제 1개, 성공 통제 3개, 거절 통제 2개로 구성했다. 개발 과정에 노출된 진단 패널이며 일반 사용 분포나 독립 holdout이 아니다. 이전 중단 실행의 일부 출력을 새 점수에 섞지 않고 모든 질문을 새로 분해·검색했다.

## 근거 충족 결과

아래의 충족은 **질문에 필요한 근거와 주체·기간·단위·범위가 실제 전달 입력에 모두 있다는 판정**이다. LLM이 정답을 생성했다는 점수가 아니다.

| 목표 문항 | A | B | C | D |
|---|---|---|---|---|
| NAVER 영업권 총액과 손상 | 미충족 | 충족 | 미충족 | 미충족 |
| 삼성전자 현금 배당과 환원 정책 | 미충족 | 충족 | 충족 | 충족 |
| 현대차 미국 판매 성장과 보호무역 대응 | 미충족 | 충족 | 충족 | 충족 |
| SK하이닉스 자산 대비 차입금 | 미충족 | 미충족 | 미충족 | 미충족 |
| 셀트리온 재고 평가손실·환입·폐기손실 | 미충족 | 충족 | 충족 | 미충족 |
| 현대차 영업비용과 매출 비율 | 미충족 | 충족 | 충족 | 충족 |
| **필수 근거 전체 충족** | **0/6** | **5/6** | **4/6** | **3/6** |

후보에 근거가 있는지와 실제 입력까지 도달했는지도 분리했다.

| 분모와 위치 | A | B | C | D |
|---|---:|---:|---:|---:|
| 목표6문항 후보 합집합 | 5/6 | 5/6 | 5/6 | 6/6 |
| 목표6문항 최종 선택 | 0/6 | 5/6 | 4/6 | 3/6 |
| 목표6문항 실제 입력 | 0/6 | 5/6 | 4/6 | 3/6 |
| 답변 가능10문항 실제 입력 | 4/10 | 9/10 | 8/10 | 5/10 |
| 성공 통제3문항 실제 입력 | 3/3 | 3/3 | 3/3 | 2/3 |

C−A의 목표 문항 순증은 +4로 삼성전자·현대차·셀트리온에 걸쳤다. C−D는 셀트리온 +1이며, C−B는 NAVER −1이었다. C는 성공 통제3문항에서 A가 전달한 필수 근거를 잃지 않았다. scope·source·설정·예산 위반은 없었다. 거절2문항은 검색 입력만 확보했으며 거절 응답 품질은 평가하지 않았다.

판정에는 원래 숫자나 source ID의 일치만 사용하지 않았다. 예를 들어 KB금융의 수수료·WM 문항에서 단순 문자열 탐색은 일부 근거를 놓쳤다. 실제 입력의 그룹 손익표는 반올림된 순수수료손익3,674/3,515를 제공하고, AUM 표는 십억원 단위1,216,729와 증가70,039·전년1,146,691을 제공한다. 원래 기준이 허용한 표시 정밀도와 대체 표로 A/B/C의 근거 충족을 인정했다. 특정 자회사 실적만 있는 경우는 그룹 성과로 대체하지 않았다.

검토자는 실행을 수행한 assistant이며 조건을 볼 수 있었다. 독립된 사람의 blind 평가가 아니다. 원래 근거 기준과 허용 정밀도를 유지하고 원문·축·단위·범위를 대조했다.

## 원인 분석

**NAVER에서는 검색 성공이 최종 근거 전달로 이어지지 않았다.** 현재 연결 영업권 총액과 손상액을 함께 담은 `20240318000844:353:229`는 원래 질문의 Dense6위였다. A/B에서 RRF11위라 A는 제외하고 B는 전달했다. C에서는 영업권 하위 질문의 Dense1위로도 검색됐지만, 다중 질문·채널의 점수를 합친 최종 순위가15위가 되어 전달되지 않았다. D에서는24위였다. C가 전달한 전기 표나 별도재무제표는 요청한 당기 연결 값을 대체하지 못한다.

**셀트리온의 C 개선은 B에서도 얻을 수 있었다.** 세 재고 손익을 각각 담은 `20240318000913:517:357`은 A/B에서 RRF11위였다. C에서도11위여서 B와 C 모두 전달했다. D에서는21위로 밀렸다. 다른 상위 청크에 있는 순환입 합계만으로 세 개의 개별 금액을 복원할 수는 없다.

**SK하이닉스는 후보와 선택 두 단계에 걸친 실패였다.** A/B/C에는 현재 연결 유형·무형자산 분모의 완전한 근거가 없었다. D 후보에는 연결 재무상태표 `20240319000684:123:0`가 들어왔지만 RRF16위라 최종12개에서 빠졌다. 차입금 내역은 네 조건에 모두 전달되었으므로 분자만으로 비율을 완성할 수 없다. A/B/C에서 큰 청크를 전체 생략한 사례도 있었지만, 여기서 확인된 자산 분모 누락은 이미 그 이전 후보·선택 단계에 있었다.

이 패널에서는 후보 깊이와 질문 수를 늘리는 것만으로 최종 근거 충족이 보장되지 않았다. B가 C보다 높은 충족 수를 보였으므로 **C−A의 증가를 질문 분해 고유의 효과라고 주장할 수 없다.** 이 결과만으로 RRF 일반의 우열이나 새로운 선택 방식의 이득까지 결론 내리지는 않는다.

## 종료 상태와 재현 자료

사전 기준에 따라 답변96회 비교,새60문항 검증,같은 패널에서 prompt·후보 수·RRF 가중치를 바꾸는 후속 실험은 실행하지 않았다. 기본 앱의 top-8과 기존 동작을 유지했다. B의 근거 충족 증가도 이번 답변 정확도 검증이나 기본값 변경의 근거로 승격하지 않는다.

새 산출물은 `benchmarks/results/query_decomposition_v2_20261020_132630/`에 저장했고 Git 추적 대상에서 제외된다.

- `revision.json`, `runner_revision.diff`, `authorization.json`: 승인된 수정 범위와 새 실행기
- `stage1/`: 분해 원응답,모든 검색 후보,48개 실제 입력,요청·응답,ledger와 seal
- `evidence_review.json`: 필수 근거 단위별 후보·선택·전달 판정,대체 근거와 검토 이유
- `stage1_review.json`, `decision.json`: 고정 기준에 따른 진행 판정과 종료 상태
- `mechanism_diagnosis.json`: 위 세 사례의 원래 검색 순위와 재계산한 RRF 순위
- `cost_and_size_summary.json`, `stage1_full_integrity.json`: 비용·입력량·호출·원본 보존 확인

프로젝트 경험으로 설명할 수 있는 결론은 “질문 분해로 정확도를 올렸다”가 아니라 **복합 질문의 근거 누락을 후보·선택·입력 단계로 분리하고, 문맥 크기와 검색 깊이를 통제해 분해의 추가 효과가 충분하지 않음을 확인했다**는 것이다. 답변 성능 상승 주장은 이번 결과에 포함되지 않는다.
