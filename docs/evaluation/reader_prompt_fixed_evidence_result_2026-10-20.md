# 동일 근거에서 답변 생성 지시를 바꾼 소규모 실험

2026-10-20. 정답에 필요한 근거가 전달됐지만 이전 답변이 실패한 6문항에서, 기존 지시와 근거 점검 지시를 각각 3회 비교했다. **이 수정의 답변 품질 개선은 확인하지 못했다.** 기존의 엄격한 완전 정답 기준에서는 **6/18 → 4/18**이었다. 불확실성을 명시한 반올림 가설 두 답변을 허용하면 **6/18 → 6/18**, 완곡한 원인 추정까지 모두 허용하면 **6/18 → 7/18**이다. 세 해석 모두 사전에 정한 탐색적 개선 기준에 미달했다.

셀트리온 상각비의 계산 대상 선택은 두 조건 모두 0/3, 현대차 차량 이익의 조정 범위 선택은 1/3 → 0/3이었다. 인용 지시를 강화해도 문장 옆 출처가 그 주장을 뒷받침하지 않는 경우가 남았다. 제품 프롬프트와 기본 설정은 유지한다.

## 비교 조건

[전체 평가](full77_top8_top12_ab_result_2026-10-20.md)와 [회귀 분석](top12_regression_diagnosis_2026-10-20.md)에서 실제 입력까지 추적한 실패 중 6개를 선택했다. KB금융 WM 요약처럼 질문의 넓은 범위와 고정 평가 항목 사이에 해석 문제가 큰 문항, 필수 근거가 빠진 문항은 제외했다.

| 항목 | 고정하거나 변경한 내용 |
|---|---|
| 대상 | 제네시스 전략, 현대차 차량 이익, 셀트리온 상각비, 현대차 미국 판매, 셀트리온 파이프라인, NAVER CAPEX |
| 근거 | 각 문항의 과거 실패 당시 packet 그대로. 앞의 5개는 당시 top-12, NAVER는 당시 top-8 |
| 동일성 | 질문·명시적 보고서 범위·청크 본문·문맥·ID·순서 및 실제 user payload 동일 |
| P0 | 현재 `ANSWER_INSTRUCTIONS` |
| P1 | P0 뒤에 공통 근거 점검 지시 추가. 회사명·문항 ID·정답·정답 수치·평가 메모 없음 |
| 모델 | `gpt-5.6-terra`, reasoning `low`, 동일 strict `RagAnswer`, 출력 상한 8,192, default tier |
| 실행 | 6문항 × 2조건 × 3회 = 새 답변 36개. 인접 P0/P1 순서를 문항·반복별 교대 |
| 제한 | 36회, 추정 사용량 2달러, 15분, 재시도 0. 오류·예산·동일성 위반에서 중단 |

이번 비교에서 P0/P1은 프롬프트 조건이다. top-8과 top-12를 다시 비교한 것이 아니다. 검색·임베딩을 재실행하지 않고 저장된 검색 결과를 실제 `SimpleRagAgent` 생성 경로로 전달했다. 시스템 지시 외의 native 요청 body가 동일함을 확인했다.

P1은 요청 항목별로 근거를 점검하고, 사실과 계산 피연산자의 대상·기간·범위·단위·항목을 맞추며, 구성항목·합계·조정을 구분하도록 요구했다. 계산값과 공시값을 분리하고 근거 없는 차이 원인을 만들지 않도록 했으며, 중요한 주장마다 source ID를 답변 안에 표시하고 인용 목록에도 넣도록 했다. 계산 도구, 별도 검증 호출, 구조화된 셀 선택 단계는 추가하지 않았다.

정확한 두 지시는 로컬 산출물 `prompts.json`에 보존했다. 여러 점검 항목을 함께 추가한 하나의 조건이므로, 각 문장의 개별 효과를 분리한 실험은 아니다.

## 정답과 근거 충실성

완전 정답은 기존처럼 내용 정확성·요구 충족·인용 근거 지지가 모두 PASS인 답변이다. 모든 출력과 원응답을 봉인한 뒤 조건명을 가린 36개 답변을 같은 assistant가 원문과 대조했고, 초기 판정과 민감도 해석을 저장한 후 조건을 열었다. 인용 스타일 때문에 조건을 추측할 수 있으므로 완전한 맹검이나 독립 평가로 보지 않는다.

| 지표 | 기존 P0 | 근거 점검 P1 |
|---|---:|---:|
| 엄격한 완전 정답 | 6/18, 33.3% | 4/18, 22.2% |
| 내용 정확성 PASS | 8/18 | 10/18 |
| 요청 항목 포함 PASS | 18/18 | 18/18 |
| 인용 근거 지지 PASS | 9/18 | 6/18 |
| 정확성 PASS / PARTIAL / FAIL | 8 / 5 / 5 | 10 / 2 / 6 |
| 근거 지지 PASS / PARTIAL / FAIL | 9 / 7 / 2 | 6 / 12 / 0 |

요청 항목을 언급했다는 완전성 PASS가 그 항목의 정답을 의미하지는 않는다. 잘못된 범위의 수치로 모든 항목을 채운 답변은 정확성에서 실패한다.

| 문항 | P0 완전 정답 | P1 완전 정답 | 관찰 |
|---|---:|---:|---|
| 제네시스 고급화 전략 | 2/3 | 2/3 | P1은 미국 설명의 기간 혼동을 피했지만 한 답변에서 보고서 전체의 별도 실적 부재를 단정 |
| 현대차 차량 이익 비중 | 1/3 | 0/3 | P1 세 번 모두 조정 전 차량 이익을 선택 |
| 셀트리온 상각비 영향 | 0/3 | 0/3 | 두 조건 모두 자산 배부까지 포함한 합계로 8.38%p 계산 |
| 현대차 미국 판매 성장 | 2/3 | 0/3 | P1의 반올림 원인 설명은 엄격 기준에서 미통과. 불확실성 표현에 따라 아래 보조 결과가 달라짐 |
| 셀트리온 파이프라인 | 1/3 | 1/3 | P1 두 번은 개발품의 참조 브랜드를 쓰면서 그 관계의 근거 문서를 인용하지 않음 |
| NAVER 인프라 투자 | 0/3 | 1/3 | 통과한 P1은 추가 감소율을 생략. 올바른 감소율 계산을 보여준 것은 아님 |

현대차 미국 판매의 P1 세 답변 모두 11.4% 계산과 공시의 11.5%를 구분했다. 그중 두 답변은 차이 원인이 확정되지 않는다고 명시하면서 반올림을 가능성으로 제시했다. 이 두 답변을 허용하면 P1의 완전 정답은 6/18로 P0와 같다. “반올림 때문으로 보인다”는 나머지 답변도 허용하면 P1은 7/18이다. 기존 원문 지지 기준과 이 보조 해석을 함께 공개하며, 가능성을 한정한 답변을 확정적 사실 날조와 동일하게 설명하지 않는다.

사전 기준은 완전 정답 3개 이상 증가, 문항별 통과 횟수가 2문항 이상에서 증가, 인용 지지 감소 없음이었다. 엄격 기준에서는 모두 만족하지 못했다. 위 보조 해석에서도 완전 정답 증가가 최대 1개여서 기준에 미달했다. 같은 6문항의 반복이며 새 독립 질문 18개가 아니므로, 일반 성능이나 안정적인 악화 확률을 추정하지 않는다.

## 무엇이 그대로 남았나

**셀트리온은 값을 보지 못한 문제가 아니었다.** P1 두 답변은 손익 비용 182,049,824천원을 직접 언급하면서도, 기능별 배부 합계 182,286,838천원을 계산에 사용했다. 두 값의 차이 237,014천원은 같은 표의 개발비 209,548천원과 건설중인자산 27,466천원의 합계다. 매출액 2,176,431,531천원으로 나누면 각각 8.3646…%p와 8.3755…%p다. 모두 영업비용이라는 가정을 덧붙였지만 실제 손익효과를 선택하지 못했다. `360:200`의 합계와 `185:25`의 손익비용을 질문에 맞게 구별하는 문제가 남았다.

**현대차에서는 조정 전후를 구분한 피연산자 선택이 안정화되지 않았다.** P1은 세 번 모두 통합표 `530:388`의 조정 전 차량 이익 12,969,227백만원을 선택했다. 이를 전체 15,126,901백만원으로 나눈 85.7% 또는 85.74%는 산술적으로 맞다. 그러나 기존 평가가 요구하는 조정 반영 차량 이익 12,677,300백만원과 비중 83.8%를 구분해 제시하지 못했다. 한 답변은 전체에 제거액이 반영됐음을 명시하여 인용 지지 자체는 PASS로 판정했다. 이 실패를 숫자 날조나 모든 조정 전 비율의 무효로 확대하지 않는다.

**문장마다 출처를 넣는 것만으로 인용 관계가 맞아지지 않았다.** 셀트리온 P1 두 답변은 CT-P39–졸레어, CT-P41–프롤리아·엑스지바, CT-P43–스텔라라 등 대응을 쓰고 `103:44`를 붙였다. 그 표에는 개발 단계와 적응증이 있고 해당 참조 브랜드 대응은 없다. 관계를 제공하는 `84:25` 또는 `1056:11`도 인용 목록에서 빠졌다. 내용 자체는 제공 문맥의 다른 청크에 있지만 인용 연결은 틀렸다.

P1의 나머지 파이프라인 답변은 전체 인용 목록에 해당 근거가 포함돼 기존 기준에서 통과했다. 일부 문장 옆 ID 하나만으로는 주장을 지지하지 못했지만, 이번 평가 도중 기준을 ‘각 inline 인용의 개별 정확성’으로 강화하지 않았다.

**불필요한 설명을 줄여 통과한 경우와 오류를 고친 경우도 달랐다.** NAVER에서 통과한 P1은 감소액 639억원을 맞히고, 기존에 틀렸던 감소율은 생략했다. 감소율을 다시 쓴 P1은 여전히 8.4%라고 답했다. 실제 639/7,562는 8.450145…%로 소수 첫째 자리에서는 8.5%다. 다른 P1은 감소율을 생략했지만 401,910,065천원을 ‘4,019억 100만원’으로 잘못 변환했다. 정확한 환산은 4,019억 1,006만 5,000원이다.

이 결과는 일반적인 근거 점검 지시만으로 계산 대상의 의미나 인용 지지가 검증되지는 않았음을 보여준다. P1에서 답변과 출처 표시가 길어졌다는 사실도 실제 검증 절차가 생겼다는 뜻은 아니다. 같은 문항에 더 많은 금지 문구를 덧붙이는 추가 실행은 하지 않았다.

추정 비용 합계는 **$0.6771666**, 실행·보존 확인을 포함한 시간은 **219.21초**다. P1은 출력 토큰이 약 48.0%, 비용이 약 18.3% 늘었다. [공식 모델 요금](https://developers.openai.com/api/docs/models/gpt-5.6-terra)의 100만 토큰당 일반 입력 $2, 캐시 읽기 $0.20, 캐시 쓰기 $2.50, 출력 $12를 저장 usage에 적용했다. reasoning 출력은 출력 합계 안에 포함되어 중복 과금하지 않았다. 청구서 정산값은 아니다.

실행 전 외부 네트워크를 차단한 SDK 모의 호출 36회와 실패 조건 12개를 확인했다. 실제 요청 36개·원응답 36개·제품 응답을 대조했고 응답 ID는 모두 고유했다. 실제 오류·재시도·검색·임베딩·별도 judge 호출은 0회다. 기존 소스·환경·활성 store·선행 실험 등 보호 파일 3,651개와 HEAD·staging을 보존했다.
