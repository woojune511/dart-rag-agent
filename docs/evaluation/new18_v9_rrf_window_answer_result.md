## 회귀와 남은 문제

- **판정축 회귀:** 정확도·완성도·충실도·인용·경계·엄격 판정 모두 P→F 0,
  P→U 0. 필수 그룹의 P→F/U도 0. 엄격 U→P는 U04 두 반복과 U12 r1의 3개다.
  U18 r1은 F→U이며 완전 성공으로 세지 않았다.
- **실패 문항 내부 악화:** U08 r2의 8개 답변은 Euro 법인의 국가를 유보했으나,
  12개 답변은 러시아로 연결했다. 실제 관계는 원문 소재지 표에서 확인되지만,
  생성에 제공하고 인용한 표는 그 관계를 지원하지 않는다. Vina–베트남 연결도
  같은 기준으로 네 답변 모두 점검했으며 명칭 연상만을 출처 증거로 인정하지 않았다.
  따라서 양쪽 모두 충실도 F이나, 지원되지 않는 Euro 연결은 1/2→2/2로 증가했다.
  기존 F에 가려지는 추가 주장의 악화를 별도로 유지했다.
- **U15 원문 충돌:** 서술은 두 부문의 영업이익 개선을 말하지만 호텔&레저 표는
  64,522→60,854백만원이다. 네 답변의 호텔 이익 개선/개선 기여 주장은 정확성 U,
  원문 귀속에 맞는 전달은 충실도 P다. 생성 환각 F로 바꾸지 않았다. 공항 철수
  위약금 일부가 영업외 비용이라는 필수 설명은 양쪽 2/2 보존됐다.
- **U14:** 상충 서술 `1017:0`은 RRF 14위로 양쪽에 없다. 네 답변 모두 부문 표를
  정확히 읽었다. 과거 v6의 “12개에 상충 자료 추가” 조건을 이번 결과에 적용하지 않았다.
- **부재 단정:** U18 네 답변과 U12의 8개 r1은 발췌에서 못 찾은 내용을 보고서
  전체의 미공시로 넓혔다. 원래 bounded-negative 기준으로 U를 유지했다. 추가 문맥이
  필수 근거를 새로 제공하지 않은 U12/U18의 문장 차이는 생성 변동 가능성이 남는다.
