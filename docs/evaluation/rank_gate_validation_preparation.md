# 검색 순위 불일치 규칙: 전향적 소규모 반복 비교

Date: 2026-09-29. User request: “그럼 그걸 검증해볼까”.

목적은 [사후 감사](selector_call_audit.md)에서 사용한 호출 규칙을 새 질문에
그대로 적용했을 때 이득 포착·회귀·비용이 유지되는지 확인하는 것이다.
제품 기본 경로는 바꾸지 않는다.

## 고정 설계

- Dense와 BM25 각각의 상위 8개 ID 집합의 Jaccard 불일치가 **6/7 초과**이면
  추가 LLM 선택. 두 집합이 각각 8개면 공통 후보 0–1개일 때 호출한다.
  동점은 건너뛴다. 부동소수점 경계 오차를 피하도록 동일 조건을 정수로 계산한다.
- KB금융·NAVER·카카오·현대자동차의 기존 2023년 보고서에서 새 긍정 질문 8개를
  작성하고 질문·요구사항·원문 witness를 검색 전에 동결했다. 과거 보고서에
  노출됐고 일부 문항은 원문을 공유하므로 독립 gold·미노출 보고서 평가가 아니다.
- 인원/여성 비중, 평가기관별 장단기 등급, 주요리더 보수 범위,
  연결 R&D 자산화·집계·회계처리, 보조금 차감 후 R&D 증감,
  러시아 공장 지분매도 옵션을 묻는다. 정확한 요구 문구와 허용 근거는 로컬
  `questions.json`, `rubric.json`, `witnesses.json`에 고정했다.
- 긍정 G01/G05의 필수 숫자를 포함한 전체 후보 출처를 제거한 통제 C01/C05를
  추가한다. 원문을 편집하지 않으며 후보 전체에서 대체 근거가 없는지 생성 전에
  검토한다. 부모 질문의 검색 판단을 상속하는 거절 통제이며 새로운 독립 질문,
  자연적인 corpus 누락 또는 gate의 부족 근거 탐지력 평가로 세지 않는다.
- 모든 10개 입력 조건에 RRF 답변과 선택 후 답변을 두 번씩 생성한다.
  선택도 매 반복 새로 수행한다. 조건부 정책은 고정 gate에 따라 두 경로 중
  하나의 관측 결과를 사용한다. 별도 세 번째 답변은 생성하지 않는다.
- 반복 사이 대화 상태를 공유하지 않고, RRF와 선택+답변 실행 순서를 교차한다.
  프롬프트·모델·출력 형식은 기존 비교와 동일하다. 새 요약·계산기·재검색은 없다.

## 검색과 실행 경계

기존 table corpus·문서 벡터를 재사용하고, 질문별 임베딩만 8회 수행한다.
Dense16과 기존 BM25/RRF60의 후보 pool을 고정한다. 후보 표시 순서는 기존
hash 순서이고, whole-source 선택 입력 상한은 overhead 포함 200,000바이트다.
RRF에 전달되는 출처를 우선 보존하며 초과 후보는 기존 방식으로 통째로 제외하고
기록한다. 답변 packet은 65,536바이트, 전체 요청 예약 상한은 68,560이다.

모델은 `gpt-5.6-terra`, reasoning low, 최대 출력 8,192토큰, store=false,
standard/default service tier다. 다른 모델로 대체하지 않는다.
[공식 모델 문서](https://developers.openai.com/api/docs/models/gpt-5.6-terra)와
[가격표](https://developers.openai.com/api/docs/pricing)를 2026-09-29 확인했다.
Standard short-context 입력 $2/출력 $12 per 1M, 질문 임베딩 $0.13 per 1M을
사용하며 cache 할인은 무시한다. 예약 입력 상한은 long-context 기준 272K보다 낮다.

최대 **생성 60회 + 질문 임베딩 8회**, 총상한 **USD20**이다.
최대 입력·출력 사용량 기준 전체 예약은 **USD19.38616**이다.
이전 실행의 소비된 승인을 재사용하지 않고 이번 요청에 따른 별도 1회 실행이다.

두 단계로 진행한다. (1) 8회 임베딩과 검색을 봉인하고 통제를 확인한 뒤,
(2) 최대 60회 생성을 수행한다. 각 단계는 1회만 시작할 수 있다.
오류·usage 누락·잘못된 출처·budget/hash/형식 위반이면 남은 실행을 중단한다.
재시도·오류 이후 재개·결과에 따른 문항 교체는 없다. 20초 heartbeat를 기록한다.

## 평가와 중단 판단

긍정 문항의 주 판정은 모든 명시 요구의 정확성·완전성·실제 인용 지지 및
비거절이다. 통제는 근거 부족을 명시하고 요청한 정확한 수치를 만들어내지 않아야
한다. 관련된 근거 있는 부분 답변은 허용한다. 기간·대상/범위·단위·연산/산술,
누락·인용 지지를 분리하고, 답변에서 피연산자를 확인할 수 없으면 추정하지 않는다.

안정적 개선은 선택 경로가 두 번 모두 통과하고 RRF는 한 번 이상 실패한 문항이다.
안정적 회귀는 반대다. 두 반복을 별도 독립 질문으로 부풀리지 않는다.

후속 비용을 검토할 탐색적 기준은 다음을 모두 만족하는 것이다.

- 안정적 개선 문항 최소 2개, gate가 관측된 안정적 개선을 모두 포착.
- gate로 발생한 안정적 회귀 없음, 통제에서 잘못된 완전 답변 증가 없음.
- 조건부 비용이 항상 선택 비용의 80% 이하.
- 호출·비호출 긍정 문항이 모두 존재.

개선이 적거나 두 경로가 모두 높으면 효과 판별 불가로 종료한다. 이 기준은
통계적 우월성·배포 승인 기준이 아니다. 리뷰는 원문을 아는 assistant가 수행하며,
가능한 한 조건명을 가린 응답을 사용하지만 독립 평가자로 표현하지 않는다.

## 실행 전 확인된 상태

9개 계약 테스트와 10개 오류/예산 중단 통제가 통과했고, 네트워크 차단 예행에서
임베딩 모의 8회·생성 모의 60회를 재현했다. 초기 준비에서 부동소수점 경계와
단계별 admission 연결을 수정했으며 이전 파일은 보존했다. 초과 입력 검사에서는
정상적인 BudgetStop을 기대하도록 테스트만 수정했다. 실제 유료 오류 재시도는 없다.

생성 전 실제 검색에서는 **G03만 호출 조건에 해당**했고, 긍정 8개 모두 대표
witness가 RRF top-8에 있었다. C01/C05는 각각 필수 출처 1개가 제거돼 후보 34개씩
남았으며, 남은 출처·context의 요청 숫자 유출과 대체 근거를 확인했다.
질문 임베딩 추정 비용은 USD0.00010764다. 표본을 교체하지 않았으므로 검색
회복보다 읽기/답변 효과를 관측하는 비교이며 gate 효과를 판별할 힘은 제한적이다.
