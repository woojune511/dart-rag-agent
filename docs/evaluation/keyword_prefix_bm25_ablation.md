# 공통 키워드 접두어 제거: BM25 검색 비교

2026-10-15 · 완료 · `COMPLETE_REVIEWED_NO_ADOPTION`

**필수 근거가 충분한 문항은 11/12 → 11/12로 같았다. N03은 개선됐지만 C10에서 실제 회귀가 발생했다.** C12는 기존 출처가 top8에서 빠졌어도 동일한 내용을 제공하는 연결 주석이 남아 회귀로 세지 않았다. 사전 조건인 기존 성공 문항의 근거 보존에 실패했으므로 기본 검색은 유지한다.

이 수치는 **검색 입력의 근거 충분성**이다. 새 답변을 생성하지 않았으므로 답변 정확도 개선·하락을 측정한 결과가 아니다. [직전 reader/evidence 진단](reader_evidence_diagnostic_result.md)의 답변 판정도 변경하지 않는다.

## 고정한 조건과 유일한 변경

사용자는 공통 키워드 접두어만 제거하고 나머지 조건을 고정한 검색 비교 및 다른 문항의 회귀 확인을 요청했다. 직전 진단에서 제안한 provider-free 비교에 따라 **BM25 색인의 생성된 `[키워드: …]` 한 줄과 그 줄바꿈만 제거**했다. Dense 후보는 기존 실행의 결과를 그대로 재생했다.

| 항목 | 조건 |
| --- | --- |
| 소스 | 농심·코웨이 2025년 사업보고서, 원본 XML 및 기존 2,240청크·순서 고정 |
| 질문·정답·판정 | 직전 진단의 12문항 전체, frozen gold/rubric/원문 witness 고정 |
| 변경 | 2,240청크 각각의 생성된 키워드 줄 1개만 BM25 검색 텍스트에서 제거 |
| 보존 | 원문, 청크 경계, metadata, 회사·연도·섹션 및 나머지 구조 접두어 |
| Dense | 질문별 기존 top16의 ID·거리·순서·원문 고정, 재임베딩 없음 |
| BM25 | 실제 제품의 한글 bigram tokenizer, BM25Okapi `k1=1.5, b=0.75, epsilon=0.25`, scope 후 양수 점수 top24 |
| 결합 | 실제 제품의 동일 가중치 RRF `k=60`, Dense 우선의 동점 순서, 최종 top8 |
| 답변 입력 | 선택된 청크의 **기존 전체 텍스트**로 복원, 실제 `SimpleRagAgent` 입력 경계에서 캡처; 65,536-byte 한도 고정 |
| 실행 | 변형 1개, provider/임베딩/답변 호출 0, 비용 USD0, runtime·앱 store 변경 없음 |

색인 텍스트가 달라지면서 TF·문서 길이·평균 길이·IDF는 각 색인에서 다시 계산된다. 이는 접두어 제거의 결과이며 별도 튜닝이 아니다. 답변 입력까지 키워드 줄을 제거하면 두 변수를 바꾸게 되므로 검색 표현과 전달 원문을 분리했다. 이 비교는 **Dense 임베딩에서도 접두어를 제거한 실험이 아니다.**

## 개선과 회귀의 근거

### N03: 공통 접두어의 검색 영향이 실제로 관찰됨

필요한 `998:2`에는 매출액3,514,316/3,438,731백만원과 영업이익183,933백만원, 당기·전기 열, 연결 영업실적 제목이 있다. 기존에는 BM255위였지만 Dense16에 없어 RRF10위에서 잘렸다. 제거 후 BM251위·RRF2위로 최종 입력에 들어왔다.

직전 진단에서 원문에는 매출액·영업이익이 없는데 접두어에만 그 단어가 붙었던 청크들이 관찰됐다. 이번 단일 변경은 그 접두어 줄이 **N03의 BM25 순위 저하에 기여했다**는 근거를 제공한다. 다만 제거한 한 줄에는 섹션명 반복 등도 함께 있으므로 어느 개별 토큰이나 TF/IDF 효과가 원인인지는 분리하지 않았다. Dense 후보는 그대로라 연금 가정·주당이익 표제 청크도 여전히 상위에 남는다.

### C10: 연결 표가 별도 표에 밀리는 실제 근거 회귀

기존 `104:5`에는 연결 영업활동 현금흐름 **35,544,145,039원**, 당기순이익 **617,510,076,654원**이 있다. 제거 후 이 청크가 최종10위로 내려갔고, 새로 들어온 `486:4`는 **별도** 현금흐름표의19,961,564,073원과399,059,004,756원이다. 같은 항목명이 있어도 질문의 연결 범위를 충족하지 않는다.

최종8청크 전체의 원문·접두어·context를 검토했다. 다른 청크는 값 없는 표제, 다른 금융손익, 회계기준 개정 설명 등을 담고 있으며 필요한 두 연결 금액을 제공하지 않는다. 숫자의 단순 문자열 부재 검사도 병행했지만, 회귀 판정은 출처 전체와 요청 범위의 대조에 근거한다.

`400:295`와 `748:261`은 각각 연결·별도 주석의 “영업활동현금흐름 / 당기 / 단위”만 있는 표제 청크인데 두 검색 채널에 함께 나와 RRF1·2위를 유지했다. 필수 연결 표는 한 채널에만 나와 BM253→4위의 작은 하락이 최종8→10위의 근거 소실로 이어졌다. RRF는 계약대로 계산됐지만, 순위 결합 자체는 값의 존재나 요청 범위 충족을 보장하지 않는다.

### C12: 출처 ID 이탈을 회귀로 과대 집계하지 않음

환위험 문단 `74:1`이 최종8→9위로 빠졌다. 그러나 최종2위인 **연결** 주석 `450:345`에 수출·원재료 수입 관련 자산·부채라는 발생 원인과 정기 평가·관리·보고 절차가 모두 있다. 최종1위 `77:4`에는 차입한도·유동성 예측·고려사항·잉여자금 운용 원칙이 남는다.

원본 XML의 `39. 재무위험관리 (연결)` 아래 로컬 표 byte 범위2,980,154–2,988,849와 환위험 열을 별도로 대조했다. 이 문항은 근거 중복이 줄었지만 필수 내용이 사라진 회귀는 아니다.

## 검증과 해석 범위

- 실행 전에 protocol·코드·테스트·의존성 버전과 보호 파일761개를 고정했다. freeze SHA256: `df8a87eca0b5bbae7adbec5664cd4d0de0584c3e53719f41f2eb77e982a4ed34`.
- 기본 검색의 Dense/BM25 후보·점수·RRF top8·실제 답변 입력·누락을 **12/12 재현**한 뒤 변형을 실행했다. 독립 RRF 계산과 실제 입력 캡처를 두 조건24건 모두 대조했다. Dense192개 후보는 조건 간 동일하다.
- 원문 경계 밖 키워드 줄만 제거하는 동작, 원문 안 동명의 문자열 보존, 누락·중복 접두어 거부, CRLF, 네트워크 차단 테스트 **5/5 통과**. 생성된2,240줄·360,642 UTF-8 bytes가 제거됐고 원문·나머지 접두어는 보존됐다.
- 기존 준비 입력32개·보호 파일440개·봉인된 live 파일343개·과거 검사 파일2,751개와 이전 분석 결과를 다시 확인했다. 기존 파일을 덮어쓰지 않고 새 실험 폴더에 결과·주석·원문 witness를 분리했다.
- 원문 검토는 같은 assistant의 비맹검 판정이다. 이미 노출된 양성12문항·두 보고서 corpus이며, 실제 제품11개 보고서의 BM25 통계와 다르다. 일반화·거절 성능·모델 성능을 입증하지 않는다.
- C09의 기존 계산 절차 `UNDETERMINED`와 C11의 기존 추가 해석 오류는 그대로다. 근거가 충분하다는 판정과 모델이 올바르게 답했는지는 분리한다.

## 결정과 재현 자료

**공통 키워드 줄의 일괄 제거를 제품에 반영하지 않는다.** N03의 국소 이득은 확인됐지만 C10 회귀로 사전 보존 조건을 통과하지 못했고 전체 근거 충분성의 순증도 없다. 가중치·topK·접두어 예외를 이번 결과에 맞춰 조정하거나 후속 유료 실행으로 넘어가지 않았다.

남은 구체적 관찰은 “값 없는 표제 청크가 두 채널의 중복 투표로 상위에 남고, 필요한 값이 있는 표는 top8 경계에서 탈락한다”는 것이다. 후속 검토를 한다면 이 청크가 생성·색인되는 경계와 내용 보존을 먼저 확인할 근거가 생겼다. 이번 결과만으로 parser 버그나 Dense 접두어 제거의 효과까지 판정하지 않는다.

로컬 재현 자료는 `benchmarks/results/keyword_prefix_bm25_ablation_2026-10-15/`에 있다. `protocol.json`, `freeze.json`, `ablation.py`, `test_ablation.py`, `baseline_reconstruction.json`, 두 조건의 `*_retrieval.json`·`*_bm25_ranks.json`, `removal_proofs.json`, `results.json`, `source_review.json`, `additional_original_witnesses.json`을 보존한다. `results.json`은 검색 실행 당시 상태이고, 최종 의미 검토와 결정은 `source_review.json`, 무결성 종료 기록은 `closeout.json`을 따른다. 실험 산출물은 Git ignored 상태다.
