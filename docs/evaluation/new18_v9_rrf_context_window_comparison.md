# v9 저장 RRF의 최종 문맥 8개·12개 비교

상태: **COMPLETE_OFFLINE_SOURCE_COMPARISON**. 추가 모델·임베딩·검색·reranker·judge 호출 **0회, USD 0**. 새 답변 생성·정확도·출처 충실도 평가는 **NOT_RUN**이다.

**12개에서 HD 경영진단 핵심 근거는 복구되지만, U16의 당기 현금과 미래 리스는 복구되지 않는다.** 새 18문항의 필수 근거는 **27/33→28/33**, 기존 충분 근거의 회귀는 **0개**다. 문맥 평균 크기는 **20,979→32,115 bytes, +53.1%**다. 이 결과만으로 기본 문맥 수를 변경하거나 답변 품질 향상을 주장하지 않는다.

## 고정 조건과 확인 방법

[v9 실행](new18_v9_store_execution_result.md)의 봉인된 `live_v1/retrieval/U01..U18.json`을 사용했다. 현재 작업 소스는 v12지만, 재파싱·새 검색·store 개방 없이 **저장된 v9 후보·본문·metadata·점수·순서**만 읽었다. 과거 v6의 문맥 비교 결과는 이번 순위나 판정에 대입하지 않았다.

8개 문맥 **18/18은 과거 실제 생성 요청의 문맥과 바이트까지 일치**했다. RRF 점수·순서도 18/18 일치한다. 12개 문맥의 앞 8개는 기존 문맥과 출처 내용·순서가 모두 같으며, 두 조건 모두 크기 제한으로 생략된 출처가 없다. 총 36개 문맥에 각각 정확히 8개·12개가 들어갔다.

원문 XML 3개와 기존 정답 근거 97개 fragment의 해시를 확인했다. 저장 후보 620개는 v9 corpus의 원래 metadata와 모두 일치했다. 본문 615개는 정확히 같고 5개는 기존 BM25 색인의 끝 공백 제거만 달랐다. 이 차이는 과거 실행 코드의 `.strip()` 동작이며, 이번 문맥은 저장된 후보를 그대로 보존했다. 새 정규화나 파서 수정을 하지 않았다.

## 중복·상충·오독 가능성

출처 ID 중복과 접두어 포함 전체 텍스트 중복은 모두 0이다. 접두어를 제외한 **본문만 동일한 추가 슬롯**은 전체 6개→9개로 늘었다. 증가분은 U04의 배출권 도입문, U14의 연결/별도 영업부문 표제, U18의 서로 다른 절의 ‘해당사항 없음’이다. 절·범위가 다른 자료도 있어 동일 본문만 보고 삭제하지 않았다.

이번 v9 U14에서는 “두 부문 영업이익 개선”이라는 서술 `1017:0`이 **RRF 14위**다. 따라서 과거 v6의 12개 문맥에서 관측했던 상충 서술 추가를 이번 결과에 재사용하지 않는다. U13·U15에서는 같은 서술과 호텔&레저 이익 **64,522→60,854백만원** 표가 이미 8개에 함께 있고, 12개에서도 그대로 남는다. U17의 이번 두 문맥에는 ‘비누적’ 설명이 없으므로 과거 v6의 우선주 설명 충돌도 새로 발생했다고 세지 않는다.

필수 근거의 물리적 손실은 없지만, 전기/당기·연결/별도 자료와 값 없는 표제가 더 들어온다. U03의 지역표는 본사국가·북미·아시아·유럽·기타 열과 값을 보존하고, U16의 추가 표는 당기/전기와 지급/만기 구분이 가능하다. **모델이 이를 올바르게 읽는지, 문맥 증가가 오독·누락·인용에 영향을 주는지는 확인하지 않았다.** 이는 저장된 근거의 보존 검사와 별도다.

## 판단과 한계

- **확인:** HD 핵심 근거는 후보에 있고 9위라 12개에서 복구된다. U16의 현금 요약·미래 리스는 후보에 있지만 19·30위라 12개에서도 빠진다.
- **확인:** U08·U09의 지정한 필수 값은 후보 단계에서 누락되어 같은 후보의 최종 개수 조정으로 해결되지 않는다. 문맥 확대는 실패 유형 전체를 해결하지 못한다.
- **확인:** 기존 충분 근거 27개는 내용과 순서까지 보존됐다. 12개에서는 근거 한 그룹 추가에 문맥 평균 53.1% 증가가 동반된다.
- **미검증:** 새 답변의 정확도·필수 항목 완전성·출처 충실도, 생성 시간·실제 토큰 비용. 개발에 노출된 18문항의 assistant 근거 검토이므로 일반 성능이나 통계적 우열도 주장하지 않는다.
- **결정:** 기본 top8·검색·생성·활성 store는 유지한다. 12개 채택이나 후속 호출을 실행하지 않았다.
