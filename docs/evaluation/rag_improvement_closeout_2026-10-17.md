# RAG 개선 작업 종료와 유지 기준선

2026-10-17. 상태: **종료 — 기본 검색·생성 설정 유지, 추가 실험 없음**.

원문을 잃거나 잘못 연결하던 파서 결함 수정은 소스에 유지한다. 개별 문항의 검색·생성 개선을 겨냥한 실험은 아래 결과로 마감하고 기본값으로 채택하지 않는다. 이번 정리는 추가 모델 호출이나 새 성능 평가를 포함하지 않는다.

**전체 정확도 향상이나 배포 완료를 선언하지 않는다.** 현재 소스의 파서는 v12지만 `.env`가 지정한 기존 store는 v5다. 별도 v9 평가 store도 활성화하지 않았다. 원문 보존 수정의 유지, 실험의 답변 효과, 실제 앱의 실행 가능성을 분리한다.

## 유지할 구현

유지 판단의 근거는 재현 가능한 원문 손상 복구와 범위·출처 계약이다. 특정 문항의 점수 상승을 파서 수정의 필요조건으로 삼지 않고, 원문 보존 검증을 답변 품질 보증으로 확대하지 않는다.

v9 원문 보존 검증은 세 보고서의 4,424개 블록·3,234개 표·38,024개 셀 좌표를 대조했다. v12 검증은 14개 원문 해시를 보존하고, 수정 대상 외 13개 보고서의 전처리 XML·트리가 v11과 같음을 확인했다. 이는 해당 원문의 구조 보존 근거이며 모든 DART 문서의 완전성을 입증하지 않는다.

**파서가 원래 표의 표제·기간 소유를 복구하는 변경과 C10의 실험용 검색 입력 확장은 다른 변경이다.** 앞의 구조 복구를 유지한다는 결정으로 뒤의 검색 실험까지 채택하지 않는다.

## 남은 한계

1. **실행 가능한 최신 store가 연결되지 않았다.** 현재 v12 소스와 지정된 v5 store의 manifest가 불일치한다. 이번에는 DB를 열거나 재구축·활성화하지 않는다. 문서상의 종료를 서비스 복구로 설명하지 않는다.
2. **필수 근거 누락이 남는다.** U09 현금흐름은 저장 후보에서 빠지고, v9 U16의 당기 현금·미래 1년 리스 근거는 최종 12개 밖에 있다. 청크 수 증가만으로 모든 누락이 해결되지는 않는다.
3. **생성의 관계·범위·산술 오류가 남는다.** C11 분류, U08 국가 연결·환산, 문맥의 부재를 문서 전체의 부재로 확대하는 문제가 포함된다. 출처 ID 검사는 주장별 지지 검증이 아니다.
4. **원문과 평가에도 불확실성이 있다.** U14·U15의 원문 서술·표 충돌과 기존 판정 유보를 보존한다. 핵심 정보 누락, 중대한 수치·대상 오류, 경미한 추가 표시 오류의 사용자 영향은 같지 않다. 기존 엄격 점수는 수정하지 않으며, 이 구분을 새 점수 향상으로 집계하지 않는다.
5. **18문항은 개발 회귀 세트다.** 실사용 상황을 가정해 assistant가 작성한 질문이며 실제 사용자 로그나 독립 holdout이 아니다. 반복 분석·수정에 사용됐으므로 미노출 정확도 근거로 쓰지 않는다. 두 번의 생성과 같은 assistant의 판정만으로 작은 차이의 안정성을 보장할 수 없다.
6. **전체 성능의 최신 추정값은 없다.** 과거 77문항, v9 평가, 현재 v12 원문 보존 검증은 서로 다르다. 최고 점수를 골라 현재 제품 정확도로 제시하지 않는다. 모델 alias와 새 임베딩도 완전한 불변성을 보장하지 않는다.

## 종료와 보존

이번 개선 작업은 **완료·종료**다. 남은 실패는 제한 사항이며 자동 실행 목록이 아니다. 기존 준비 문서의 `PREPARED_NOT_RUN`이나 과거 제안은 당시 기록으로 남기고, 새로운 실행 승인으로 취급하지 않는다. 이미 소모된 호출·비용 상한을 재사용하지 않는다.

이후 별도 작업을 시작하려면 사용자 목적·지원할 질문 범위·성공 기준부터 다시 정해야 한다. 개선 효과 검증이 필요할 경우 구현을 고정한 뒤 미사용 문서·질문으로 판단해야 하며, 이번 종료에서 새 평가 세트 작성이나 실행을 예약하지 않는다.

이전 현재 상태 문서의 상세 이력은 종료 전 상태 기록 (`../history/rag_improvement_handoff_snapshot_2026-10-17.md`, local artifact not included)에 보관하고, [CONTEXT](../../CONTEXT.md)와 [project status](../overview/project_status.md)는 유지 기준선과 남은 한계 중심으로 정리한다. 기존 실험 보고서의 수치·판정·원문은 바꾸지 않는다.
