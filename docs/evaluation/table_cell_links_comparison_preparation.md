## B에 추가하는 정보

추가 내용은 질문을 보지 않는 공통 변환으로 만든다. 전체 표 객체·정답 셀·평가 기준을 모델에 전달하지 않는다.

## 판정과 종료 기준

원래 필수 항목·선택 항목·반올림·범위 충돌 기준은 `gold.json`과 `evaluation_protocol.json`에 동결했다. 정확성, 요청 충족, 원문 충실도, 실제 인용 지원, 단위·기간·범위·부호, 엄격 성공을 각각 P/F/U/NOT_RUN으로 기록한다. 출처 ID 검사 통과를 의미 정확성으로 바꾸지 않는다.

**U03의 생략을 오류 교정으로 세지 않는다.** 지역별 상세 금액은 원래 질문의 선택 항목이라는 계약을 유지한다. 별도 기전 지표에서는 북미·아시아·유럽 금액이 실제로 제시됐는지와 연결 정확도를 함께 본다. B가 금액을 생략하면 원래 질문의 답변은 통과할 수 있지만, 셀 해석 개선은 `NOT_EXPOSED`다.

주 진단에서 안정적 교정이라고 부르려면 새 A에서 지역·금액 오연결이 한 번 이상 확인되고, 새 B의 세 번 모두 해당 세 지역의 금액과 인용이 정확해야 한다. 새 A에서 오류가 재현되지 않으면 `CEILING_OR_NOT_REPRODUCED`로 남긴다. 옛 오답을 사용해 새 비교의 개선을 만들어내지 않는다.
