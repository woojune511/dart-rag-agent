# 출처 선택 단일화: 6문항 실제 실행 계획

2026-09-28. 사용자가 “실험 실행까지 진행해줘”라고 요청한 단일 배치다.
봉인된 무호출 수정본은 그대로 두고 별도 실행본을 만든다.

- 동일한 개발 노출 6문항, 순서·원문·최초 검색·기존 rubric 유지.
- `gpt-5.6-terra`, reasoning low, 출력 최대8,192토큰, default tier, store=false 유지.
- 기존 고정 corpus와 벡터 재사용. 추가 질의만 `text-embedding-3-large`로 임베딩한다.
- 문항당 추가 검색 최대2회, 고유 선택 출처 최대8개. 답변 전후의 진단 비교를 위해 최초 답변을 저장하며, 검색을 하지 않으면 최종 답변으로 공유한다.
- 보수적 상한 USD15, 최대 생성30회·질의 임베딩12회, 전체 최대 예약USD14.0106. 최초 전송 이후 오류·잘못된 출력·예산 중단 시 배치를 종료하며 재시도·resume·출력 보정은 하지 않는다.
-20초 heartbeat와 요청·원시 응답·사용량·검색 기록을 저장한다.

변경 축은 원장의 evidence/qualifications에서 전달 출처를 코드가 파생하는 계약이다.
무호출 수정본과 동일한 프롬프트·스키마·검색·답변 로직을 사용한다. 새 실행본은
전송 경로와 manifest에 연결된 일회성 승인만 추가한다. 기본 앱은 변경하지 않는다.

실행 성공과 답변 품질을 분리한다. 기존 rubric의 완전성, 인용 원문에 대한 주요 주장
지원 여부, 주체·기간·단위, 기권·남은 정보 표시를 검토한다. 과정에서는 중요한 단서
보존, 추가 검색의 필요한 근거 회수, 성급한 sufficient 종료를 확인한다.
이전에 공개한 카카오 대안 답변 판정은 별도로 유지한다. 결과를 보고 rubric이나
과거 점수를 고치지 않는다. ERROR/NOT_RUN을 오답에 합치지 않는다.

기존 결과와의 비교는 개발 표본의 역사적 비교다. 독립 gold, holdout 또는 변경의
인과 효과를 입증하는 무작위 비교로 표현하지 않는다. 총 배치 비용은 최초 진단
답변과 거절된 호출도 포함하고, workflow 비교 비용은 검색한 문항의 중복 진단 답변을
별도로 분리한다.

[공식 가격표](https://developers.openai.com/api/docs/pricing)를 실행 준비 시 확인했다.
