## 평가 방법

P=충족, F=확인된 오류·누락 또는 인용 지지 실패, U=판정 유보다. 정확도는 실제 주장한 수치·기간·대상·관계를, 완전성은 기존 필수 그룹을 평가한다. 정확한 부분 답변도 완전성F일 수 있다. 엄격 통과는 모든 적용 축P이고 추가 중대한 문제가 없는 경우다. F와U가 함께 있으면 엄격 결과는F로 기록하되 축별U는 보존한다.

72개 답변을 사전에 고정한 익명 순서로 대조한 뒤 조건을 연결했다. 같은 assistant가 문항 작성과 검토를 수행했고 문맥 길이로 조건을 추정할 수 있으므로 독립 사람 평가나 완전한 맹검은 아니다. 원문XML97개 byte witness, 실제 요청72개, 원래 Decimal 계산24개 및 실제 답변의 추가 계산/반올림17개를 검증했다. 이는 사후 평가이며 제품이 산술·의미·누락을 검증했다는 주장이 아니다.

기존 대체 답변 허용과 U 처리를 유지했다. HD의 넓은 질문과 좁은 필수 타깃 차이, 전망을 과거 배경으로 옮긴 시점, 보고서 전체 부재 주장에는 기존과 같은 U 원칙을 적용했다. U14 충돌 언급이나 전년 비교를 새 필수 항목으로 추가하지 않았다. 실재 사실이라도 제공/인용 문맥에 관계 연결이 없으면 출처 충실도에서 실패할 수 있다. A019는 제공 문맥에는 있는 주장에 해당 출처를 인용하지 않은 사례이며, 내용을 새로 발명한 경우와 구별했다.
