## Contract and bounds

- Existing structured row records retain exact column indices and parser
  `label_source`. A row whose column-labelled cells are bare, four-digit calendar
  years without units supplies possible column-period evidence. Complete members
  retain non-annual labels such as totals; a number is not assigned a year yet.
  Decimal values, unlocated/duplicate coordinates, explicit units, ordinary data
  rows and mixed non-annual column labels do not create this axis.
- Projection attaches only a cell at the same column, with identical observed
  column-header paths, in the same document/hash/table/locator and a different
  physical row. No source ID, raw scalar, unit or existing period is changed.
  These attached axes confer no additional numeric operand authority or quota.
  Projection is independent of source list order and removes stale links when
  their source disappears. It does not search another document or fetch data.
- The Compiler selects nullable `interpretation.period_ref` from the exposed
  owner's finite options. Lowering checks selected-cell ownership. Internal
  `period_option_id` requires owned request references and the selected cell's
  complete column axis; absent fields preserve existing program projections.
  Code reads the selected annual label without accepting a model-written year.
- For an unresolved value with this column evidence, an attached prose quote
  cannot substitute for its column reading. Totals/non-annual columns have no
  annual option. Foreign-column refs, conflicting/ambiguous known periods and
  contradictory context fail without changing the selected candidate or request.
  Existing located relative-context behavior outside this new axis is retained.
- Validated direct/derived operands use a binding-local period resolution;
  original period/value-year and exact source/target cell identities remain in
  operand and answer-slot proofs. V2 fingerprints and revalidation bind the
  complete enriched catalog, chosen option and proof. Catalog values stay intact;
  historical catalogs are not silently enriched or remapped.

Physical linkage still does not certify that a label denotes the requested
measurement period. An anonymous `Catalog identifier` control can pass structural
validation after an authored interpretation of year-looking identifiers. It is
explicitly retained as a semantic boundary; no vocabulary rule hides that case.
