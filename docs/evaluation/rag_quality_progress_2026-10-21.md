# 검색 범위와 생성 모델에 따른 RAG 답변 품질 비교

2026-10-21. 11개 기업·77문항에서 검색 근거 수, 생성 모델, 평가 기준을 나누어
검토했다. 같은 새 기준을 적용한 답변 대상 46문항에서 완전 정답은
**Terra top-8 34/46 → Sol top-12 42/46**, 인용 근거 충실성은
**42/46 → 45/46**이었다. 모델과 문맥량이 함께 달라진 전체 비교이며,
아래의 같은 모델·같은 입력 비교로 각각의 관측을 구분한다.

모든 결과는 개발에 노출된 자체 평가셋에 대한 assistant의 원문 대조다.
독립 평가나 미노출 기업의 성능은 확인하지 않았다. 기존 답변과 점수는 보존했고,
이번 문서 공개가 제품 기본 모델·top-k·파서를 변경하지는 않는다.

## 같은 기준으로 비교한 전체 결과

77문항을 **일반 답변 46개, 거절 19개, 진단·보류 12개**로 나눴다.
완전 정답은 내용 정확성·필수 항목 충족·실제 인용 근거 지지가 모두 PASS인
답변이다. 거절과 보류를 정답률 분모에 합산하지 않는다.

| Terra top-12 | 36 (78.3%) | 39 (84.8%) | 68 (88.3%) | 18 | $2.152 |

Terra는 `gpt-5.6-terra`, Sol은 `gpt-6.1-sol`이며 reasoning은 모두 `low`다.
비용은 각 실행의 usage·cache read/write와 당시 동결 단가에 따른 추정액이다.
청구서 확정액이나 현재 가격표가 아니며, 수집·저장소 구축·이전 실험 비용은
포함하지 않는다. 두 모델 실행의 캐시 사용량이 달라 가격 차이만의 비교도 아니다.

- Terra top-8/top-12는 양쪽을 새로 생성하고 교차 실행했다. Sol top-8은 저장된
  Terra top-8과 **모델 ID를 제외한 실제 요청 전체가 77/77 동일**했다.
- Sol top-12는 저장 top-8과 비교했다. 모델·질문·caller scope·시스템 프롬프트·
  응답 형식을 유지하고 전달 근거를 늘렸다. 각 조건의 전체 평가 생성은 1회다.
- top-k는 문서 수 상한이다. 같은 **65,536 bytes** 제한으로 Sol top-12에서
  71문항만 실제 12개를 전달했고, 6문항은 6~11개를 전달했다.

## 실패가 발생한 단계를 먼저 구분했다

답변이 틀렸다는 사실만으로 검색이나 프롬프트를 바꾸지 않았다.
원문·청크, Dense/BM25 후보, RRF 순위, 실제 생성 요청에 전달된 근거,
답변과 인용을 차례로 연결해 누락 위치와 해석 오류를 구분했다.

| 관측한 문제 | 확인 방법 | 후속 실험과 관측 |
| --- | --- | --- |
| 필수 표가 후보에는 있지만 top-8 밖에 있음 | 후보 순위와 실제 입력을 대조 | 같은 Sol에서 top-12로 늘리자 영업권·배당·재고자산·영업비용 4문항이 완전 정답으로 전환 |
| 필요한 근거가 이미 있는데 대상·기간·비용 범위를 잘못 읽음 | 동일 근거를 고정하고 모델만 교체 | 실패 6문항 × 3회에서 완전 정답 Terra 3/18, Sol 16/18; 성공 대조 3문항 × 3회는 8/9, 9/9 |
| 숫자는 있으나 단위나 표의 주체가 연결되지 않음 | 실제 인용한 본문·행·열·단위 문맥 확인 | 단위가 있는 원문을 보충하자 배터리 부문 답변의 금액 단위와 비율이 함께 지지됨 |
| 정답 기준이 질문보다 많은 설명을 요구함 | 질문의 필수·선택 요구를 명시 | 저장 답변을 새 기준으로 재채점하고 기존 점수와 함께 보존 |

고정 근거 모델 비교는 의도적으로 고른 실패 6문항과 성공 대조 3문항이다.
18회 응답을 독립된 18문항으로 보거나 전체 평가셋의 성능으로 확대하지 않는다.
상각비에서 자산화 금액과 손익 비용을 구분하고, 신청 시점을 당기 성과로
옮기지 않는 차이가 확인됐다. [반복 비교 상세](reader_model_fixed_evidence_result_2026-10-20.md)

Terra top-12에서 회귀한 기존 기준의 5문항도 따로 추적했다. 같은 top-8 입력의
다른 출력에서도 발생한 오류, 근거는 읽었으나 인용을 연결하지 못한 오류,
추가 표를 선택하며 대상 범위를 잘못 해석한 오류가 섞여 있었다.
따라서 모두를 추가 문맥의 인과적 악영향으로 단정하지 않았다.

## 질문 분해와 하위 질문별 선택은 이번 설정에서 미채택

전체 77문항에 자동화했을 때 완전 정답은 **42/46 → 41/46**으로 개선되지
않았고, 비용은 **$2.515 → $12.065, 약 4.8배**였다. 개선 2개·회귀 3개였으며,
근거 충실성도 같은 46요청에서 **45/46 → 43/46**이었다. 후자는 생성 실패 1개를
미평가로 둔 수치이며, 생성된 45답변만 보면 43/45다. 비용의 **77.6%**가
근거 선택 호출에서 발생해 제품 기본 경로에 채택하지 않았다.

77개를 시도해 76개 답변을 얻었고, 1개는 하위 질문에 허용되지 않은 근거 ID를
선택해 생성 전에 거절됐다. 원래 중단 기록을 남기고 아직 시도하지 않은 11개만
별도 실행해 합산했으며, 이 완료 절차는 최초 사전 계획에 없었다. 실패를 재시도하거나
기준선 답변으로 대체하지 않았다. 분해·검색·선택·문맥 전달이 함께 달라진
단회 실험이므로 질문 분해 일반의 효용을 부정하는 결론으로 확대하지 않는다.
