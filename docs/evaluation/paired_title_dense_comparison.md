# 원래 입력·표제/기간 보존 입력의 Fresh Dense 2회 비교

2026-10-15 · `COMPLETE_REVIEWED_PAIRED_DENSE`

**C10의 필요한 값 표가 두 반복 모두 최종1위로 올라왔다.** Dense 전체 순위는 원래 입력30·32위에서 표제·기간 보존 입력6위, 최종 RRF는4위에서1위다. 값 없는 표제는 최종8개에서4→3개로 줄었지만, **Dense16에서는9개로 그대로**다. 부분적인 개선이며 표제 편중이 해소된 것은 아니다.

네 조건(A1·B1·A2·B2) 모두 기존12문항의 필수 근거가 충분했다. 각 반복의 A→B 근거 누락 회귀0건, 추가 근거 충분성 회복0건이다. N01·N04의 필수 출처 순위는 내려갔다. 답변 생성은 하지 않았으며, 이 결과는 답변 정확도 개선을 뜻하지 않는다.

## 고정한 비교 조건

[직전 중단 실행](linked_title_dense_ablation.md)은 그대로 보존하고, 사용자가 새로 승인한 **46회 호출·$0.317 상한**으로 별도 실행했다. 원본 연결이 확인된723개 값 청크에만 다음 차이를 둔다.

- **A:** 원래 canonical 입력을 새로 임베딩한다.
- **B:** 같은 입력 앞에 이전 실험의 원본 표제·기간 조각을 그대로 붙여 새로 임베딩한다.
- 각각2회 반복한다. 한 요청에32문서의 A/B64개를 함께 넣고, 반복1은 A/B, 반복2는 B/A 순서로 배치 위치를 균형화했다. 각 반복23회, 총46회다.

나머지1,517개 문서 벡터와12개 질문 벡터는 네 조건에서 동일한 기존 값을 재사용했다. 같은 모델 `text-embedding-3-large`,3072차원,원래 질문과 접수번호 필터,2개 보고서·2,240청크를 유지했다.

**BM25는 양쪽 모두 기존 표제·기간 보존 입력을 사용하고, 문서·질문의 정확한 `까지` 토큰만 제외한다.** `k1=1.5,b=0.75,epsilon=0.25`,BM2524,Dense16,RRF60/동일 가중치/top8,기존 키워드 접두어,canonical 답변 출처와65,536-byte 제한을 고정했다. Dense에는 원본 문자열을 넣으므로 `까지`를 문자열에서 삭제하지 않는다. 새 링크·파서·청킹·질문 변경은 없다.

주 비교는 동일한 scoped squared-L2 정확 검색이다. 기존 캐시의 Dense192개 후보는 이 정확 검색과 모두 일치했다. 별도로 네 조건마다 같은 설정의 새 실험용 Chroma를 만들어 ANN 차이를 확인했다. 기존 앱 store는 열지 않았다.

## C10: 필요한 값 표는 올라오고, Dense 표제 수는 유지

| 지표 | A1 원래 입력 | B1 보존 입력 | A2 원래 입력 | B2 보존 입력 |
| --- | ---: | ---: | ---: | ---: |
| 필수 연결 값 표 `104:5`의 Dense 전체 순위 | 30 | **6** | 32 | **6** |
| 같은 표의 BM25 순위 | 1 | 1 | 1 | 1 |
| 같은 표의 최종 RRF 순위 | 4 | **1** | 4 | **1** |
| Dense16의 값 없는 표제 | 9/16 | 9/16 | 9/16 | 9/16 |
| 최종8개의 값 없는 표제 | 4/8 | **3/8** | 4/8 | **3/8** |
| 필수 두 값·단위가 실제 packet에 존재 | 예 | 예 | 예 | 예 |

`104:5`는 원본 연결 현금흐름표의 영업활동 현금흐름 **35,544,145,039원**과 당기순이익 **617,510,076,654원**을 포함한다. 추가 입력은 원본의 `연결 현금흐름표`,당기·전기·전전기 날짜 범위와 단위 조각이다. 표제·기간·단위가 함께 들어간 조각의 효과이며, 각 요소의 독립 효과를 분리한 실험은 아니다.

BM25 점수68.409189는 네 조건에서 같다. A에서는 해당 표가 Dense16 밖이라 BM25 한쪽만 RRF에 기여한다. B에서는 Dense6위로 진입하면서 두 채널이 가산돼 RRF 점수가 약0.016393→0.031545로 올라간다. RRF 규칙이나 가중치를 바꾸지 않았다.

최종 순서는 두 반복에서 각각 동일했다. A의 선두는 값 없는 `400:295`,`748:261`,`395:290`이고, B에서는 `104:5`,`486:4`가 먼저 오며 세 표제는3·4·5위로 밀린다. `306:201` 표제는 최종7→9위로 빠진다. **Dense 단계에서는 같은9개 표제가 모두 남고 주당이익 표제가 여전히1위**다.

표제가 연결된 조정 상세표도 Dense 후보에는 들어온다. `401:296`은108→12·11위,`749:262`는336·342→10·13위다. 두 표는 BM2524 밖이므로 최종8개에는 들어오지 않는다. 또한 이 상세표의 값은 C10의 필수 피연산자를 대신하지 않는다.

별도 현금흐름표 `486:4` 역시 Dense25·24→9위,RRF6→2위로 올라온다. 연결 질문의 정답으로 인정하지 않았다. 따라서 이번 변화가 **값 표의 검색 가능성을 높였다는 근거는 있지만, 연결/별도 의미 구분까지 해결한 근거는 없다.**

A 반복의 최소 cosine은0.993389,B 반복은0.995210이고 최대 성분 절대차는 각각 약0.020370이다. 이번에는 이 수치를 중단 기준으로 쓰지 않고 순위·근거 효과를 측정했다. 벡터와 일부 Dense 순서가 달라도 **최종 packet과 A→B 효과는 두 반복에서 같았다.** 새 A 두 조건 모두 이전 캐시 기준과도 최종12개 packet이 동일하다.

같은 설정의 새 Chroma와 정확 검색은 Dense 후보 순서41/48,실제 packet47/48이 일치했다. 유일한 최종 차이는 B2의 C11이다. 정확 검색의8위 `72:4`(수주 상황의 해당사항 없음)가 native에서는 빠지고 `894:0`(경영 개요)가 들어왔다. 필수 출처 `70:2`,`71:3`은2·3위로 그대로였다. native 네 조건도 각각12/12 근거 충분,두 반복 모두 회귀0건이다. C10의 값 표1위·최종 표제4→3개 결과도 native에서 같다.

이는 인덱스 재생성 변동이 사라졌다는 뜻이 아니다. 주된 임베딩 효과와 ANN 차이를 나누어 기록한 결과다. 모델 버전 변경이나 특정 provider 내부 원인을 단정하지 않는다.
