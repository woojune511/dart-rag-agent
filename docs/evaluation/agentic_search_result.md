# 제한된 Agentic RAG 검색 비교 결과

2026-09-28. **6문항 완료, 생성21회·검색어 임베딩5회, 오류·재시도·NOT_RUN 0.** [실행 전 고정 설계](agentic_search_preparation.md).

최초 후보에 없던 근거를 추가 검색으로 찾아 답변을 회복한 사례가 있다. 그러나 충분하다는 오판과 기존 주의사항 누락도 관측됐다. 이번 결과는 검색 루프의 작동과 한 사례의 명확한 회복을 보여주며, 기본 앱을 Agentic RAG로 전환할 근거로 삼지 않는다.

## 구현과 비교 범위

실험용 단일 컨트롤러가 근거를 선택하고 부족한 정보와 다음 검색어를 JSON으로 반환한다. 코드는 동일 보고서 안에서 hybrid 검색을 실행하고 결과 원문을 다음 관측으로 제공한다. 최대2회 추가 검색 후 최종 선택 근거로 답변한다. 상태는 구조화한 ledger와 요청·검색·답변 파일에 기록했다. 회사명이나 정답별 runtime 분기, Planner/Compiler, 자동 산술 실행은 추가하지 않았다.

비교 대상은 같은 초기 LLM 선택과 답변을 공유하는 **고정 근거 기준선**이다. 검색을 요청한4문항만 새 답변을 생성하고, 멈춘2문항은 동일 답변을 공유한다. 이2개의 일치는 독립 생성 두 번의 재현성이 아니라 비교 설계의 결과다. 초기 프롬프트는 근거를 함께 읽었을 때의 충분성을 묻는다. 직전 실험의 개별 관련성 선택 프롬프트와 다르므로 이전12입력 점수와 직접 비교하지 않는다.

대상은 이미 분석한 표 구조 C의6문항이다. 후보 누락3, 기존 성공2, corpus 누락1을 의도적으로 골랐다. 미노출 평가나 전체77문항 성능 추정이 아니다.

### 셀트리온: 새 검색과 의미 선택이 함께 기여

모델은 `셀트리온헬스케어 흡수합병 주석 36 이전대가 취득자산 인수부채 영업권`을 검색했다. 기존 후보에 없던 `496:351`이 새 후보27위, `504:359`가12위로 들어왔다. 둘 다 단순 top8 밖이지만 컨트롤러가 최종 근거로 선택했다.

답변은 총 이전대가14,689,603,676천원, 식별가능 순자산3,231,827,332천원, 영업권11,457,776,344천원을 지지하는 표와 합병일·비율·목적을 인용했다. 최초 답변은 신주 대가13,262,925백만원을 전체 대가라고 잘못 부르지는 않았지만, 필요한 총액이 빠져 있었다. 이번 개선은 새 근거 회복이다.

### 카카오: 정보 추가와 주의사항 손실이 공존

새 검색은 기존 후보에 없던 취득 후 수익 표 `676:543`(새 후보3위), 취득 무형자산 표 `673:540`(5위), 사업결합 요약 `671:538`(2위)을 회복했다. 답변에 취득 후 수익756,966,101천원, 취득 무형자산 합계612,531,909천원 등이 추가됐다.

그러나 최초 답변이 인용했던 MD&A `1159:3`의 **전체 무형자산 감소** 설명은 최종 선택에서 제외됐다. 이 원문은 다음 관측에도 보였고 byte 제한으로 잘린 것이 아니다. 새로 선택한 `416:283`에는 영업권의 기초·기말 감소 표가 남아 있었으나 답변은 그 감소도 다루지 않았다. 모든 반대 근거가 사라졌다고 말할 수 없으며, 선택과 답변의 누락을 함께 봐야 한다. 원래 대표 근거인 뮤직 성장 설명 `36:0`은 이번에도 찾지 못했다.

카카오 판정은 요구 범위에 민감하다. 기존 rubric의 콘텐츠 성장 설명까지 요구하면 양쪽 모두 불완전하다. 현재 SM 매출과 취득 영업권을 명시하고 내부거래 제거 후 순증분은 확인할 수 없다고 한 기준선의 **대체 근거 답변**을 허용하면, 기준선은 감소 주의까지 포함하지만 검색 후 답변은 그 주의를 잃었다. 반대로 질문을 편입의 총증가 기여만 묻는 것으로 좁히면 검색 후 답변도 허용될 수 있다. 이를 숨긴 단일 정답률을 주 결론으로 사용하지 않는다.

### 삼성과 탄소배출권: 충분성 선언과 거절 플래그의 한계

삼성은 `연결재무제표 주석 우발부채와 약정사항 주요 소송 채무보증 충당부채 재무영향`을 검색해 충당부채·보증 내용을 추가했다. 그러나 웰스토리 `887:1`은 최초·추가 후보 모두에 없다. 컨트롤러는 충분하다고 선언하고 남은 검색1회를 쓰지 않았다. 최초 답변의 분할 전 채무 연대책임 설명도 최종 답변에서는 빠졌다.

탄소배출권은 표 corpus에 회계처리 원문 자체가 빠진 대조 사례다. 두 번의 검색 후에도 모델은 부족을 보고했다. 답변은 조회된 근거의 한계를 설명했고 없는 회계정책을 만들지는 않았지만, **두 답변 모두 `abstained=false`**다. 완전한 답변이나 구조화한 거절 성공으로 집계하지 않는다. 부족 설명과 거절 플래그는 별도 관측이다.

## 대응표와 판정 범위

corpus 누락 대조1개를 제외한5문항에서, 기존 rubric의 필수 내용 충족 기준은 기준선2/5, 검색 후3/5다. 둘 다 충족2, 검색 후만 충족1, 기준선만 충족0, 둘 다 미충족2다. 위 카카오 대체 근거 답변을 기준선 통과로 허용하면3/5→3/5이며, 대응표는 둘 다2, 검색 후만1, 기준선만1, 둘 다 미충족1이 된다. 카카오를 제외한4문항은2/4→3/4다. 이는 assistant 원문 대조 판정이며 독립 평가·통계적 우세·일반화 성능을 뜻하지 않는다.

검토한 원래 후보 누락 근거3개 중 정확한 대표 근거 회복은 셀트리온1개다. 카카오는 다른 유용한 취득 기여 근거를 추가했다. 근거 회복, 답변 완전성, 인용 지지, 모델의 충분성 선언을 구분한다.

기록된 단계 시간 합은 기준선66.08초, Agentic93.89초로 약1.42배다. 임베딩·추가 로컬 검색 시간은 포함하고, 공통 최초 검색은 저장 결과를 사용했다. 순차 실행과 메모리에 유지된 corpus/index의 영향이 있으므로 실제 앱의 종단 지연 측정은 아니다. 입력2.5/출력12달러 per1M, embedding0.13으로 계산하고 cache 할인을 적용하지 않았다. 관측 청구서가 아니라 [공식 가격](https://developers.openai.com/api/docs/pricing)에 근거한 보수적 추정이다.

## 검증과 다음 판단

- 실행 전 네트워크 차단 SDK rehearsal42회와10개 중단 control 통과.
- 최초6개의 저장 dense/BM25 결과를 정확히 재현하고, 추가 검색5개를 실제 반환된 query embedding으로 재현했다. 실제21개 생성 요청은 각 단계의 출처와 선택에서 다시 구성한 요청과 일치한다. 답변 packet 누락0, decision context 누락0.
- 보호된335개 파일과 별도 준비 seal 유지. production source, 기존 corpus/vector, 질문·rubric·기존 답변을 변경하지 않았다. 결과 봉인은 새 로컬 산출물에 별도로 남긴다.
- 이 검증은 실행 경계와 무결성에 관한 것이며 의미 정확도나 산술 실행의 증거가 아니다.

현재 기본 앱은 SimpleRagAgent로 유지한다. 다음 개선 지점은 **이미 충족한 요구와 주의사항을 다음 선택에서도 보존하는 근거 기록**, 그리고 그 기록을 기준으로 종료를 판단하는 방식이다. 이번 프로토타입은 선택 ID와 부족한 정보만 넘기므로 새 정보에 집중하면서 기존의 중요한 설명을 잃을 수 있었다. 후속 구현·비용 호출·전체77 재실행은 자동으로 진행하지 않았다.
