# 출처 선택 단일화 실제 실행: 첫 결정의 구간 길이 초과로 중단

2026-09-28. [고정 실행 계획](agentic_ledger_single_selection_live_preparation.md)에 따라
6문항 배치를 한 번 실행했다. **첫 문항의 결정 출력이 거절되어 완료0·ERROR1·NOT_RUN5**다.
답변 정답률이나 Agentic RAG 품질 개선을 평가할 결과는 없다. 출력 보정·재시도·resume은 하지 않았다.

## 관측된 실패

첫 카카오 문항의 provider 응답은 정상 완료됐고 JSON 스키마도 통과했다.
모델은 원장에6개 참조, 중복 제거 후5개 출처를 선택했다. 모든 출처는 실제 입력에
있고 지정한 보고서에 속한다. 기존의 중복 `selected_ids` 불일치는 발생하지 않았다.

단서 하나가 아래 길이 제한을 넘었다.

| 항목 | 실제 값 |
| --- | --- |
| 출처 | `20240418000375:146:13` |
| 선택 역할 | 첫 요구사항의 qualifications |
| 원문 조각 | 총12개, 번호0~11 |
| 모델 선택 | piece_start=1, piece_end=11 |
| 선택 길이 | 양 끝 포함11개 |
| 계약 한도 | 한 참조당 최대8개 |
| 결과 | `invalid source range`로 거절 |

시작·끝 좌표는 모두 존재한다. 실패는 미등록 출처나 범위 밖 좌표가 아니라
**유효한 원문에서 너무 긴 연속 구간을 선택한 것**이다. 고정256문자 조각 표시와
코드 검증은 그대로 적용됐다. 다른5개 참조는 물리적 구간 검증을 통과했다.
이 검증은 각 note의 의미가 정확하다는 판정이 아니다.

모델은 partial 상태로 추가 검색을 요청했으나 원장 검증에서 중단되어 검색 질의를
실행하지 못했다. 최초 답변도 생성하지 않았다. 기존 카카오의 단서 보존, 삼성의 검색
누락, 셀트리온의 충분성 판단이 개선됐는지는 이 실행으로 확인할 수 없다.
