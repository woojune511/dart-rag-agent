2026-10-20, `gpt-6.1-sol`의 기본 top-8 답변을 77문항에서 각 1회 생성하고 전부 검토했다. 같은 날 저장한 Terra top-8과 비교하면, 공통 답변 대상 48문항의 **완전 정답은 33/48(68.8%) → 35/48(72.9%)**, 인용 근거 충실성 PASS는 **44/48(91.7%) → 46/48(95.8%)**였다. 완전 정답 전환은 개선 2개, 회귀 0개다. 거절은 양쪽 모두 18/19다.

관측된 개선은 작다. 셀트리온 상각비의 비용·자산 배부 구분과 NAVER CAPEX 증감률의 표시 정밀도가 좋아졌지만, 필수 항목 충족은 양쪽 모두 36/48로 같았다. 검색 결과에 없는 핵심 금액을 모델 교체로 복구하지는 못했고, 이미 주어진 AUM 표를 답변에 활용하지 못한 사례도 남았다.

이번 실행의 usage 기반 추정 비용은 **$1.895297**, 생성 시간은 **661.12초(약 11분)**다. 승인한 $5 한도 안에서 77회로 종료했다. 기본 모델·검색 설정은 변경하지 않았다.

## 평가 분모와 기준

전체 77문항을 모두 생성했지만, 정답률은 기존 판정을 그대로 이어 **일반 답변 48개 / 거절 19개 / 진단·보류 10개**로 분리한다. 77/77은 실행 완료율이다.

- 완전 정답: 내용 정확성, 필수 항목 충족, 인용 근거 충실성이 모두 PASS.
- 근거 충실성: 중요 사실 주장이 인용한 모델 입력의 원문·구조 문맥으로 지지되는지 검토한다. 출처 ID가 존재하는 것과 의미가 맞는 것은 다르다.
- 안전한 부분 답변도 요청한 핵심 금액을 빠뜨리면 완전 정답으로 세지 않는다.
- 기존 참고답안·판정·질문별 예외 기준을 보존했다. 새 결과에 맞춰 분모나 기준을 바꾸지 않았다.
- 수치와 단위는 생성 후 Decimal 계산과 원문 대조로 검토했다. 이 검토가 기본 앱의 계산·의미 검증 기능이라는 뜻은 아니다.

보류 10개는 `KBF_T1_017`, `POS_T1_075`, `POS_T2_058`, `HYU_T3_036`, `KAK_T3_055`, `SKH_T2_061`, `MIX_T3_063`, `SAM_T2_027`, `CEL_T2_073`, `HYU_T2_035`다. 정확성·완전성은 판정하지 않고 실제 답변 주장의 근거 지지만 별도로 검토했다.

이번 Sol 비용은 Terra 저장 실행보다 약 10.6% 높았지만, 모델 단가 외에 cache read가 없고 cache write가 많았던 영향이 크다. 이를 모델의 일반적 비용 배율로 해석하지 않는다. Sol 생성은 평균 약 2.1배 오래 걸렸지만, 실행 시점·서버·캐시·출력 길이가 통제된 속도 벤치마크는 아니다. 전체 11분에는 실행 중 관리 비용이 포함되고, 사후 수동 검토 시간은 제외된다. 서비스 검색을 포함한 end-to-end 지연도 아니다.

입력 패킷 한도 65,536 bytes 및 출력 상한 8,192 tokens는 실제 사용량과 별개다. 원래 패킷 제한으로 `SKH_T1_060`은 7개, `MIX_T3_063`은 6개 source가 전달되었으며 이 구성도 그대로 고정했다.
