## 결론과 설계 결정

**이번 문제 세트에서는 독자적인 근거 선택 기법을 설계할 필요성이 확인되지 않았다.**
일반 의미 선택과 SETR 기반 집합 선택 변형이 모든 18입력에서 동일한 문서 집합을
선택했다. 필요한 근거가 제공된 12입력에서는 양쪽 모두 요구 근거를 전부 유지했다.

차이는 근거가 제거된 배당 사례 1개의 충분성 선언뿐이다. 집합 선택 변형은 부족을
인식했고 일반 의미 선택은 잘못 충분하다고 판단했다. 선택 문서 집합은 이 사례에서도
같았다. 이를 집합 선택의 retrieval 개선이나 자체 기술의 기여로 주장하지 않는다.

사전 조건인 서로 다른 질문 2개 이상의 공통 반복 실패는 관측되지 않았다.
따라서 **이 패널을 근거로 새 reranker·범위 규칙·Compiler를 구현하지 않는다.**
실패를 만들려고 사후적으로 질문을 어렵게 바꾸거나 프롬프트를 조정하지 않았다.

순서를 제외하면 18입력 모두 두 방식의 선택 집합이 같다. 모든 완전 후보 입력에서 올바른 출처를
유지했고 불필요한 출처는 선택하지 않았다. 근거가 제거된 경우에는 남아 있는
관련 근거만 선택하거나 다른 주식 종류의 배당 발췌도 함께 선택했다.

6질문의 세 조건을 비교한 것이므로 18개의 독립 질문으로 보지 않는다. 이 표는
작성된 주석에 대한 **근거 선택과 충분성 판단** 결과다. 답변은 생성하지 않았으며
숫자·산술·요약 정확도, 유해한 설명 생성, 제품 정답률은 평가하지 않았다.

## 유일한 불일치: 배당 근거 부족

입력 `p_ee0ef23c888d`는 현대자동차 2022년 보통주와 2우선주의 중간배당 및
연차배당(예정)을 합산하는 질문이다. 원본 연차배당 표를 제거한 조건이다.

양쪽 선택은 동일했다.

- `e_c0a9306f4de6c53e`: 보통주·2우선주를 포함한 중간배당 주당 1,000원 표.
- `e_39a06cc702532cef`: 우선주/3우선주 연간 배당 7,050원 발췌.

두 번째 발췌에는 요청한 보통주와 2우선주의 연차배당 예정액이 없다. 나머지 후보의
주당이익, 이익잉여금 처분 총액, 리스비용, 연구개발비도 이를 대체하지 못한다.
원본 연차배당 표는 보통주 6,000원·2우선주 6,100원을 담지만 해당 입력에 없다.

일반 의미 선택은 `pool_sufficient=true`, `selected_sufficient=true`를 반환했다.
집합 선택 변형은 두 값을 false로 반환하고 보통주·2우선주의 연차배당 예정
주당 금액이 없음을 명시했다. 원문 검토상 후자의 판단이 맞다.

이는 **근거 충분성의 오판**이다. 모델이 잘못된 7,050원을 계산에 사용했다고
단정할 수는 없다. 답변 생성과 숫자 선택을 수행하지 않았기 때문이다.
단일 응답 차이로 안정적인 우열이나 원인을 입증하지도 않는다.

## 원문 의미 검토

원본 HTML의 발췌 및 문맥 연결을 재검증하고 선택 결과를 기준 근거와 대조했다.
주석 변경이나 동등 근거로 인한 재채점은 없다. 나머지 부족 조건에서는 양쪽 모두
실제 빠진 당기/전기/별도 금액을 부족 정보로 지목했다.

완전 후보에서 기간 간 비교(P01/P05), 연결·별도 비교(P03), 영업·재무활동의
요청된 합산(P06)을 이유로 한 과잉 거절은 관측되지 않았다. 필요한 출처의
보존과 충분성 수락을 확인한 것이며, 최종 답변에서의 정확한 해석까지 검증한 것은 아니다.

평가자는 질문·주석을 작성한 assistant다. 독립 gold나 blind human review,
미노출 holdout이 아니다. 후보도 실제 검색 결과가 아닌 원문 발췌 6개다.
두 방식에는 충분성 보고 지시가 공통으로 들어가며, SETR 원형을 재현하지 않았다.
이 결과를 실제 RRF top-8 교체의 효과로 일반화할 수 없다.
