2026-10-15. **COMPLETE_OFFLINE_DISPOSITION**. 기존 질문·정답·답변·점수는 수정하지 않았다.

[근거 용량 감사](evidence_capacity_audit.md)에서 보류한 7문항을 향후 평가에서 어떻게 다룰지 고정한다. 이 문서는 새 정답 데이터셋이나 재채점 결과가 아니다. 확인되지 않은 원문 관계를 가정해 통과·실패로 바꾸지 않는다. 이번 새 보고서 진단 (로컬 기록: `reader_evidence_diagnostic_preparation.md`)에는 아래 문항이 들어가지 않는다.

후속 버전은 원본 질문 ID를 덮어쓰지 않고 새 ID와 `supersedes`를 사용한다. 질문, 필수 요청 항목, 원문 인용 구간, 대상·기간·단위, 계산식·정밀도, 허용되는 대체근거, 미확정 처리 기준을 실행 전에 함께 고정한다. 의미가 같은 다른 근거를 사용할 수 있지만, 질문에 없던 예시 답안의 세부사항을 필수 요청으로 올리지 않는다.

평가 축은 ① 입력 근거 충분성, ② 핵심 내용 정확성, ③ 명시적 요청 충족, ④ 필수 주장 인용 지지, ⑤ 추가 주장 인용 지지, ⑥ 거절 여부, ⑦ 실행 상태로 분리한다. 인용 ID 유효성은 의미적 지지의 증거가 아니다. `UNDETERMINED`를 임의로 실패나 성공으로 합산하지 않고, 원문 분모와 보류 수를 함께 보고한다.

위 처분은 기존 감사의 사실관계를 사용한 평가 계약 정리다. 새 모델 호출, 7문항 전체의 독립 원문 재감사, 기존 점수 개선을 수행하지 않았다.
