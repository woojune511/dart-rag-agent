# C11 질문의 내수 세 분류 열거 삭제 비교

2026-10-15 · `COMPLETE_SOURCE_REVIEWED` · C11 한 문항의 별도 진단

**홈쇼핑을 온라인 아래에 넣은 답변은 원래 질문2/2, 삭제 질문1/2였다.** 삭제 질문의 두 번째 답변은 홈쇼핑을 유지하면서 원문처럼 병렬로 나열했다. 네 답변 모두 기존 필수 항목을 포함했고, 누락으로 오류를 회피한 경우는 없었다. 한 반복에서만 개선됐으므로 안정적인 해결이나 일반적인 오류율 감소로 판정하지 않는다.

[직전 분석과 실험](reasoning_high_comparison.md)에 사용한 C11의8개 검색 문서·본문·출처 ID·순서·context·명시적 receipt scope를 고정했다. 질문을 바꿔 재검색하거나 임베딩하지 않았다. 변경한 것은 답변 모델에 전달되는 질문의 아래 한 구절뿐이다. 수출 경로와 판매방법·대금회수 요청은 그대로 유지했다.

원래 질문:

> 코웨이 사업보고서에 나온 내수와 수출 판매경로를 구분해 설명해 줘. 내수는 방문판매·오프라인 유통·온라인 채널, 수출은 현지법인·해외 제휴선·ODM을 포함하고, 판매방법과 대금회수 방식도 함께 알려 줘.

삭제한 정확한 구절은 `내수는 방문판매·오프라인 유통·온라인 채널, `이며 끝의 공백도 포함한다. 수정 질문:

> 코웨이 사업보고서에 나온 내수와 수출 판매경로를 구분해 설명해 줘. 수출은 현지법인·해외 제휴선·ODM을 포함하고, 판매방법과 대금회수 방식도 함께 알려 줘.

생성은 원래 `ANSWER_INSTRUCTIONS`, `gpt-5.6-terra`, reasoning `low`, 출력 상한8192, strict `RagAnswer` schema, default tier, `store=false`, explicit prompt cache를 유지했다. 분류 금지 문장을 추가하지 않았다. temperature·seed·reasoning mode는 기존처럼 미지정이며 반환 effort는 모두low, mode는 모두standard였다. 원래1회→삭제1회→삭제2회→원래2회 순서로 **네 답변 모두 새로 생성**했다.

삭제1회는 내수를 방문판매·시판 유통·온라인·직영 매장의 네 항목으로 나눴다. 그러나 온라인 제목 아래에 홈쇼핑을 넣는 관계는 남았다. 추가한 직영 매장의 제품·브랜드 체험 설명은 실제 인용한71:3이 지원한다. 삭제2회는 다음과 같이 답했다.

마지막 두 줄은 항목을 함께 나열하며 새로운 상하위 관계를 선언하지 않는다. 홈쇼핑도 유지됐으므로 이 응답의 개선은 생략에 의한 것이 아니다. 수출의 현지법인·제휴선·ODM, 렌탈·일시불·멤버십, 현금·지로·카드이체·어음도 모두 남았다. 원래 질문 두 답변과 삭제1회도 이 필수 사실은 전부 포함했다.

실행 전에 기존 gold의4개 요구 그룹을 그대로 고정하고, 이를 내수5항목·수출3항목·판매방법3항목·대금회수4항목의15개 세부 확인 항목으로 풀어 기록했다. 내수의 첫 항목은 코디·홈케어 조직을 통한 방문판매다. 양쪽을 같은 기준으로 검토했으며 삭제 질문의 요구 수준을 낮추거나 이전 점수를 수정하지 않았다. 홈쇼핑 언급 여부는 별도 확인해 삭제를 성공으로 세지 않도록 했다.

원본 XML의 내수·수출·판매방법·대금회수 문장4개와 전달된 청크의 일치를 재확인했다. 필수 근거70:2와71:3은 네 답변 모두 인용했다. 삭제1회는69:1도 인용했으나 이 문서는 홈쇼핑의 온라인 하위 관계를 제공하지 않는다. 각국 법인 목록도 원문에 있으며, 추가 관계의 지원 여부를 출처 ID 유효성과 구분했다.

**가설 해석:** 내수 세 분류를 제거하면 병렬 나열로 답할 수 있다는 사례는 확보했다. 그러나 삭제 후에도 같은 오류가1회 남았고, 개선도1회뿐이다. 이 관측은 질문의 분류 유도 가능성과 일치하지만 표본 변동을 배제하거나 질문을 유일 원인으로 확정하지 못한다. 검색1위69:1의 방문판매·시판 유통·온라인 나열과70:2의 표현은 그대로이므로 문서 표현의 영향도 분리하지 않았다. ‘이 구절만 제거하면 항상 해결된다’는 주장은 뒷받침되지 않는다. 별도 질문 수정 규칙이나 제품 프롬프트를 채택하지 않았다.
