# 새 18문항: Qwen3-Reranker-0.6B와 현재 RRF 비교

2026-10-15 · `COMPLETE_SOURCE_GATE_NOT_MET` · 외부 모델 API **0회 / $0**

**622쌍을 각각 한 번 평가했다. HD 경영진단 원인은 복구했지만, 기존 필수 근거를 모두 보존하는 조건은 실패했다. 현재 RRF를 유지한다.** U15의 필수 근거는 유지됐고, U08·U09·U14에서 확정 회귀가 발생했다. U16의 현재 현금은 추가 복구했으나 상환액 비교는 여전히 불완전하다.

이 결과는 **최종 8개 원문의 근거 충족도**다. 답변 생성·정확도·출처 충실도 평가는 `NOT_RUN`이며, 과거 답변 점수를 바꾸지 않았다. 동일 assistant가 기존 평가 기준으로 검토했고 독립적인 사람·별도 agent 검토는 수행하지 않았다.

## 주요 개선과 회귀

**HD U04:** `20260316000940:1128:1`이 RRF11위에서 Qwen2위로 들어왔다. “중동과 미주시장 매출증가 및 수익성 개선”을2025 연결 매출·이익 변화에 연결한 본문이 그대로 전달된다. 이는 지정 근거의 복구다. 과거 넓은 질문에 대한 답변U 판정을 P로 바꾸거나 새 답변 개선으로 계산하지 않았다.

**U08:** 매출 표 `78:2 / 79:3 / 82:6`이 각각22/26/25위로 밀렸다. 국가 설명과 지역분류 정의 `159:35`는 남지만, 그 기준으로 보여줄 매출값이 없어 U08.2가P→F다. 이미F였던 U08.1도 기존의 부분적인 법인 금액을 잃었다. 1위의 한국 김 수출 시장 규모는 오리온 해외 매출이 아니다.

**U09:** 연결 이익을 제공하던 `920:0`이34위, 대체 손익표 `925:1`도8위 밖이다. 상위의 현금흐름 시기 설명·전기902백만원 재분류·현금흐름 표제는 실제2025/2024 영업현금흐름 총액이 아니다. 법인별 별도 재무현황이나 향후5년 추정이익률도 요청한 연결 실현 이익을 대체하지 못한다.

**U14:** 부문 손익을 제공하던 `45:1 / 1019:1`이24/28위로 밀렸다. 전사 손익표와 호텔&레저의 사업 범위 정의만 남아 TR 손실·호텔&레저 이익의 비교를 완성할 수 없다. 정의만으로 값과 범위의 연결을P로 보지 않는 것은 U08과 같은 기준이다. 이전 CC/DBSF와 달리 상충하는 `1017:0` 서술을 새로 추가하지는 않았지만, 부문 수치 자체를 잃었다.

**U15:** 수요 원인 `1020:2`는3위, 손익표 `1019:1`은6위로 보존됐다. 기존P인 U15.1과 이미F인 U15.2 안의 손익 방향은 추가 손실되지 않았다. 공항 위약금 원인의 지정 원문 `1017:0`은 이 문항 후보에 없다. 날짜만 있는 사채표제는 최종8개에 없지만, `927:402 / 542:17 / 806:281 / 385:301`이라는 다른 값 없는 표제4개가2/4/5/8위를 차지했다. 표제 편중의 일반적인 해결은 아니다.

**U16:** `1026:0`이1위가 되어 현재 연결 현금 **3,383억원**이 복구됐다. 원문 `original:2359~2362`에서 연결 범위·억원 단위·2025말을 확인했고, gold의338,290,693,972원은3,382.90693972억원으로 이 표시와 일치한다. 그러나 기존1년 차입금·사채 부분 근거 `59:5 / 489:405 / 1030:4 / 459:375`가 모두 밀렸다. 새 이자비용 표와 전체 차입금12,869억원은1년 내 원금·리스 상환액이 아니다. 현금 회복과 기존F그룹 내부의 추가 손실이 동시에 발생했다.

## 판정 민감도와 설명 정정

**U03.2는 U로 남겼다.** 기존 연결 지역별/제품별 근거는 빠지고 별도 지역표 `838:239`가 남았다. 연결 지역 값의 동등한 대체는 아니지만, 질문은 연결 범위를 명시하지 않았고 gold는 근거 있는 지역/사업 해석을 허용한다. 별도라고 구별한 설명까지 인정할지 사전에 명확히 고정되지 않았으므로 결과를 본 뒤 강제P/F로 확정하지 않았다. 별도 기준도 허용하면 **24P/9F, 완비13/18**, 불허하면 **23P/10F, 완비12/18**이다. 어느 해석에서도 U08·U09·U14의 확정 회귀 때문에 사전 조건은 실패한다.

현재 원문 재검토로 이전 설명 두 가지를 정정한다. 원래 산출물·gold·질문·답변 점수는 덮어쓰지 않았다.

1. 준비 문서의 “후보에 현재 현금이 없어 복구할 수 없다”는 U16 설명은 과도했다. 정확한 원 단위 표와 별개로 **기존 후보에 유효한 억원 반올림 요약표가 있었다.** 원래 gold의 반올림 허용 규칙으로P가 되며, 평가 기준을 완화한 것이 아니다. 기존 RRF 최종8개에는 이 표가 없어 그F는 유지된다.
2. 이전 CC/DBSF 검토에서 `637:105`를 같은3,500원 배당의 보강으로 설명한 주석은 부정확했다. 실제로는 전기2,500원이고, 당기3,500원 처분표는 `636:104`다. 기존 `874:5`가 당기3,500원을 제공하므로 이전 필수 그룹P와 합계는 바뀌지 않는다. 이번에는 전기 표가2위여서 기간 혼동 가능성을 별도 기록한다.

## 필수 그룹 외의 손실과 한계

- U10의 영향·대응·FX 민감도는 유지되지만, 해외 원재료의2025/2024/2023 가격표 `55:2`는9위로 빠졌다. U12의 정량 FX 민감도 `931:7`은23위로 빠졌다.
- U01·U02·U06·U13에는 연결 전사 수치를 대신할 수 없는 별도/부분 매출·손익 자료가 추가됐다. U11·U17에는 전기 배당 자료가 추가됐다. 실제 답변이 이를 혼동했는지는 평가하지 않았다.
- U18은 필요한 경고와 실적을 보존하지만,1위는2026 자기주식 계획의 기간만 있는 표제다. 사채 만기일·리스 만기 표제는 흑자 전망 근거가 아니다.
- 모든 입력은 무절단으로 평가했고 점수·순위·출처를 재구성했다. 이번 손실은 저장 후보의 최종 선택 결과에서 관측됐다. 모델 크기, 한국어 이해, 입력 접두어, 짧은 표제 선호 중 무엇이 원인인지는 이 단일 비교로 분리되지 않는다.
- 이18문항은 assistant가 실사용 상황을 가정해 만든, 이미 여러 비교에 노출된3개 보고서의 개발 평가다. 일반 사용자 정확도나 모든 reranker의 성능으로 일반화하지 않는다. 실제 답변 생성과 독립 holdout은 미실행이다.
