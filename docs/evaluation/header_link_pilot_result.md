# 동일 근거의 헤더 연결 명시: 첫 실험 결과

2026-09-29. **64/64 생성 완료, 오류·재시도·NOT_RUN 0.**
[실행 전 설계](header_link_pilot_preparation.md).

**현재 표현 A와 헤더 연결을 추가한 B 모두 긍정 12/12, 부족 통제 4/4를
두 번의 반복에서 충족했다. 이 표본에서는 추가 효과를 판별하지 못했다.**
B는 입력 토큰이 17.4%, 보수적 추정 비용이 14.5% 늘었다. 새 보고서 검증으로
넘어갈 안정적 개선 문항이 0개이므로 이번 단계에서 종료한다. 기본 앱 적용,
프롬프트 보정, 추가 유료 실험은 수행하지 않았다.

## 비교 범위

LG에너지솔루션·POSCO홀딩스·SK이노베이션·카카오뱅크의 익숙한 2023 보고서에서
긍정 문항 12개를 새로 작성하고 4개의 의존적인 근거 제거 통제를 만들었다.
모든 문항과 기준은 유료 응답 전에 고정했다. 새 회사/보고서·무작위 표본·독립
골드·학습 미노출 평가는 아니다. 반복 응답도 독립 질문으로 세지 않는다.

필요 근거와 혼동 자료를 미리 제공하는 **고정 context 읽기 진단**이다. 검색
성능이나 실제 RAG 전체 정확도를 평가하지 않는다. 원문 청크·출처·순서·질문·
모델·답변 프롬프트·출력 계약은 동일하다. B에만 기존 헤더에서 생성한 열 위치와
헤더 경로를 추가했다. 정답 셀 강조, 연도 변환, 계산기, 추가 검색은 없다.

조건명을 가린 64개 답변 전체를 고정 원문과 대조하고 판정을 저장한 뒤 조건별
집계를 수행했다. 질문 작성과 검토를 같은 assistant가 했으므로 독립 평가나
완전한 맹검이라고 주장하지 않는다. 이번에는 애매한 정답 기준의 사후 수정이 없다.

검증했다는 뜻이 아니다. 비계산 문항의 계산 축과 거절한 요청의 숨은 피연산자

## 대표 관측과 남는 한계

- **기간·열 대응:** 건물의 두 기말 장부금액, 자기주식 처분 시작일별 이행수량,
  SK온의 연도별 매입액, 카카오뱅크의 기수별 기업대출금 이자율을 양쪽 모두
  올바르게 선택했다. 기존 표·메타데이터만으로도 이 문항들은 풀 수 있었다.
- **범위:** 비상장과 전체 종속회사 수, SK지오센트릭과 SK에너지의 매출,
  용도별 대출금과 평균잔액을 양쪽 모두 구분했다.
- **단위·미기재:** 포스코디엑스 계약의 금액 열과 수량 열을 구분하고 수량의
  `-`를 0으로 단정하지 않았다. 카카오뱅크의 평균잔액/구성비/이자금액/이자율도
  양쪽 모두 구분했다.
- **H16의 거절 형태:** 용도별 대출금 근거를 제거하자 모든 응답이 요청값은
  확인할 수 없다고 거절했다. 다만 평균잔액 329,478/5,263억원과 그 차이
  324,215억원을 참고로 덧붙였다. 모두 인용 근거가 있고 요청한 값과 다르다고
  명시했으므로 고정 기준상 통과다. “거절하면 다른 숫자도 전혀 제시하지 않음”을
  검증한 결과는 아니다.

이번 표본은 열 위치를 복원할 수 있는 표를 선택했고 질문도 대상·기간·단위를
명시했다. 기존 표현의 만점으로 인해 표현 차이를 구분하기 어려운 **천장 효과**다.
기수에서 달력 연도를 추론하는 원래의 오독 사례, 헤더가 끊긴 청크, 불규칙 표,
대규모 검색 후보와 복합 서술 누락까지 해결됐다는 뜻이 아니다. B의 효과가 없음을
일반적으로 증명하지도 않는다.

## 종료와 산출물

진입 기준은 안정적 B 개선 최소 2문항, 안정적 회귀 0, 부족 통제의 부당 수치
답변 증가 없음이다. **개선 0문항이므로 미충족**이다. 이번 효과를 근거로 새
보고서 실험이나 제품 적용을 진행하지 않는다. 계산 오류도 이번에는 관측되지
않았으며 검색을 실행하지 않았으므로, 계산기·추가 검색의 가치에 대한 새 결론은 없다.

`benchmarks/results/header_link_pilot_2026-09-29/`에 질문·rubric·원문·적격성 검토,
질문 독립적인 변환 코드, XML 대조, 고정 요청과 비용 manifest, mock/오류 통제,
64개 live 원시 응답, 조건명 가린 평가 및 매핑, 판정·집계·봉인을 남겼다.
실험 산출물은 ignored 상태이며 기본 앱·공개 API·이전 실험 원시 기록은 그대로다.
