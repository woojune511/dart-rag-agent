> 실행 당시의 판정과 조건을 보존한 기록입니다. 후속 재채점과 전체 비교는 [최신 종합 보고서](rag_quality_progress_2026-10-21.md)를 참고하세요. `benchmarks/results/` 경로는 공개 파일이 아닌 로컬 증거 위치입니다.

평가일: 2026-10-18 KST. **77문항을 각각 1회 완료했다. 실제 호출은 154회, usage 기준 추정 비용은 USD 1.92034669로 승인 상한 308회·USD 21.10 안에서 끝났다.** 별도 v12 store 복사본을 사용했고, 실행 중 모델·검색·프롬프트를 바꾸지 않았다.

과거에도 있던 출처 한계 2건을 양쪽에 같은 기준으로 반영하면 종합 통과는 28→30이다. 이는 기존 판정의 보완을 포함하는 보조 비교이며, 과거 공식 기록을 덮어쓰거나 30/54와 30/48의 분모 차이를 개선으로 계산하지 않는다. 이번 평가 후 추가 수정·재실행·앱 재시작·커밋은 하지 않는다.

## 3. 정확성·필수 항목·출처·거절 비교

`P/부분/F`는 PASS/PARTIAL/FAIL이다. 종합 통과는 정확성·필수 항목 충족·출처 지지가 모두 PASS인 경우다. 출처 지지 PASS인 부분 답변도 필수 항목을 빠뜨리면 종합 통과하지 못한다.

이번에 발견한 양쪽 공통 출처 한계는 다음 두 가지다. 과거 원시 답변과 기존 review 파일은 수정하지 않았다.

- `SKI_T1_068`: EBITDA·자산 숫자는 원문과 맞고 비율 30.6%도 맞다. 그러나 양쪽이 인용한 표의 텍스트·문맥에는 금액 단위가 없고 `unit_hint`는 `%`뿐이다. 전달됐지만 인용하지 않은 다른 자료에 단위가 있다는 사실은 해당 인용의 금액 단위 지지를 대신하지 못한다.

과거 저장 판정과 비교하면 종합 통과 전환은 개선 3/미통과 전환 3이다. 위 공통 한계를 양쪽에 적용하면 **개선 3, 통과→미통과 1, 양쪽 통과 27, 양쪽 미통과 17**이다. 이 1개는 종합 PASS의 전환 수이며, 이미 미통과였던 문항의 정확성·검색 악화까지 없었다는 뜻은 아니다.

## 7. 해석과 종료

확인된 사실은 일부 필요한 표·회계정책 근거가 복구돼 답변 3개가 통과로 바뀌었고, 필수 항목 미충족이 감소했다는 것이다. 동시에 대상·기간·비용 범위 오독, 이미 전달된 요청 항목 누락, 근거 없는 부연이 남았다. source ID 검사 성공은 이 오류를 걸러내지 못한다.

이 데이터셋은 직접 구성했고 개발 과정에 반복 노출됐다. 독립 holdout도, 독립 사람의 blind 평가도 아니다. 문항마다 이번 1회와 과거 1회만 비교하므로 생성 변동을 추정할 수 없다. 평가 계약 보류 10건, 사후 발견된 공유 출처 한계 2건, 누적 구현·store 변화도 해석에 포함해야 한다. `HYU_T3_011`의 엄격한 요약 항목과 `MIX_T3_023`의 회계처리 요구를 느슨하게 읽으면 판정이 달라질 수 있으며, 이번에는 동결된 주 기준을 유지했다.

현재 구현의 종합 통과율이 크게 올랐다는 근거는 확보하지 못했다. 이번 기록을 현재 제품의 성능과 한계를 보여 주는 최종 측정으로 남기고, 추가 튜닝 없이 작업을 종료한다.
