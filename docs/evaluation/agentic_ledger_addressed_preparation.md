# 위치 선택 기반 근거 기록: 로컬 준비 완료

2026-09-28. [첫 ledger 실험](agentic_ledger_result.md)은 모델이 원문 공백을 수정해 생성1회 후 중단됐다. 이 문서는 별도 수정본의 **무호출 준비 결과**다. 새 provider 호출0, 실제 답변 품질 평가는 NOT_RUN이며 기존 실패 배치를 재시도하거나 resume하지 않았다.

## 구현

모델용 각 출처를 고정256문자 조각으로 표시한다. 조각 번호는 해당 출처 안의0 기반 위치이며, 분할·결합 과정에서 글자·공백·개행을 바꾸지 않는다. 회사/질문/재무 항목별 분할 규칙은 없다. 조각 경계는 의미 경계가 아니므로 모델은 필요하면 인접 조각을 함께 읽는다.

모델은 원문 문장을 출력하지 않고 `source_id`, `piece_start`, `piece_end`, 짧은 해석 note를 선택한다. 같은 출처의 연속 조각 최대8개만 허용한다. 코드는 해당 원문을 그대로 복사하고 출처 fingerprint와 문자 범위를 붙여 답변 입력에 전달한다. 모델의 note/요구사항/status는 검증되지 않은 의미 해석이며, 물리적 연결 검증과 분리한다.

이전 요구사항 ID·문구 보존, 변경 이유, 근거 출처의 선택/가시성, 누락된 출처를 인용하는 답변 차단, 종료 상태의 내부 일관성 검사는 유지한다. 모델의 quote 문자열을 받던 구 schema는 거절한다. 과거 실패 인용을 정규화·검색·추정해 새 위치로 자동 변환하지 않는다. 이전 원시 응답은 여전히 거절된 기록이다.

출처 제시 형식이 바뀌고 답변 packet에 코드가 복사한 인용이 추가되므로, token 수·문서 누락·의미 선택 결과도 바뀔 수 있다. 원문 복사 실패를 코드 구조상 제거한 것과 실제 모델이 올바른 위치를 선택하는 능력은 다르다. 범위가 유효해도 의미가 틀릴 수 있다.

## 완료한 검증

- 기존6문항의 최초 dense/BM25 검색 결과 정확 재현.
- 네트워크 차단 SDK 최대 경로42회 모의 실행과15개 중단 control 통과.
- 추가16개 상태/범위 검증 통과: 음수·역순·범위 초과·과도한 조각 수·boolean 위치,
  과거 quote 형식, 요구사항 삭제/변경, 미선택 출처, 근거 없는 covered 상태 등을 검사했다.
-6입력에 포함된 고유 출처5,239개를 조각에서 정확하게 재구성했다. 별도 Unicode/CRLF/tab fixture도 무손실이다.
- 실제 실패 원문의 `카카 오게임즈`가 코드 복사에 그대로 남는 작성된 위치 fixture를 확인했다. 이는 새 모델 출력이나 실패 요청의 자동 보정이 아니다.
- 답변 system prompt와 schema는 기존과 같다. 모델이 선택한 출처 원문과 ledger의 모든 인용 출처가 함께 전달되는지 확인한다.
- 위치 선택 수정본에 live 출력, consumed marker, 새 실행 authorization은 없다. 이전 source/corpus/vector와 봉인된 결과는 hash로 보호한다.

## 다음 실제 평가의 고정 범위

준비된 runner는 같은6문항, 같은 모델·검색·top8·추가 검색2회 제한을 사용한다. 제안 상한USD15, 최대 생성30회·검색어 임베딩12회, 보수적 전체 예약USD14.0106이다. 상한은 청구 관측이 아니다. 실제 실행에는 이 수정본 manifest hash를 지정하는 새 단일 실행 승인이 필요하며, 이전 배치의 consumed 승인을 재사용하지 않는다. 이번 턴에서는 추가 비용 호출을 하지 않았다.

평가할 것은 원문 인용 계약 통과, 검색 후 주의사항 보존, 종료 판단, 실제 답변의 내용/인용, 비용이다. 이전 Agentic6문항과의 비교는 개발 표본의 역사적 비교이며, 미노출/무작위 실험이 아니다. 원래 카카오 판정 민감도와 corpus 누락 대조를 유지한다.

Production SimpleRagAgent는 변경하지 않았다. 로컬 제외 구현과 검증:
`benchmarks/results/agentic_ledger_addressed_2026-09-28/`의 `experiment.py`,
`ledger_contract.py`, `build.py`, `contract_checks.py`, manifest, checks,
transition_checks와 readiness seal. 이 경로는 검토 가능한 프로토타입이며 새 제품 기본 경로가 아니다.
