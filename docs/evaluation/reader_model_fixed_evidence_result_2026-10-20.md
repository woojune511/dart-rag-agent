# 동일 근거에서 Terra와 Sol을 비교한 결과

2026-10-20. **COMPLETE_EXPLORATORY_GATE_MET**.

기존 실패 6문항에서 질문·검색 근거·기존 프롬프트를 유지하고 생성 모델만 바꿨을 때, 완전 정답은 **Terra 3/18 → Sol 16/18**, 인용 근거 지지 통과는 **6/18 → 16/18**이었다. 성공 대조 3문항에서는 **8/9 → 9/9**였고, 대조 문항별 통과 횟수의 감소는 없었다. 특히 상각비의 비용 범위와 파이프라인의 신청 시점을 Sol이 각각 세 번 모두 정확히 구분했다.

이는 실패 사례를 골라 구성한 **9문항의 반복 평가**다. 전체 평가셋 정답률이나 미노출 문항으로의 일반화를 확인한 결과는 아니다. 사전 탐색 기준은 통과했으며, 제품 기본 모델은 Terra로 유지했다.

## 비교 조건과 실행

사용자의 “그래 그럼 모델 바꿔서 해보자” 요청에 따라, 앞서 제안한 실패 6문항과 성공 대조 3문항을 두 모델에서 각각 세 번 생성했다. **54/54회 완료, 오류 0, 재시도 0**이다. 과거 기본 모델 답변을 주 비교의 baseline으로 재사용하지 않았다.

| 고정 항목 | 조건 |
|---|---|
| 비교 모델 | `gpt-5.6-terra` / `gpt-6.1-sol` |
| 프롬프트·출력 | 기존 `ANSWER_INSTRUCTIONS`, strict `RagAnswer` |
| 생성 설정 | reasoning `low`, 최대 출력 8,192, `service_tier=default`, `store=false` |
| 입력 | 저장된 질문·보고서 범위·청크 본문·문맥·순서 그대로 |
| 검색 결과 수 | 기존 실패 패킷 유지: 5문항 top-12, NAVER CAPEX 1문항 top-8; 성공 대조는 top-12 |
| 순서 | 문항별 두 모델을 인접 실행하고 반복마다 순서를 교대 |
| 실행 상한 | 54회, 사용량 기반 추정 비용 3달러, 20분; 첫 오류 중단 |

9개 문항의 Terra 요청은 해당 과거 평가의 native 요청과 정확히 일치했다. 각 문항의 Terra/Sol 요청에서 다른 필드는 모델 ID뿐이며, 실제 전송한 요청 54개도 동결 요청과 일치했다. 검색·임베딩·judge 호출은 없었다.

실행기 기록은 440.8초다. 반환 모델 ID는 요청과 같았고, 54개 모두 `low`·`standard`였다. 같은 `low` 설정이 두 모델의 내부 계산량을 동일하게 만든다는 뜻은 아니다.

## 정답과 근거 충실성

완전 정답은 **정확성 PASS ∧ 요청 충족 PASS ∧ 인용 근거 지지 PASS**다. 출처 ID가 존재하는지만 검사하지 않고, 실제 인용한 모델 입력이 주장과 계산 기준을 지지하는지 검토했다.

원시 답변을 봉인한 뒤 모델·반복 이름을 가린 답변을 원문과 대조했다. 주 판정과 해석 경계의 보조 판정을 저장·봉인한 후 모델을 공개했다. 같은 assistant가 검토했으므로 독립 평가나 완전한 맹검으로 주장하지 않는다.

| 평가 축 | Terra | Sol |
|---|---:|---:|
| 실패 6문항 × 3회: 완전 정답 | **3/18, 16.7%** | **16/18, 88.9%** |
| 같은 패널: 정확성 | 4 PASS · 7 PARTIAL · 7 FAIL | 18 PASS |
| 같은 패널: 요청 충족 | 18 PASS | 18 PASS |
| 같은 패널: 인용 근거 지지 | 6 PASS · 12 PARTIAL | 16 PASS · 2 PARTIAL |
| 성공 대조 3문항 × 3회: 완전 정답 | **8/9** | **9/9** |
| 성공 대조: 인용 근거 지지 | 8 PASS · 1 PARTIAL | 9 PASS |

실패 패널의 반복별 완전 정답은 Terra/Sol 순서로 **0/5, 1/6, 2/5**였다. 문항·반복 번호를 맞춘 18쌍은 양쪽 통과 2쌍, Terra만 통과 1쌍, Sol만 통과 14쌍, 양쪽 미통과 1쌍이다. 반복 18개를 독립된 18문항으로 해석하지 않는다.

사전 탐색 기준인 완전 정답 3개 이상 증가, 2문항 이상에서 통과 횟수 증가, 근거 지지 통과 감소 없음, 성공 대조의 문항별 통과 횟수 감소 없음을 모두 충족했다.

## 어떤 오류가 달라졌는가

아래 숫자는 각 문항의 세 번 중 완전 정답 횟수다.

|---|---:|---:|---|
| 제네시스 고급화 성과 `MIX_T2_047` | 1/3 | 3/3 | Sol은 2022년 미국 판매 설명을 2023년 성과로 옮기는 문장을 생략 |

| 무형자산상각비 `CEL_T1_038` | 0/3 | 3/3 | Sol은 전체 배분액과 당기 영업비용을 구분 |
| 미국 판매 성장률·IRA `HYU_T2_010` | 1/3 | 1/3 | Sol의 두 답변에 근거 없는 반올림 설명이 남음 |

| 데이터센터 CAPEX `NAV_T3_032` | 0/3 | 3/3 | Sol은 감소율 8.5%를 정확히 계산하고 계약·투자 범위를 구분 |

### 상각비와 차량 이익의 기준 선택

상각비 원문 `360:200`의 전체 배분액은 **182,286,838천원**이다. 매출원가 145,878,128과 판매비와관리비 36,171,696의 합은 **182,049,824천원**이고, 개발비·건설중인자산 배분액은 237,014천원이다. 같은 패킷의 `185:25`도 비용액과 매출액을 제공한다.

Terra는 세 번 모두 총 배분액을 비용으로 사용해 **8.38%p**를 제시했다. Sol은 세 번 모두 총액을 보존하면서 자산 배분액을 제외하고, `182,049,824 / 2,176,431,531 × 100 = 8.364601…%p`, 즉 **8.36%p**를 계산했다. 추가 문장을 생략한 것이 아니라 계산에 사용할 비용 범위를 정확히 선택한 개선이다.

차량 이익에서는 Sol이 세 번 모두 `76:0` 등에서 조정 포함 **12,677,300백만원**을 선택해 전체 15,126,901 대비 **83.8%**를 계산했다. Terra의 두 답변은 조정 전 12,969,227을 선택했다. 이 값과 85.74% 자체가 날조나 산술 오류인 것은 아니므로, 조정 기준을 한정한 대체 해석은 별도 보조 평가에 남겼다.

### 파이프라인의 날짜와 인용 연결

Sol은 세 번 모두 `103:44`에 있는 **CT-P39의 미국 신청과 CT-P41의 유럽 신청은 작성기준일 이후**라는 주석을 보존했다. `108:49`의 CT-P47 신청도 **2024년**이라고 구분했다. 상업화 제품의 오리지널 브랜드 대응을 설명할 때는 그 관계를 제공하는 `84:25`를 인용했다.

Terra도 CT-P47의 2024년 신청은 구분했지만, CT-P39·P41을 “2023년 기준” 표에 사후 신청 한정 없이 넣었다. 상업화 제품의 브랜드 대응을 덧붙이면서 `84:25`를 인용하지 않은 문제도 세 번 모두 남았다. 신청 시점에 관대한 해석을 적용해도 인용 누락 때문에 완전 정답으로 바뀌지 않는다.

### CAPEX와 제네시스의 개선은 구분해서 해석

Sol은 CAPEX 세 답변 모두 `692.3 / 756.2 − 1 = −8.450145…%`를 **약 8.5% 감소**로 정확히 표시했다. Terra는 두 번 8.4%라고 썼다. 나머지 한 번은 감소율을 생략했으나, 원문이 “클라우드 데이터센터 신축 등”으로만 표시한 계약을 “세종”으로 특정해 근거 지지가 PARTIAL이었다. 따라서 Terra도 핵심 CAPEX 금액은 맞았고, 0/3은 추가 주장까지 포함한 엄격 판정이다.

제네시스에서는 Sol이 누적판매 100만 대·고급차 믹스 기여·수상·출시를 보존하면서 잘못된 미국 판매 설명을 쓰지 않았다. 이는 **불필요한 기간 오류를 줄인 효과**이며, 2022년 문장을 정확한 연도로 다시 설명하는 능력을 별도로 입증한 결과는 아니다.

### 남은 미국 판매 문항의 한계

Sol의 세 답변은 현대차의 87.0만 대와 78.1만 대로 **11.4%**를 계산하고 공시 **11.5%**와 구분했다. 하지만 두 답변은 판매대수가 반올림되어 공시됐다고 서술하거나 그 때문에 차이가 난다고 설명했다. 원문은 이 처리 방식이나 차이의 원인을 설명하지 않는다. 따라서 정확성·충족은 PASS, 인용 지지는 PARTIAL로 유지했다.

Terra의 두 답변은 현대차 판매 대신 **미국 자동차시장 전체 1,560.8만 대·12.3%**를 답했다. 원래 동결 정답은 현대차를 대상으로 하지만 질문 자체는 회사 주어를 생략한다. 시장 전체를 명시한 이 답변의 사실을 날조로 세지 않았고, 질문을 시장 전체로 읽는 보조 평가도 함께 집계했다.

다음 보조 판정은 주 점수를 바꾸지 않는다. 조정 기준·파이프라인 시점은 사전 지정된 경계이며, 시장 전체 해석·표시 설명·세종 계약 귀속·대조 정밀도의 구체적인 보조 판정은 모델 이름을 공개하기 전에 추가로 기록했다.

## 비용과 응답시간

실행일 확인한 [Terra 공식 요금](https://developers.openai.com/api/docs/models/gpt-5.6-terra)과 [Sol 공식 요금](https://developers.openai.com/api/docs/models/gpt-6.1-sol)을 반환 사용량에 적용했다. 아래는 청구서가 아닌 추정 비용이며, reasoning 토큰은 출력에 이미 포함되어 있어 중복 계산하지 않았다.

| 항목 | Terra | Sol |
|---|---:|---:|
| 답변 호출 | 27 | 27 |
| 입력 토큰 | 308,676 | 308,676 |
| 일반 입력 토큰 | 81 | 81 |
| 캐시 읽기 토큰 | 274,679 | 205,730 |
| 캐시 쓰기 토큰 | 33,916 | 102,865 |
| 출력 토큰, reasoning 포함 | 12,575 | 13,609 |
| 그중 reasoning 토큰 | 2,089 | 875 |
| reasoning 토큰이 보고된 답변 | 15/27 | 15/27 |
| 추정 비용 | **$0.2907878** | **$0.4139875** |
| 평균 답변 호출 시간 | **4.95초** | **10.85초** |
| 중앙 답변 호출 시간 | 4.91초 | 11.12초 |

합계는 **$0.7047753**으로 3달러 상한 이내다. Sol의 관측 비용은 약 42.4% 높고 평균 응답시간은 약 2.19배였다. 시간은 저장된 검색 결과를 사용한 답변 호출 구간이며 실제 제품의 검색 포함 지연시간과 다르다.

| 비용 구성, USD | Terra | Sol |
|---|---:|---:|
| 일반 입력 | 0.0001620 | 0.0001620 |
| 캐시 읽기 | 0.0549358 | 0.0205730 |
| 캐시 쓰기 | 0.0847900 | 0.2571625 |
| reasoning 출력 | 0.0250680 | 0.0087500 |
| 나머지 출력 | 0.1258320 | 0.1273400 |

이번 비용 차이에는 **Sol의 더 많은 캐시 쓰기**가 크게 작용했다. 두 모델의 캐시 상태가 달라 이 비용비를 일반적인 모델 가격비로 해석할 수 없다. 반환 토큰 수를 그대로 두고 모든 입력에 일반 입력 요금을 적용하는 가정 계산은 Terra $0.768252, Sol $0.753442다. 이는 새 실행 결과나 청구 예측이 아니다.

Sol의 보고된 reasoning 토큰은 오히려 적었다. 따라서 이번 개선을 reasoning 토큰 증가의 효과라고 설명할 근거는 없다.

## 결론과 재현 자료

이 패널에서는 **같은 근거의 비용 범위·기간·인용 관계를 해석하는 단계에서 모델에 따른 반복 개선**을 확인했다. 이전의 점검 지시·선택 기록 추가는 개선 기준을 통과하지 못했지만, 이번 모델 비교는 통과했다. 특히 상각비와 파이프라인은 올바른 해석을 답변에 명시해, 단순한 답변 축소 이상의 차이가 관찰됐다.

다음 검증 후보는 같은 실패 유형의 새로운 문항이다. 이번 결과만으로 전체 77문항 성능이나 거절 품질을 보장하거나 기본 모델을 자동 변경하지 않는다. 과거 같은 6패킷의 Terra 기본 응답은 완전 정답 6/18과 7/18이었으며, 이번 값과 차이가 있다. 이번 결론은 과거 점수와의 차감이 아니라 **동시에 새로 생성한 모델 간 비교와 구체적인 원문 대조**에 근거한다. 모델 ID는 날짜 없는 alias이고 평가자는 동일 assistant다.

검증에서는 모의 SDK 호출 54개와 제한 조건 26개를 확인했다. 실제 요청 54개·고유 응답 ID 54개·모델만 다른 요청 쌍 9개·과거와 정확히 같은 Terra 요청 9개를 재구성했다. 원시 출력·조건 공개 전 판정 봉인과 기존 보호 파일 4,796개를 확인했다. 기존 소스·환경·store·과거 결과는 보존했으며 제품 변경, 앱 재시작, 커밋·push는 수행하지 않았다.
