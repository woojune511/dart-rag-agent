# 동일 근거에서 선택 기록을 출력하는 실험 — 중단된 패널의 부분 결과

상태: **INTERRUPTED_HTTP_520_PARTIAL_REVIEWED**. 계획한 36회 중 6회가 완료됐고, 7번째 요청이 HTTP 520으로 실패했다. 나머지 29회는 미실행이다. 최초 오류 시 중단한다는 사전 규칙에 따라 재시도하지 않았다. **전체 실험의 개선 여부는 판정할 수 없다.**

완료된 3문항을 각각 한 번 비교한 결과, 기존 방식과 선택 기록 방식 모두 완전 정답은 **1/3**이었다. 선택 기록은 원문에 있는 값을 잘 복사했지만, 두 계산 문항에서 필요한 값의 의미와 조정 기준을 고르는 문제를 해결하지 못했다.

## 비교 조건

- 이전 실험과 같은 6개 고정 질문·근거 묶음. 5문항은 top-12, NAV_T3_032는 top-8 패킷이다. 새 검색·임베딩·문서 처리는 하지 않았다.
- P0: 기존 SimpleRagAgent 지시와 RagAnswer 출력.
- S1: 동일 지시에 일반적인 선택 기록 지시를 추가하고, 최종 답변 앞에 `evidence_selections`를 출력한다. 요청 항목, 사실 또는 수량, 주체, 기간, 범위, 원문 값·단위, 출처 ID와 정확한 인용문을 기록한다.
- 모델은 `gpt-5.6-terra`, reasoning `low`, 출력 한도 8,192토큰이다. 조건별 모델 호출은 한 번이며, 별도 검증 모델이나 계산 도구를 추가하지 않았다.
- 계획은 조건별 3회 반복, 총 36회, 비용 상한 2달러, 재시도 0회였다. 실제로는 앞의 3문항에 대해 조건별 1회만 완료했다.
- 지시와 출력 스키마를 함께 바꾼 비교다. 스키마만의 효과를 분리한 실험이 아니다. 기록을 답변 앞에 출력했다는 관측은 내부 추론 순서의 증명이 아니다.

생성 요청에는 평가 정답·판정 기준·실패 원인을 전달하지 않았다. 실제 전송된 질문·근거·출처 순서를 이전 패킷과 대조했고, 기존 조건의 요청도 이전 P0와 동일함을 확인했다.

## 선택 기록에서 확인한 실패

S1 답변 3개의 선택 기록은 총 9개, 인용 구간은 11개다. **11개 모두 제공된 청크에 실제로 존재하는 연속 문자열**이며, 출처 ID도 유효하고 최종 인용 목록에 포함됐다. 이는 청크와 인용의 물리적 대응 결과이며 의미 정확도 점수가 아니다.

### 차량 부문: ‘연결’이라는 범위만으로 조정 기준이 맞아지지 않는다

S1은 차량 `12,969,227백만원`, 금융 `1,385,538백만원`, 전체 `15,126,901백만원`을 기록했다. 출처 `530:388`에 모두 있는 값이다. 그러나 차량 값은 조정 전이고 전체는 조정 후다. 원래 평가에서 사용하는 조정 포함 차량 값 `12,677,300`과 비중 `83.8%`는 `67:0` 등에 제공돼 있었다.

조정 전 차량을 전체와 비교한 비율 자체는 별도의 기준으로 설명할 수 있다. 따라서 조정 전 값을 원문에 없는 숫자나 조작으로 분류하지 않았다. 기존 평가 기준과의 불일치, 기준 설명의 충분성, 산술 정확성을 구분했다.

- P0: 조정 전 차량 기준 `85.74%`. 해당 피연산자에 대한 산술은 맞지만 조정 기준을 구분하지 않았다.
- S1: 전체는 조정 반영 합계라고 설명했지만, 같은 분수를 `85.81% ≈ 85.8%`라고 계산했다. 독립 재계산값은 `85.7361795…%`이므로 이 부분은 명확한 산술 오류다.

구조화된 기록에 값을 적게 해도 기준 선택과 산술은 별도로 틀릴 수 있었다. 한 번씩 나온 결과이므로 S1이 산술 오류 확률을 높였다고 결론 내리지 않는다.

### 상각비: 합계의 이름을 정확히 쓰고도 잘못된 효과를 계산했다

S1은 `fact_or_quantity`를 **“무형자산상각비 기능별 항목 합계”**로 적고, `182,286,838천원`을 선택했다. 인용문에는 다음 구분도 들어 있었다.

- 매출원가 `145,878,128` + 판매비와관리비 `36,171,696` = **182,049,824**
- 개발비 `209,548` + 건설중인자산 `27,466` = **237,014**

하지만 최종 답변은 합계 전액을 영업비용으로 가정해 **8.38%p**를 제시했다. 실제 손익 비용을 사용한 기존 기준은 `182,049,824 ÷ 2,176,431,531 × 100 = 8.364601…%p`, 즉 **8.36%p**다. 동일 패킷의 `185:25`에도 비용 합계가 직접 제시돼 있었다.

이 답변은 숫자를 못 찾거나 복사하지 못한 사례가 아니다. 기록에서 합계의 이름을 보존하고도, 영업이익률에 영향을 주는 부분을 골라 쓰지 못한 사례다. “전액 비용이라는 가정”을 붙였지만 요청한 실제 비용 기준의 추정으로 이어지지는 않았다.
