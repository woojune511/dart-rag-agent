## HD현대일렉트릭 경영진단

이전 파서 수정은 잘못된 중복 속성 따옴표로 경영진단 앞에서 문서가 잘리던 문제를 복원했다. 원문 근거 위치는73/76에서76/76으로 보존됐고, HD 청크는563→1,305가 됐다. 전체3,645청크 중 기존 HD 본문559개는 동일하고4개는 더 완전한 표 안에 포함되며, 나머지 두 보고서는 동일하다. 이는 [수정 전후 무호출 검증](hd_xml_quote_fix_and_new18_execution_preparation.md)의 결과다.

이번 실제 실행에서는 복원된 청크의 사용을 확인했다.

- **U01**은 `1128:1`의 연결 손익계산서를 두 번 모두 인용했다. 매출 증가와 영업이익률 비교가 정확했다.
- **U04**는 `1126:0`의 경영진단 개요를 두 번 모두 인용했다. 청주 생산 기반·북미 확장·신규 수주와2025 매출23%/영업이익49% 증가를 전달했다.
- U04의 원래 정답 근거인 **중동·미주 매출 증가와 수익성 개선**은 `1128:1`에 보존돼 있고 Dense6위까지 검색됐지만 BM2524개에는 없었다. RRF에서는 **11위**, 최종 문맥은8개여서 해당 설명을 생성 모델이 받지 못했다. 문맥 바이트 제한으로 잘린 경우는 아니다.

확인된 것은 **복원된 경영진단이 검색·답변에 도달했고, 특정 핵심 원인이 최종 선택에서 빠졌다는 사실**이다. 수정 전 답변을 같은 조건으로 생성하지 않았으므로 파서 수정의 정확도 증가폭을 계산할 수 없다. Dense에 유용한 후보가 있었다는 관측만으로 Dense 단독이나 다른 합성 방식의 전체 성능을 결론내릴 수도 없다.

## 판정의 민감도와 한계

**U04는 원래 gold를 보존하고 두 반복 모두U로 남겼다.** 원래 필수 항목의 특정 원인만 확인하면 두 번 모두F지만, 넓게 물은 질문에 대해 실제 경영진단의 다른 설명을 답한 부분도 있다. 이 차이를 단순 오답이나 사후 정답 승격으로 처리하지 않았다. U10의 실제 공동구매 대응과U15의 TR 수요 설명은 기존 기준이 허용하는 대체 표현으로 인정했다. U15의 사전 지정 ‘두 부문 모두 영업이익 개선’ 원문 충돌은 이번 답변에 해당 주장이 없어 자동U를 붙이지 않았다.

**수치와 단위도 사전 규칙대로 평가했다.** U02 첫 답변의 `4,079,498백만원`은 `40,794.98억원`이므로 억원 정밀도로는40,795다. 본문40,794는 허용 반올림 구간 밖이라F이며, 옳은 분모·2.31배 계산은 그대로 인정했다. U13 둘째 답변은 각 금액에 억원을 명시했으나 마지막에 ‘단위: 백만원’이 있어U다. 이 두 표기 문제만 평가에서 제외하는 민감도 계산은9/18·11/18, 두 번 모두9/18이지만, 공식 판정은 **8/18·10/18, 두 번 모두7/18**을 유지한다.

질문은 실사용 상황을 가정해 새로 작성한 것이며 실제 사용자 로그가 아니다.18문항은3개 보고서에 묶여 있고,36개 답변을 독립36문항으로 해석할 수 없다. 질문·gold 작성과 이번 원문 대조는 같은 assistant가 했으며 독립 사람 검토는NOT_DONE이다. 기존12문항은 재평가하지 않았으므로 그 세트의 생성 회귀 여부를 새로 주장하지 않는다. 원문·기존 입력 보존과 새18문항 품질은 별개다.
