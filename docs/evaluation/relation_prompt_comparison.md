# 분류·관계 추가 금지 프롬프트의 2회 비교

2026-10-15 · `COMPLETE_SOURCE_REVIEWED` · 기본 제품 미채택

**C11 개선은 관찰되지 않았다.** 검색 입력을 고정하고 일반적인 금지 문장 두 개만 추가했지만, 기존 P0와 수정 P1 모두 두 반복에서 홈쇼핑을 온라인 채널의 하위 항목으로 분류했다. 기존 12문항의 정확도·출처 충실도에는 두 반복 모두 새 회귀가 없었다. 조건별 strict 판정은 동일하게 **10통과·1실패·1유보**다. 이 수정은 기본 프롬프트에 반영하지 않았다.

[직전 답변 비교](paired_title_answer_comparison.md)의 표제·기간 보존 B1 검색 결과 12개를 모든 조건에 그대로 사용했다. B1/B2 packet이 동일함을 확인했고 질문, 출처 ID·본문·순서, 범위와 문맥을 고정했다. `까지` 제외, 표제·기간 보존 검색 입력, Dense16/BM25-24/RRF60·동일 가중치·top8·receipt scope 조건을 유지했다. 검색·임베딩을 다시 실행하지 않았고, 답변에 전달하는 출처 본문도 원래 canonical 청크 그대로다.

P0는 기존 `ANSWER_INSTRUCTIONS`, P1은 그 끝에 공백 하나와 다음 **25단어·189 UTF-8바이트·두 문장**만 덧붙인 조건이다. 회사·문항·채널 이름이나 정답 예시는 추가하지 않았다.

```text
Do not add classifications or relationships unsupported by the cited evidence, including through headings or grouping. Listing items together does not establish a parent-child relationship.
```

12문항 × 기존/수정 × 2회로 **48개 답변을 새로 생성**했다. 과거 답변을 대조군으로 재사용하지 않았다. 문항별 인접 쌍의 순서를 교대하고 두 번째 반복에서 뒤집었다. `gpt-5.6-terra`, reasoning `low`, 출력 상한8192, strict `RagAnswer` schema, default tier, `store=false`, explicit prompt cache를 고정했다. temperature·seed는 기존처럼 미지정이다. 실제 요청도 system instruction 외에는 동일했다.

**C11의 실제 결과:** 원문 `70:2`는 `홈쇼핑 및 온라인 채널`을 나열한다. `71:3`은 온라인 채널 강화를 위한 자사몰·온라인 커머스를 설명한다. 두 자료는 홈쇼핑이 온라인의 하위 분류라는 관계를 제시하지 않는다. P0가 추가로 인용한 `69:1`도 이 관계를 뒷받침하지 않는다.

모든 평가 축에서 P0→P1 판정 변화가 없었다. 두 반복에 걸친 개선0건·회귀0건, 한 반복에서만 나타난 판정 변화0건이다. C11을 제외한 나머지11문항에도 새 회귀는 관찰되지 않았다.

**기존 판정 기준을 유지한 항목:** C09는 P0 두 답변과 P1 2회가 반올림된 비중의 차를 적었고, P1 1회도 원 피연산자에서 변화량을 계산했는지 보여 주지 않았다. 최종 수치는 맞지만 ‘중간 반올림 없이 계산’은 네 답변 모두 `UNDETERMINED`로 유지했다. N03은 네 답변 모두 원래 백만원 요약표 대신 원 단위 표를 인용했다. 직전 검토의 원본 XML 표 구간·연결 범위·2025/2024 기간·원 단위를 재검증하고 정확한 원 단위 피연산자로 Decimal 계산을 반복해2.20%·5.23%를 확인했다. 기존 동등 출처 허용 기준에 따른 판정이며 출처 ID만으로 정오를 판단하지 않았다.

실제48개 답변을 모두 읽고 각각 실제 인용한 출처와 대조한 동일 assistant의 비맹검 검토다. 필수 구절의 출처 내 위치·원문 hash, 추가 주장 근거와 미지원 관계, 계산 결과를 개별 기록했다. shape/source-ID 검사는48/48 통과했지만 이는 의미 충실도 통과를 뜻하지 않는다. 기본 런타임의 의미·산술 검증은 여전히 미수행이다.

이번 결과는 **이 최소 프롬프트 수정으로는 같은 원문을 분류·그룹화할 때 생기는 C11 오류가 줄지 않았다**는 근거다. 검색된 원문이 충분한 상태에서 동일한 추가 관계가 생겼으므로 이 사례의 남은 실패는 생성 단계의 해석에 위치한다. 이것만으로 모든 프롬프트 수정이나 모델 성능의 한계를 일반화하지 않는다. 이미 노출된 두 보고서의 양성12문항·조건별2회이며 독립 holdout, 거절 품질 또는 일반적인 무회귀의 증명이 아니다. 결과를 본 뒤 문구를 더 고치거나 추가 호출하지 않았으며 기본 프롬프트를 유지한다.
