# 표제·기간 보존 검색 결과의 답변 비교

2026-10-15 · `COMPLETE_SOURCE_REVIEWED`

**C10의 검색 순위 개선은 이번 답변 비교에서 추가 정답 개선으로 이어지지 않았다.** 원래 입력 A와 표제·기간 보존 입력 B 모두 두 번씩 정확한 피연산자·계산식·**5.76%**를 답했다. 기존12문항에서도 A→B 정확도·출처 충실도 회귀는 두 반복 모두0건이었다. 양쪽에 공통으로 남은 오류와 판정 유보가 있으므로 전체 답변이 모두 정확하다는 뜻은 아니다.

## 비교 조건

[직전 Fresh Dense 비교](paired_title_dense_comparison.md)의 **주 비교인 정확 검색 A1/B1/A2/B2 packet**을 그대로 사용했다. BM25의 표제·기간 보존 입력과 정확한 `까지` 토큰 제외, Dense16/BM2524, RRF60·동일 가중치·top8, 접수번호 범위, 원래 질문·canonical 출처·65,536-byte 한도를 고정했다. 새로운 검색·임베딩·파싱·청킹은 실행하지 않았다. Native Chroma의 유일한 C11 packet 차이는 이번 답변 실험에 섞지 않았다.

생성 조건은 기존 reader 실험과 같은 `gpt-5.6-terra`, reasoning `low`, 최대 출력8,192토큰, production `ANSWER_INSTRUCTIONS`, strict `RagAnswer`, default tier, `store=false`, explicit prompt cache다. temperature·seed는 기존대로 지정하지 않았다. 질문별 A/B를 연속 실행하고, 질문마다 순서를 바꾸며 두 번째 반복에서 반전했다. **12문항×2조건×2반복=48회**다.

동일 arm의 두 반복은 입력 packet과 생성 요청 body가 완전히 같다. 따라서 반복 간 문구 차이는 이 실험에서 검색 입력 차이로 설명할 수 없다. 답변에는 검색용으로 추가한 표제·기간을 새로 붙이지 않고 기존 canonical 출처만 전달했다.

기존 `gold.json`·`rubric.json`을 변경하지 않았다. 최종 값·필수 사실, 명시적 요청 충족, 계산 절차, 필수 주장과 추가 주장 각각의 **실제 인용 출처** 지지를 나눠 검토했다. 숫자는 별도로 Decimal로 재계산했다. 같은 assistant가48개 실제 답변과 인용 출처를 모두 읽은 비맹검 검토이며, 별도 유료 judge는 쓰지 않았다.

| 항목 | 원래 입력 A | 표제·기간 보존 B |

**C09:** 네 답변의 최종 수치·연도별 피연산자와 식·%/%p·하락 방향은 맞다. A1/A2는 반올림된90.94%−91.12%를 식으로 적었고 B1도 그 두 수치의 차로 설명했다. B2는 변화량만 제시해 원 피연산자로 변화량을 계산했는지 확인할 수 없다. 기존의 ‘중간 반올림 없이 계산’ 기준을 충족했다고 추정하지 않고 모두 `UNDETERMINED`로 남겼다. 최종값 정확성과 계산 절차 통과를 합치지 않았다.

**C11:** 네 답변 모두 `온라인 채널: 홈쇼핑, …`으로 분류했다. 인용된 `70:2`는 홈쇼핑과 온라인 채널을 나열하고, `71:3`은 자사몰·온라인 커머스를 설명한다. 일부 답변이 추가 인용한 `69:1`도 해당 하위 분류를 뒷받침하지 않는다. 요청된 방문판매·유통·온라인·수출·판매방법·회수방법은 모두 포함했지만, 이 추가 관계는 네 답변 모두 strict 실패다. 이전 실험과 같은 reader 해석 문제이며 B에서 새로 생긴 회귀가 아니다.

**N03의 동등 출처:** B 두 답변은 원래 정답표의 백만원 값 대신 인용된 `100:2`의 매출3,514,315,500,097원·3,438,730,857,998원과 영업이익183,933,032,197원을 사용했다. 원본 XML의 독립된 표 구간, 연결손익계산서 표제,2025/2024 기간·원 단위를 확인했고 별도로 계산해2.20%·5.23%를 얻었다. 질문은 특정 요약표·표시단위를 지정하지 않았으므로 기존 동등 출처 허용 기준으로 인정했다. 임의 숫자 변환이나 정답 출처 ID 불일치에 따른 감점은 하지 않았다.
