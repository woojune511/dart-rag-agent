## 평가와 해석

모든 요청 항목을 실행 전에 고정했다. 계산은 원문 피연산자에서 `Decimal`, `ROUND_HALF_UP`으로 계산하며 중간 반올림 없이 소수 둘째 자리까지 비교한다. %와 %p, 당기/전기, 연결/별도, 공시액/실제 지급액을 구별한다. 조회에서는 공시 표시를 보존한다. 원문이 설명하지 않은 차이를 반올림 때문이라고 추정하지 않는다.

주 평가는 핵심 내용 정확성·명시적 요청 충족·필수 주장에 대한 인용 지지의 결합이다. 추가 주장까지 모두 인용으로 지지되는 엄격 점수와 거절 여부를 별도로 보고한다. 실제 답변의 의미 판정은 source review로 수행하며 ID 검사 통과로 대체하지 않는다. 동일 의미의 요청에 맞는 다른 근거를 인정하고, 지정 gold ID의 부재만으로 근거 부족을 판정하지 않는다. 새 모호함이 드러나면 `UNDETERMINED`로 남기며 결과를 보고 기준을 보정하지 않는다. 과거 7개 보류 문항은 [별도 계약 처분](evaluation_contract_disposition_v1.md)을 따른다.

모델 `gpt-5.6-terra`, reasoning `low`, 기존 SimpleRag 답변 지시·`RagAnswer` 스키마, 최대 출력 8,192토큰을 두 arm에 동일하게 적용한다. 12문항 × 2입력 × 2회 = **48개 답변**이다. 문항별 arm 순서를 번갈아 배치하고 두 번째 반복에서 뒤집는다. 실제 검색은 한 번 수행해 두 반복에서 같은 packet을 쓴다. 두 번의 답변은 독립 문항이 아니며, 같은 보고서·출처를 공유하는 질문도 있다.

| 결과의 경계 | 다음 판단 |
|---|---|
| 원문 값·문맥이 현재 청크에 없다 | 파서/청킹 손실을 먼저 재현한다. |
| 충분한 원문은 corpus에 있으나 후보에 없다 | 후보 생성·query/embedding/BM25 문제를 좁힌다. |
| 후보에 충분한 묶음이 있으나 최종 packet에 없다 | 최종 선택이나 중복 제거를 다음 제한 실험 후보로 삼는다. |
| 검색 입력은 부족하고 충분 근거 입력에서 두 번 모두 회복 | 해당 문항에서는 근거 전달을 먼저 개선할 근거가 된다. 특정 reranker의 효과는 아직 모른다. |
| 충분 근거 입력에서도 반복 실패 | 단위·대상 해석·요청 누락·계산·인용을 나눠 기록한다. 후속 동일 입력 모델 비교를 고려할 수 있다. |
| 두 입력 모두 잘 답하거나 반복 결과가 뒤집힘 | 천장 효과/변동성을 보고한다. 새 기능 도입이나 인접 prompt 변형을 자동 실행하지 않는다. |

충분 근거 arm은 검토한 corpus 청크를 쓰므로 입력 선택·길이·잡음이 함께 달라진다. 개선을 RRF 공식 하나의 인과효과로 해석할 수 없다. 그 arm의 실패 역시 모델 한계로 바로 단정하지 않고 근거 충분성·문맥·루브릭을 다시 확인한다. source-authored 양성 12문항, 2개 회사, 동일 assistant 검토이므로 일반 정확도·거절 성능·독립 평가 결과로 제시하지 않는다.

## 호출·비용·중단 경계

원문이 새 보고서여서 문서 벡터가 없다. 격리 실험에서만 `text-embedding-3-large`, 3,072차원으로 2,240문서/35배치와 질문12개/1배치를 임베딩한다. **36임베딩 요청 +48답변 요청 =84 HTTP 요청**이며 retry는 0이다. query 벡터를 반복 재사용한다. 기존 제품 store에 복사·활성화하지 않는다.

2026-10-15 [공식 요금](https://developers.openai.com/api/docs/pricing)을 확인했다. 답변 모델은 100만 토큰당 input USD2, output USD12이고 보수적 계산은 모든 input에 cache-write 요금 USD2.50을 적용한다. 임베딩은 USD0.13/100만 토큰이다. 로컬 임베딩 토큰은 1,617,941개이며 배치별 여유 128토큰을 추가한다. 답변 입력은 UTF-8 byte 수+스키마+4,096 overhead, 출력은 요청 상한 전체로 사전 예약한다.

- 계산된 보수적 최대: **USD9.90504837** = 답변9.69411700 +임베딩0.21093137.
- 제안 승인 한도: **총 USD12.00, 1회 실행**. 할인·cache hit를 이득으로 가정하지 않는다. 비용 추정은 청구서가 아니며 provider usage·요금 경계가 어긋나면 즉시 멈춘다.
- 첫 HTTP/응답상태/스키마/출처 ID/usage/hash/cap 오류에서 중단한다. 재시도·복구·resume·모델 대체·후속 호출은 없다. 실패 요청은 사전 예약액을 유지하고 사용량 미확정을 별도 표시한다.
- 20초 heartbeat, 원본 HTTP 응답, exact request, 단계별 사용량·시각, 중단 후 `NOT_RUN`을 저장한다. 요청 전 cap을 검사하고 실제 후보와 48개 답변 입력 전체를 첫 답변 전에 고정한다.

[AGENTS.md](../../AGENTS.md)의 “provider, fresh ingest, store mutation은 별도 필요성과 승인 경계를 따른다”와 [runtime contract](../architecture/agent_runtime_contract.md)의 “Fresh quality/cost/latency evaluation needs a separately frozen bounded run”을 적용한다. 현재 완료 범위는 이 구체적인 실행의 준비·검증이다. 위 1회 비용·호출 범위의 승인이 있어야 유료 CLI를 실행한다.

## 검증과 산출물

- 네트워크를 차단한 진단 계약 검사 **12/12 통과**. 실제 OpenAI SDK 직렬화, 변조된 요청/대상 URL/cap 거절, scope 거절, 전체 청크 byte 누락, 원문/질문/gold 분리, 계산·정밀도, usage·벡터 shape/순서/유한성, 미완료 응답·없는 출처, HTTP503에서 재시도 없이 중단을 검사했다.
- 모의 실행에서 **84/84 SDK 요청, 실제 native 검색12회, 답변 입력48개**를 끝까지 구성했다. RRF 순위를 별도 계산으로 대조했다. 사용한 벡터·응답은 합성 fixture이며 모델 성능·비용·지연시간 결과가 아니다.
- 준비 중 전체 XML 복구 tree의 상위 표 포함관계가 국소 표 근거로 부적합해 `original_witnesses_v2.json`의 원본 byte 구간 감사로 대체했다. 최초 모의 응답 fixture의 SDK 필수 필드 누락도 수정한 후 전체 12검사를 다시 통과했다. 제품 parser/SDK 결함이나 유료 실행 실패로 기록하지 않는다.
- 실제 답변, 후보 충분성의 최종 판정, 원문 기반 의미 채점, 모델 비교, 성능 개선은 **NOT_RUN**이다. 입력 hash와 준비 검증은 의미적 정답을 보증하지 않는다.
