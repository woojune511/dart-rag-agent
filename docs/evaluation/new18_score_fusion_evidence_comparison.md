# 새 18문항 CC DBSF RRF 검색 근거 비교

작성일: 2026-10-15. **사전에 고정한 CC와 DBSF는 HD현대일렉트릭 경영진단 핵심 근거를 복구하고 U06·U10·U18의 필수 그룹을 유지했다. 그러나 U08·U15의 필수 근거가 각각 하나씩 빠졌다.** 두 방식 모두 근거 완비 문항은 현재 RRF의13/18에서14/18로 늘지만, 충족한 필수 근거 그룹은26/33에서25/33으로 줄었다. 회귀 없는 개선이 아니므로 기본 RRF를 유지한다.

모델·임베딩·답변 생성·judge·새 검색·외부 원문 요청은0회, 추가 API 비용은$0이다. 저장 벡터와 문서의 로컬 점수 계산만 수행했다. 수치는 **최종8개에 필요한 공시 근거가 있는지**를 뜻하며 답변 정확도나 출처 충실도 개선은 평가하지 않았다.

## 결과 전에 고정한 비교 규칙

사전 manifest (`../../benchmarks/results/new18_score_fusion_replay_2026-10-15/manifest.json`, local artifact not included)를 별도 freeze 단계에서 기록한 다음 실행했다. 모든18문항에 같은 설정을 적용했으며 결과를 본 뒤 정규화 범위·가중치·계산 정밀도를 변경하지 않았다. 상수 변경이나 추가 가중치 탐색은 실행하지 않았다.

| 항목 | 고정 조건 |
|---|---|
| 후보 | 기존 실행에 저장된 Dense16개와 BM25 최대24개의 UID 합집합. 18문항622개 문항–후보 쌍 |
| 질문·범위 | 기존 질문 원문, 회사·2025 사업보고서 범위 유지 |
| Dense 점수 | 저장 float32 질문/문서 벡터를 float64로 변환해 squared L2 계산 후 부호 반전. 높을수록 좋은 점수로 통일 |
| BM25 점수 | 기존 한글 bigram/ASCII 토큰화와 BM25Okapi 기본값. 원래3,645개 문서 전체의 IDF·평균길이 및 원문 strip 유지 |
| 점수 보충 | 합집합의 모든 후보에 양쪽 실제 점수를 계산. 목록 밖 후보에0을 대입하지 않음. 실제0·음수도 임의 절단하지 않음 |
| 최종 문맥 |8개,65,536 UTF-8 bytes. 본문·메타데이터·출처 ID 보존 |
| 동점 | 기존 Dense 우선 삽입 후 새 BM25 후보 순서의 stable 정렬 |
| 기타 | 추가 검색·재임베딩·reranker·캡션 첨부·backfill 없음 |

현재 RRF는 저장된 순위에 동일 가중 `1/(60+rank)`를 합산한다. 한 목록에 없는 후보의 해당 RRF 기여는0이며, 기존 실행의 순서를 그대로 재현한다.

CC는 질문별 고정 합집합 안에서 검색기별 `N(s)=(s-min)/(max-min)`을 계산하고 `0.5*N(Dense)+0.5*N(BM25)`로 결합한다. 정확히 같은 점수만 있는 목록은 모두0.5로 처리한다.

DBSF는 같은 합집합 안에서 검색기별 평균μ와 **표본 표준편차σ(ddof=1)**를 계산하고 `N(s)=0.5+(s-μ)/(6σ)`를 동일 가중치1:1로 합산한다. clipping은 하지 않으며 σ가 정확히0이거나 후보가 하나이면0.5로 처리한다.

이번 DBSF는 **양쪽 점수를 보충한 전체 합집합에 DBSF 정규화 공식을 적용한 조건**이다. 검색기마다 반환된 짧은 목록에서만 통계를 계산하고 부재 기여를0으로 두는 방식이나 Qdrant 실행의 재현이 아니다. CC와 DBSF가 같은 점수 영역을 사용하도록 고정했으며, 이 조건의 결과를 모든 DBSF 구현으로 확대하지 않는다.

전체 corpus의 Dense top16을 다시 뽑지 않았다. BM25 전체 점수 계산은 기존 점수·순위 재현과 합집합 후보의 점수 보충에만 사용했다. 후보 멤버십·청킹·검색 입력·임베딩 모델을 바꾸지 않았다.

## 재현과 산술 검증

현재 RRF18개 문맥은 이전 실행의 본문·순서까지 모두 일치했다. 저장 Dense288개 점수와 BM25432개 점수/순위를 대조했다. Dense 최대 절대 오차는1.238e-6으로 사전 허용1e-5 이내이며, 원래 BM25 코드로 재계산한 점수는 정확히 일치했다.

별도 검증 스크립트는 실행 스크립트의 계산 함수를 가져오지 않고 scalar L2 합산, 수동 BM25식, 표본 표준편차로 재계산했다.622개 점수 쌍과54개 전체 순위·최종8개가 일치했다. 독립 BM25 계산의 최대 차이는9.20e-13이다. DBSF의 범위 밖 정규화 값4개도 절단하지 않았다.8–9위 동점은 사전 stable 정렬대로 처리했다.

54개 문맥 모두 정확히8개이고 최대29,654bytes로 크기 제한 누락은0이다. 이전 답변2회가 같은 검색 결과를 공유했으므로 이번 결정적 비교를 반복 표본으로 부풀리지 않았다.

## 전체 필수 근거와 회귀

기존33개 필수 그룹의 기준과 허용 대체 근거를 유지했다. P는 해당 그룹을 설명할 공시 근거가 충분한 경우, F는 일부 또는 전부가 누락된 경우다. 숫자·문구 일치만으로 판정하지 않고 대상·기간·단위와 관계를 대조했다. 주 에이전트 판정과 별도 에이전트의 본문 검토를 대조했으며 독립 사람 검토는 수행하지 않았다.

**완비 문항 증가와 근거 그룹 감소가 동시에 발생한다.** U04는 새로 완비됐지만, U08·U15는 원래부터 다른 필수 그룹이 부족했던 문항이다. 이 두 문항의 남아 있던 근거까지 잃어도 완비 문항 수는 추가로 감소하지 않는다. 따라서14/18만 보면 회귀를 놓친다.

**U08:** 원래 RRF에 있던 법인별 매출 표78:2·79:3·82:6이 모두 탈락했다. 주요 해외 국가 설명은 남고 연결 지역분석 정의159:35가 추가되지만, 그 기준으로 제시할 매출 규모가 없다. 이에 범위와 실제값을 연결하는U08.2가P→F이며, 이미F였던 국가별 완비U08.1 안에서도 남은 값이 추가로 사라졌다.

**U15:** TR 면세수요 회복과 호텔·레저 수요 환경을 설명하는1020:2가 RRF3위에서 CC16위·DBSF12위로 밀려U15.1이P→F다. CC는 서로 다른 UID의 값 없는 사채 작성기준일 청크5개, DBSF는4개를 선택했다. 기존 UID 중복 제거 규칙을 유지했으므로 이 동일 본문들이 각각 자리를 차지한다. DBSF가 유지한 조직개편 문장도 해당 수요 설명을 대신하지 못한다. 원래 부족했던 위약금 원인U15.2는 여전히F이며, 손익 방향을 보여주던 표도 추가로 빠졌다.

U15의1020:2는 Dense 점수 정규화값이1.0이어도 BM25 정규화값이0.074인 반면, 사채 작성기준일 청크982:22는 각각0.674·0.603이다. 고정된 동일 가중 CC는 후자를 높게 평가했다. 점수 차이를 활용하면 특정 순위 편중을 풀 수 있지만, **점수 자체가 요청별 필수 근거를 판정해 주지는 않는다는 관측**이다. 이를 근거로 이번 문항에 맞춘 가중치나 제거 규칙을 추가하지 않았다.

경계 설명 그룹U06.1·U12.1·U18.1을 제외한 기존 민감도에서도 RRF23/30, 두 대안22/30이다. 일반적인 거절 가능성을 제외해도 모든 필수 근거의 보존을 달성하지 못한다.

## 부분 손실과 남은 한계

U12는 외화 민감도 표를 잃었지만 지역별 성장률·러시아 생산 및 판매량 확대 설명과 환율 영향 서술을 유지해 기존 두 그룹은P다. 제공 문맥에 정량 분해가 없다는 한정된 설명이며 보고서 전체에 없다는 증명은 아니다.
