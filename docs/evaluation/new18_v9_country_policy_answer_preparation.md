# v9 기존 검색과 BM25 보완 정책의 문맥 12개 답변 비교 준비

상태: **PREPARED_NOT_RUN — 2026-10-17**. 모델·임베딩·검색·reranker·judge 호출 **0회, $0**. 공식 요금 문서만 조회했고 새 답변과 품질 판정은 모두 NOT_RUN이다.

새 18문항에 대해 **기존 검색 문맥 12개 / BM25 보완 정책 문맥 12개를 각각 2회**, 총 **72개 새 답변**으로 비교하도록 준비했다. 예상 비용은 **약 $1.73~$2.10**, 제안 실행 상한은 **72회·$13.33·2시간 30분**이다. 이번 요청은 준비까지이며 과거 실행 승인·소진 예산을 재사용하지 않는다.

[직전 오프라인 검색 비교](new18_v9_country_lexical_policy.md)는 필수 근거 28/33 → 29/33, 근거 회귀 0개였다. U08만 문맥이 바뀌고 다른 17문항은 문맥 전체가 같다. 이번 평가에서는 U08의 실제 국가 연결·기간 해석 개선과 모든 문항의 정확도·필수 항목 누락·출처 충실도 변화를 확인한다. 검색 근거 점수를 답변 점수로 대신하지 않는다.

기존 arm의 18개 요청은 직전 실제 top12 생성 요청과 canonical body가 정확히 같다. 정책 arm도 U08 이외 17개 요청이 같다. **요청 파일은 36개, 서로 다른 body 해시는 19종**이다. 동일 body라도 호출이나 응답을 재사용하지 않고 지정한 72개 슬롯을 모두 독립 요청으로 실행한다.

모델 alias와 요청 조건은 고정하지만 내부 모델의 불변 snapshot까지 확인한 것은 아니다. 실제 반환 model·effort·tier·기본값·usage·제공되는 fingerprint를 기록한다.

## 순서와 판정 단위

- 1회차: U01 → U18. 홀수 문항은 기존→정책, 짝수는 정책→기존.
- 2회차: U18 → U01. 각 문항의 조건 순서를 1회차와 반대로 한다.
- **조건별 36답변**, 동일 문항·회차의 **36쌍**, 조건별 필수 그룹 **66개 관측**, 총 **132개 관측**이다.
- 과거 답변은 비용 추정·역사적 참고용이며 새 대조군을 대체하지 않는다.
- 조건명·실행 순서를 가린 별도 검토 순서를 고정했다. 양쪽 문서 수는 같아도 U08 내용으로 조건을 추정할 수 있고, 같은 assistant가 이미 문항·정답·문맥을 보았으므로 독립 평가나 완전한 맹검은 아니다.

**동일 입력 17문항**에서 관측되는 답변 차이는 생성 변동으로 구분한다. 그 차이도 전체 회귀 표에는 포함하지만 BM25 입력 변경 때문이라고 주장하지 않는다. U08 역시 5개 문서가 함께 교체되므로 특정 한 청크의 효과를 단독으로 입증할 수 없다.

## U08 국가 연결·기간·집계 기준 판정

기존 U08.1·U08.2 기준과 두 허용 답변 경로를 유지한다.

1. 중국 지역매출과 베트남/러시아 법인 매출을 **각각 다른 기준으로 명시**한다.
2. 연결 지역 기준으로 중국·기타 규모를 제시하고 베트남/러시아의 개별 금액이 그 표에서 분리되지 않는다고 설명한다.

두 번째 경로도 유효하다. 법인–국가 문장을 새 필수 항목으로 만들지 않는다. 법인 연결을 말하지 않았다면 그 연결의 독해 진단은 NA이며, 오류가 없었다는 이유만으로 정확히 읽었다고 판정하지 않는다. 전체 필수 항목 충족은 따로 평가한다.

| 판정 대상 | 근거와 확인할 오류 |
|---|---|
| 법인–국가 연결 | `593:61`의 VINA→베트남, Euro LLC→러시아. 실제 진술·법인 정체성·국가·인용 지지 여부를 각각 기록 |
| 당기 지역표 | `161:37`: **2025**, 중국 **1,316,352,022천원**, 기타 국가 **919,408,932천원** |
| 전기 지역표 | `162:38`: **2024**, 중국 **1,265,157,571천원**, 기타 국가 **778,893,731천원**. 이를 당기로 제시하면 오류 |
| 법인 매출 | `78:2/82:6`: 2025 Vina **538,097백만원**, Euro LLC **339,436백만원**, 에누리 차감 후·수출 포함 |
| 투자 장부금액 | `593:61`의 **68,498,978 / 31,980,151천원**은 매출이 아님 |
| 집계 범위 | 소재지는 소비자 매출 발생 국가와 동일하지 않음. 지역 매출과 법인 매출을 합산하거나 기타 국가를 특정 한 나라에 전부 귀속하면 오류 |
| 추가 진술 | 앞부분 인도 가치평가 문맥·다른 법인·본사 소재지로부터 근거 없는 국가 관계를 만들었는지 확인 |

원문 `original:563–565`, `173–174`, `1729`의 행·열·기간·단위·원문 해시와 패킷 witness를 연결해 두었다. 관계가 원문 전체에서는 참이어도 **실제 답변이 인용한 자료가 지지하지 않으면 출처 충실도·인용 지지 통과로 처리하지 않는다**. 원화 변환·반올림은 기존 표시 정밀도와 허용 범위를 그대로 적용한다.

각 관계·금액에 대해 ‘진술했는가 / 맞는가 / 인용으로 지지되는가’를 구분하고 네 답변을 모두 공개한다. 두 matched 반복 모두 F/U→P이면 반복된 관측 개선, 한 번이면 부분 개선, 양쪽 P이면 유지다. 국가 연결이 좋아져도 기간·단위·집계 기준 오류나 근거 없는 추가 진술이 생기면 전체 답변 개선으로 합치지 않는다.

## 전체 18문항의 회귀 기준

기존 **33개 필수 그룹**, 선택 항목, 허용 대안, 원문 충돌에 대한 U 판정을 유지한다. 정확도·요청 충족도·출처 충실도·인용 지지·경계 처리를 별도로 P/F/U/NA/NOT_RUN 판정한다. 올바른 부분 답변은 정확도 P·누락 F가 가능하다. 출처 ID가 유효한 것은 의미적 지지의 증명이 아니다.

- 문항·회차별 P→F는 확인된 회귀, P→U는 불확실성 회귀로 각각 기록한다. 축·그룹 개수와 회귀 문항 수를 분리한다.
- 조건별 0/2·1/2·2/2 strict 성공과 각 문항의 네 결과를 기록한다. U·NOT_RUN은 성공으로 세지 않는다.
- U04 HD 원인은 양쪽에 이미 있다. 유지 여부를 확인하며 검색 근거가 새로 복구됐다고 표현하지 않는다.
- U03의 열·기간·단위·고객 관계 오독, U15의 영업/순손익·위약금·원문 충돌, U06/U12/U18의 추정 한계를 계속 확인한다.
- U09 영업현금흐름과 U16 당기 현금·미래 리스 근거 누락은 두 조건에 남는다. 필요한 항목을 못 답한 경우와 없는 수치를 만들어낸 경우를 구분한다.
- U14에 과거 v6의 ‘문맥 12개에서 상충 문단 추가’라는 상황을 잘못 적용하지 않는다. 현재 두 패킷은 동일하다.

출력 검산은 사후 평가이며 제품 runtime의 산술 검증이라고 주장하지 않는다. 원래 gold의 문제가 발견되면 원본을 보존하고 양쪽에 대칭적인 유보·재판정 기록을 남긴다. 문항 삭제·prompt 변경·추가 반복으로 점수를 맞추지 않는다. 두 번의 반복은 일반 정확도나 통계적 우월성을 입증하지 않는다.

## 비용과 상한

이번 준비에서 확인한 [공식 API Standard 요금](https://developers.openai.com/api/docs/pricing)은 Terra short-context 1M tokens당 입력 **$2.00**, 캐시 읽기 **$0.20**, 캐시 쓰기 **$2.50**, 출력 **$12.00**이다. [공식 캐시 계산](https://developers.openai.com/api/docs/guides/prompt-caching)에 따라 일반 입력은 전체 입력에서 캐시 읽기·쓰기를 뺀 값이며, 쓰기 요금을 일반 입력과 중복 가산하지 않는다. reasoning은 output tokens에 포함한다. 세금·환율은 제외한다.

직전 top12 36답변의 실측 입력 **369,170 tokens**, 출력 **11,385 tokens**(reasoning 1,610 포함)를 사용했다. 동일 body는 해당 문항의 실측 입력값을 사용하고, 변경된 U08 정책 body만 **최종 요청 UTF-8 byte 비율**로 올림 추정했다. 로컬 토크나이저나 유료 token-count API는 실행하지 않았다.

| 계획 시나리오 | 예상 비용 |
|---|---:|
| 기존 출력 길이, 일반 입력 요율 | **$1.733996** |
| 기존 출력 길이, 입력 전부 캐시 쓰기 요율 | **$2.099185** |
| 출력 길이 2배, 일반~쓰기 입력 | $2.007236~$2.372425 |

예상 입력은 **730,378 tokens**, 출력은 **22,770 tokens**다. 미래 usage·캐시 동작·출력 길이는 달라질 수 있으며 특히 U08 정책 입력 토큰 수는 측정값이 아니다.

## 실행 중단과 무호출 검증

전송 직전에 실제 outgoing body·packet·slot 해시, endpoint, 시도 수, 누적 비용·미확정 예약액·다음 최대 예약액, 남은 시간을 검사한다. 전송 전에 시도를 기록하고 실패도 호출 수에 포함한다. 한 요청의 최대 90초를 남은 시간 안에 수용할 수 없으면 보내지 않는다.

HTTP/transport 오류·timeout·불명확한 결과, incomplete/refusal, model·effort·tier 불일치, usage·schema·출처 ID 오류, 입력 변경, 비용·호출·시간 한도에 도달하면 중단한다. 미확정 요청의 최대 예약액을 유지하고 나머지를 NOT_RUN으로 남긴다. 재시도·fallback·추가 슬롯·자동 재개·기본값 채택은 하지 않는다. 실행 직전 요금이 달라졌다면 임의로 조건을 바꾸지 않고 보고한다.

**검증:** 기존 top12 요청 일치 18/18, 문맥 패킷 일치 36/36, 동일 생성 설정·반복 body·72개 순서·33개 기준·132개 필수 관측을 확인했다. **모의 실행 72건과 거절 검사 35개**가 통과했다. 모의 응답은 과거 usage와 인위적인 schema/출처 ID payload이며 새 답변이나 품질 평가가 아니다.

준비 묶음에는 live HTTP client가 없다. 이후 실제 실행은 전용 adapter가 같은 검사를 **실제 전송 직전** 수행하는지 확인한 뒤 진행해야 한다. 기존 store 구축 실행기나 과거 다른 비교의 실행기를 그대로 실행하지 않는다.
