## 판단과 보존

**12개는 이번 고정 후보에서 HD 복구를 얻는 더 작은 비교 조건이다.** 16개를 선택할 추가 필수 근거 이득은 관측되지 않았다. 다만12개에서도 상충 자료와 크기 증가가 있어 기본값 변경의 근거로는 충분하지 않다. 실제 답변 비교를 한다면 같은 frozen packet의8개와12개를 비교할 수 있지만, 이번 실행 범위에는 포함하지 않았다. 검색 후보 확대나 다른 가중치·reranker 재실행도 하지 않았다.

런타임 기본값·소스·store·`.env`는 그대로다. 사전 보호 목록1,847개 중 현재 상태 문서2개만 이 결과로 갱신하고 나머지1,845개는 SHA256 일치를 확인했다. 여기에는 활성 store, 별도 평가 store, mock store, 이전 실험 기록과 모델 파일이 포함된다. store는 파일 해시만 읽었으며 DB로 열거나 재색인하지 않았다. 활성v5 store와v6 parser manifest 불일치도 그대로다. 문서 authority 검사2개를 통과했다. 커밋·push·기본값 채택은 하지 않았다.
