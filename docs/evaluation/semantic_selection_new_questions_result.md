# 새 문항 12개: 고정 LLM 근거 선택 비교

2026-09-29. **12쌍 모두 완료: 생성36회·질문 임베딩12회, 오류·재시도·NOT_RUN 0.**
[실행 전 설계](semantic_selection_new_questions_preparation.md).

사전에 고정한 완전성·정확성·인용 기준은 **RRF 11/12, LLM 선택 11/12**다.
근거는 양쪽 모두12/12 충분했다. LLM 선택은 가동률의 연도 오독1건을 줄였지만,
다른 답변에서 평가 기준에 포함한 설명1개를 누락했다. 누락 판정에는 질문보다
넓게 정한 rubric의 영향이 있어 아래에 별도 민감도를 공개한다. 이 표본에서는
검색 근거 회복의 추가 이득이나 기본 경로 채택을 뒷받침하는 결과가 나오지 않았다.

## 표본과 판정

기존2023 공시 네 개에서 새로 작성한 조회·계산·설명 각4문항이다. 원문을 본
assistant가 질문과 정답을 작성했지만 **새 검색·답변 전에 봉인**했다. full77과
final12에 대한 동일 회사·요구 항목의 재진술 및 정확 문자열 중복을 검토했다.
새 회사/보고서, 독립 정답, 무작위 표본, 모델 학습 미노출 평가가 아니다.
답변24개와 인용 원문을 대조한 비맹검 assistant 판정이며 외부 평가자 검증은 없다.

## 차이의 원인과 민감도

**N02 LG에너지솔루션 가동률:** 두 경로에 모두 `20240314001110:24:3`이 전달됐다.
표는 제4기69.3%, 제3기73.6%, 제2기72.7%다. RRF 답변은2022년을72.7%로 잘못
대응시켜3.4%p 하락이라고 답했고, 선택 후 답변은73.6%와4.3%p 하락을 정확히
답했다. 필요한 근거가 없었던 사례가 아니라 **근거를 읽는 단계의 오류**다.
추가 선택 호출과 다른 답변 context가 함께 달라지고 단회 생성만 관측했으므로
이를 근거 압축의 확정적인 인과 효과로 해석하지 않는다.

**N12 카카오뱅크 유동성 관리:** 두 답변 모두 조기경보·비상조달계획·분기별
위기상황분석·보고 대상을 맞혔다. 선택 후 답변은 사전 rubric에 포함한
**자금조달 원천과 만기의 분산**을 누락했다. 해당 내용이 있는 `284:17`은
선택·전달·인용됐으므로 선택 과정에서 근거를 잃은 것은 아니다.

다만 질문은 관리수단을 설명하라고 넓게 요청하면서 조기 감시·위기 대응·분석
주기·보고 대상만 직접 열거했다. 따라서 원천·만기 분산까지 필수로 둔 rubric은
질문보다 넓다는 해석이 가능하다. **고정 rubric을 유지한 주 결과는11 대11**,
직접 열거된 항목의 충족을 기준으로 보면 **11 대12**다. 사후에 gold를 고쳐
한 쪽 수치만 제시하지 않는다.

N03의 추가 잔액은 원문 숫자가 괄호에 보존되고 한국어 단위 표시는 허용된
반올림 오차 안에 있어 인정했다. N09의 두 답변은 높은 점도지수와 연료효율
개선을 설명한다. 원문의 어색한 ‘연비 감소’ 표현을 문장 전체의 연료효율 경제성
문맥과 함께 해석해 양쪽 모두 인정했다. 이를 문자 그대로 엄격히 거절하는
민감도에서는 양쪽 모두10/12가 된다. 이 두 판정 경계도 리뷰에 기록했다.

## 충분성 confusion matrix

선택 모델은12개 모두 후보 pool과 선택 근거가 충분하다고 선언했고, 원문 검토도
모두 충분으로 판정했다. 두 충분성 판단 각각 **TP12·FP0·FN0·TN0**다.
실제 부족 사례가0개이므로 부족 근거 탐지력·specificity는 평가할 수 없다.
이 표는 답변 정확성 분류가 아니다. N02 오독과 N12 누락은 충분한 근거를
받은 뒤 답변에서 생긴 문제다. 답할 수 없는 질문의 거절 성능도 이번 범위 밖이다.

## 검증과 보존

유료 실행 전48개 mock 호출·10개 오류/범위 통제가 통과했다. 최초 offline
rehearsal의 큰 입력 실패는 보존하고, 그 뒤 원문 청크 단위의 일반 입력 상한을
추가했다. **실제 실행에서는 후보 제외0·답변 청크 제외0**이어서 전체 검색 후보
pool이 두 비교 경로에 그대로 사용됐다. 후보 수는27–38개였다.

실제12개 검색,12개 선택 요청,24개 답변 packet, 원문·출처·raw output 연결과
790개 보호 파일을 재검증했다. 이 검증은 의미나 산술 정확성의 자동 보증이 아니다.
원문/gold와 생성 결과는 로컬
`benchmarks/results/semantic_selection_new_questions_2026-09-29/`에 분리 저장했다.
`review.json`에 문항별 판정, 민감도, 대응표 및 비용이 있고 완료 seal로 봉인한다.

이번 새 표본은 기존RRF가 처음부터 충분한 근거를 찾는 경우가 많았다. 이전의
실패 중심 표본에서 보였던 근거 회복 이득과 모순되지 않지만, LLM 선택을 모든
질문에 넣을 근거도 제공하지 않는다. 기본 앱은SimpleRagAgent로 유지하며,
추가 실험·규칙·프롬프트 수정·제품 채택은 자동으로 진행하지 않는다.
