## 초기 전체 평가

**2026-09-28, 11개 기업·77문항의 Simple RAG 실행**은 초기 전체 평가 기록입니다.
수치 22개, 요약·혼합 36개, 거절 19개를 직접 구축·검수한 데이터셋입니다.
정답과 평가 체크포인트는 답변 모델 입력에서 분리했습니다.

| 구분 | 기록 | 읽는 방법 |
| --- | --- | --- |
| 실행 | 77/77 완료, 오류 0, NOT_RUN 0 | 완료 수이며 정확도가 아님 |
| 답변 | 30/55 통과 | 정확성·필수 항목 충족·인용 근거 모두 만족 |
| 거절 | 18/19 통과 | 답변 생성과 별도 지표 |
| 최초 기준 충돌 | 3문항 | 주체·부문 범위 문제로 답변 분모에서 제외 |
| 후속 기준 충돌 | 1문항 추가 | 연결/별도 기준 오류; 추가 제외 시 30/54 |

[77문항 보고서](simple_rag_full77_result.md)에는 기업별 결과, 기준 충돌,
판정 민감도, 호출 수·비용·시간, 로컬 증거 위치가 있습니다. 원래 30/55 기록과
추가 제외한 30/54를 함께 보존합니다. 거절을 합산한 단일 정확도로 바꾸지 않습니다.

이 평가는 개발에 노출된 자체 데이터셋에서 저장 답변과 실제 전달·인용 근거를
assistant가 원문 대조한 것입니다. 독립 사람 채점·blind gold·holdout 평가가
아닙니다. 원시 로그와 store는 공개 저장소에 포함되지 않아, 보고서를 읽는 것과
실험을 독립 재현하는 것은 구분해야 합니다.

## 실패를 어떻게 나눠 보았는가

| 실패 경계 | 77문항 실행에서 관측한 내용 |
| --- | --- |
| 필요한 근거가 전달되지 않음 | 답변 실패 25개 중 22개에서 필수 근거가 부족했음 |
| 대상·기간·범위 해석 | 전기 값을 당기로 설명하거나 순액을 개별 손실 부재로 읽음 |
| 제공된 근거를 사용하지 않음 | 검색 문맥에 있던 그룹 AUM·요청 항목을 답변에서 누락 |
| 근거 없는 부가 설명 | 계산 차이를 근거 없이 반올림 탓으로 설명하거나 기간·원인을 덧붙임 |
| 평가 기준의 오류 | 그룹/은행, 연결/별도, 회사/부문 범위가 정답 기준에서 섞인 문항 |

근거 부족과 실패의 동반 관측은 검색을 바꾸면 모두 해결된다는 인과 증거가
아닙니다. 개별 원문·문항은 [실패 분석](simple_rag_full77_result.md)과
[구조 비교 실패 경계](structure_full77_failure_boundaries.md)에 기록했습니다.

## 평가와 앱의 보장은 별개

사후 검토는 답변의 정확성·필수 항목·인용 지지를 확인합니다. 앱의 runtime 검사는
명시적 scope·응답 형식·출처 ID에 한정되며, 의미 지지와 요청 완전성은
`not_checked`, 산술은 `not_executed`입니다. 유효한 출처 ID가 곧 정답을 뜻하지 않습니다.

9월의 보고서는 [당시 공개 코드](https://github.com/woojune511/dart-rag-agent/tree/358f763deb8c03515e84bbb329924c4fd929af32)와
연결됩니다. 10월 비교는 `1d09627d` 및 동결한 로컬 변경·v12 store를 사용했습니다.
각 수치는 해당 실행의 조건에 묶이며, 현재 공개 소스에서 재현한 성능으로 읽지 않습니다.
데모는 9월 22일의 저장 사례로, 전체 77문항 실행 화면이 아닙니다.
