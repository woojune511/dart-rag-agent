# 같은 검색 후보에서 top-8 / top-12 실제 답변 비교

2026-10-20 실행. 기존 12문항에서 조건별 2회씩 실제 답변 48개를 생성했다. 답변 가능한 10문항의 엄격한 완전 정답은 **top-8 4/20(20%) → top-12 14/20(70%)**였다. 반면 답변의 인용 근거 충실성은 **18/20 → 15/20**으로 하락했다. 선택된 소규모 패널에서 답변 개선은 관측했지만, 현재 결과만으로 기본값 변경을 채택하지 않는다.

## 비교 조건과 판정

- 사용자 요청: “그럼 기본 top-8이랑 top-12를 실제 답변 정확도까지 비교해보자.”
- 기존 query-decomposition v2에서 저장한 **A/B 입력만** 재사용했다. A는 원 질문의 Dense 16 + BM25 최대 24 후보를 RRF(k=60)로 합친 top-8, B는 **동일 후보·동일 순위의 top-12**다. 네이티브 `search(k=12)`의 후보 확대(Dense 24/BM25 36)는 이번에 시험하지 않았다.
- 기존 C 질문 분해 실험의 `NO_EVIDENCE_GAIN` 판정은 그대로 보존했다. 이번 실행은 새 요청에 따른 별도 A/B 답변 실험이며 C 게이트를 통과시킨 것으로 처리하지 않는다.
- 모델 `gpt-5.6-terra`, reasoning `low`, 최대 출력 8,192토큰, standard/default tier, 기존 `SimpleRagAgent` 프롬프트·JSON schema를 고정했다. 정답·채점기준은 모델 입력에 넣지 않았다.
- 문항별 A/B 순서를 교차 배치하고 두 번째 반복에서는 순서를 뒤집었다. 조건당 24개, 총 48개 답변을 모두 보존했다. 검색·임베딩·질문 분해·외부 judge 호출은 추가하지 않았다.
- 입력 묶음 한도는 양쪽 모두 65,536바이트다. SK하이닉스 문항은 전체 청크 단위 제외로 A 7개/B 9개가 실제 전달됐다. 따라서 모든 호출이 정확히 8개/12개 문서를 받은 것은 아니다.
- 실행 전 기준을 고정하고, 원본 답변을 해시로 봉인한 뒤 조건명·반복 번호를 가린 자료로 출처 대조를 수행했다. 48개 판정을 봉인한 다음 조건을 풀어 집계했다. **동일 assistant의 검토이며 독립적인 사람 평가나 완전한 블라인드 평가가 아니다.**
- 완전 정답은 요청한 결과의 정확성, 필수 요구 충족, 모든 중요 사실에 대한 인용 근거를 함께 요구한다. 계산 결과는 표시된 소수 자릿수에서 맞아야 한다. 거절 문항 2개는 별도 분모로 평가한다. 출처 ID 유효성은 의미 정확도와 구분한다.

## 어떤 개선을 확인했는가

핵심적인 근거 추가와 정답 전환이 함께 관측된 것은 **4개 질문, 8개 답변**이다. NAVER 영업권 표 `20240318000844:353:229`는 11위, 삼성 배당 현금흐름표 `20240312000736:127:6`는 10위, 셀트리온 조정항목 표 `20240318000913:517:357`는 11위, 현대차 연결 손익 표 `20240313001451:1047:3`는 10위였다. 후보 검색에는 성공했지만 top-8 경계에서 모델에 전달되지 않던 근거가 B에 들어갔고, 두 반복 모두 완전 정답으로 전환됐다.

총 개선 10개 출력 중 나머지 2개는 셀트리온 개발비 비율이다. A는 연결 비율 52.99237996%를 `53.00%`로 표시하거나, 올바른 연결 52.99%와 함께 별도 비율 58.70695334%를 `58.70%`로 표시했다. B의 53.0%/58.7%는 해당 정밀도에서 맞았다. 사전 기준상 최종 비율 오류는 실패지만, 두 조건 모두 같은 필수 피연산자를 이미 갖고 있었다. **이 2건까지 검색 근거 개선 효과로 귀속하지 않는다.** 두 번의 생성만으로 추가 문맥의 효과와 생성 변동을 분리할 수 없다.

## 함께 관측된 위험

top-12에서 근거가 늘어도 해석과 요구 충족이 자동으로 해결되지는 않았다.

- 현대차 B 첫 답변은 87.0/78.1만 대로 11.4%를 정확히 계산했지만, 보고서의 11.5%를 “반올림 기준”이라고 설명했다. 원문에는 그 차이의 원인이 없다. 숫자를 맞혔어도 근거 충실성 실패로 처리했다.
- KB금융 B 두 답변은 추가 설명에서 비이자이익 `4조 88십억원`을 `4조 88억원`으로 잘못 변환했다. 맞는 환산은 `4조 880억원`이다. 순수수료 증가율 자체는 맞았지만, 그룹 AUM 요구 누락과 별도로 이 오류가 남았다.
- SK하이닉스는 A/B 모두 전체 차입금 29,468,632백만원을 질문의 세 행 합계처럼 표현했다. 세 행만 더하면 23,757,090백만원이고, 전체 차입금에는 유동성장기차입금·유동성사채가 추가된다. B 한 답변에는 세 수를 더해 29,468,632가 된다는 명시적인 잘못된 등식도 있었다. 분모가 없어 최종 비율은 양쪽 모두 거절했다.

따라서 답변 가능 출력 중 인용 근거 충실성 실패는 A 2건, B 5건이었다. 순수 산술 정밀도 오류는 이 지표와 별도로 정확성에서 처리했다. 셀트리온 재고자산 A의 0 및 순환입액은 실제 인용 표에 있지만 질문이 요구한 세 개의 총액과 다르므로, 원문에 없는 숫자를 만들었다고 처리하지 않고 정확성·요구 충족 실패로 분리했다.

**판정: `OBSERVED_ANSWER_GAIN_WITH_FAITHFULNESS_REGRESSION / ADOPTION_DEFERRED`.** 현재 기본 top-8은 변경하지 않았다. 새로운 prompt·키워드·policy·fallback을 추가하지 않았으며 추가 유료 실험도 자동 실행하지 않는다.
