사용자는 파서 수정의 검증 결과를 근거로 관련 코드·테스트·문서를 선별 커밋하도록
승인했다. 답변 회귀 실험의 ‘7문항 모두 두 번 통과’ 조건은 충족하지 못했다.
이 결정은 해당 조건이나 점수를 바꾸지 않으며, 파서 수정 채택을 별도로 기록한다.

## 수정 범위

| 문제 | 채택한 변경 |
| --- | --- |
| 일반 문단의 명시적 제목이 누락되어 이전 주체가 다음 표에 남음 | 번호형 독립 제목·굵은 SPAN·문단 앞 대괄호 제목을 원문 위치와 연결하고 제목도 본문에 보존 |
| 대괄호 주체와 번호형 상위/하위 관계가 소실됨 | 관측한 부모 수준으로 돌아올 때만 자식 범위를 닫고, 실제 하위 항목과 중간 주체는 보존 |
| P 자체의 굵은 서식을 읽지 못해 직원 주석이 이전 소제목에 연결됨 | P의 직접 텍스트·서식을 상속한 SPAN·tail을 읽고 이미 찾은 같은 위치의 제목은 덮어쓰지 않음 |
| 작은 표 안의 회계정책 본문이 기간·단위 라벨로 소비됨 | 표 전체가 라벨 문법에 맞을 때만 소비하고, 혼합 캡션은 본문을 보존하며 명시적인 말미 단위만 다음 표에 전달 |
| 콜론 없는 긴 문자열에서 구분자 정규식이 과도하게 역추적함 | 반복 단어 사이 공백을 필수로 하여 동일 분할 탐색을 줄임; 기존 짧은 입력의 span/capture 일치 검사 |

구현은 `src/processing/financial_parser.py`, `src/processing/block_collection.py`,
`src/config/runtime_contract.py`에 한정한다. 금융 관련 라벨 어휘는 DART 문서의
표제·날짜·단위 구조를 복원하는 parser 문법이다. 회사·질문별 답변 선택이나
retrieval/routing 분기를 추가한 것이 아니다.

기존 SPAN의 `B` 부분 문자열 판정은 유지했다. 모든 SPAN 서식 문제를 해결했다거나
모든 문서의 소제목이 정확하다고 주장하지 않는다. 더 넓은 서식/줄바꿈 해석 후보는
이전 제목·원문 보존을 만족하지 못해 채택하지 않았다.

## 채택 근거와 답변 평가의 구분

저장소 재구축에서 전체 청크의 본문·metadata·float32 벡터를 다시 읽어 대조했다.
NAVER 직원 주석의 본문과 올바른 소제목이 저장 metadata·검색·캐시·답변 입력까지 유지된다.
앞서 복구한 회계정책 4개 표의 15개 원문 조각도 유지된다. 이는 관측한 원문과 전달 경로의 검증이다.

관련 테스트는 동급/하위 제목, 캡션, 문단 서식·tail, 원문 문자 위치, 표 본문·단위 보존,
구분자 비용, 이전 manifest 거절, 실제 임시 Chroma 재개방과 캐시된 agent packet을 검사한다.
모델·임베딩을 모의한 통합 검사는 실제 답변 품질의 근거로 사용하지 않는다.

[고정 7문항 회귀 기록](../evaluation/paragraph_heading_v5_answer_regression.md)은 그대로 유지한다.
핵심 답·필수 요구14/14, 엄격 기준11/14, 두 번 모두 통과4/7이다.
탄소 부재 표현을 발췌로 좁혀 읽으면12/14지만 전부 통과 조건은 여전히 미달이다.
이는 익숙한 긍정7문항의 반복 결과이며 일반 정답률·독립 평가·파서 변경만의 인과 효과가 아니다.
당시 완료 커밋을 하지 않았다는 기록도 해당 시점의 사실로 보존한다.

## 남은 문제와 종료 경계

1. **부가 주장과 인용 연결**: KB 국내 등급과 NAVER 주요리더 정의는 입력에 있었지만
   첫 반복 답변이 해당 출처를 인용하지 않았다. 유효한 출처 ID만 검사하는 현재 계약의 한계다.
2. **부재 진술의 범위**: 발췌에 금액이 보이지 않는 것과 보고서 전체에 금액이 없는 것을
   구분해야 한다. 이번 탄소 답변의 범위 판정과 민감도는 회귀 기록에 남긴다.

후속 항목으로 기록하되 이 사례에 맞춘 prompt/rule 추가나 같은 문항의 재시험을 자동 실행하지 않는다.
[SimpleRagAgent 계약](agent_runtime_contract.md)의 검색1회·답변1회·출처 ID 검사와
산술 미실행·의미 지지 미검증 표시는 유지한다. Compiler·추가 agent·재검색은 도입하지 않는다.
이번 범위는 검증된 파서 코드·테스트·문서의 로컬 커밋으로 종료한다.
