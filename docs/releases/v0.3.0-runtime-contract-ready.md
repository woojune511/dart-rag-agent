  rows, with candidate identity and catalog fingerprints preserved.

- Python 3.13 is the publication interpreter. Python 3.14 support is not claimed.
- T3 uses the reviewed consolidated Motional tuple (`26%`, `700,691백만원`, and
  the four same-basis summary measures) as its canonical curated answer. The
  evaluator consumes that canonical reference; no tolerance or faithfulness

  comparison scales the selected source value's rounding interval only.
- Provider-free counterfactual replays prove validator/executor behavior, not
  that a new compiler call will choose the same program.
- MAS and Streamlit remain experimental surfaces rather than the core product.
