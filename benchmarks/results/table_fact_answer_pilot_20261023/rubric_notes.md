# 답변 비교 사전 판정 메모

이 기준은 새 답변을 생성하거나 열람하기 전에 작성했다. 저장된 A12·64KiB·160KiB 문맥과 이전 원문 감사 결과는 이미 본 개발용 평가이며, blind 또는 held-out 평가가 아니다. 모델·프롬프트를 바꾸는 문서가 아니며 실행 runner는 동일 모델·프롬프트를 별도로 고정해야 한다. 여기서는 외부 API, 검색, 생성 호출을 하지 않았다.

12문항 × 3조건 × 2회 = 72개 답변을 계획한다. 주집계는 일반 8문항과 거절 2문항을 구분해 보고한다. MIX_T3_063·KAK_T3_055의 2개 HOLD는 주집계에서 제외하고 조건부 근거 사용과 미지원 주장을 진단한다. HOLD를 해제하거나 기준값을 교체하지 않는다. 2회 결과는 반복 일관성과 회귀를 기술하는 작은 pilot이며 유의성·일반화 근거가 아니다.

숫자가 원문과 맞는지, 요청 항목을 답했는지, 실제 전달·인용된 근거가 주장을 지지하는지는 각각 판정한다. 원문 밖 값을 우연히 맞히더라도 출처 충실도는 성공이 아니다. 반대로 올바른 유보는 충실도에 도움이 되지만 빠진 필수 항목을 충족시키지는 않는다. 출처 ID 유효성과 실제 셀·관계의 지지는 별도 검사한다.

각 답변에는 고정된 required unit별 `FULFILLED / PARTIAL / OMITTED / INCORRECT / UNRESOLVED_CRITERION`을 남긴다. 완전성 집계는 전부 충족이면 PASS, 일부만 충족이면 PARTIAL, 하나도 충족하지 않으면 FAIL로 새 3조건 모두 동일 적용한다. 과거 평가의 집계 라벨은 다시 사용하지 않고 원문 요구 기준을 유지한다. 이렇게 하면 과거에 계산 미완료 전체를 FAIL로 기록한 사례와 새 단위별 누락 수가 섞이지 않는다. 정확도는 최종 계산·요약 등 요청 결과까지 완수해야 PASS다.

새 결과를 보고 기준을 수정하지 않는다. 주체·기간·범위 해석이 원문으로 결정되지 않으면 `AMBIGUOUS`와 충돌하는 인용을 남기며 강제로 성공/실패를 확정하지 않는다. A12 대비 각 조건과160 대비64의 새 오답, 새 미지원 관계, 필수 항목 누락을 따로 비교한다. 반복 결과가 달라도 유리한 회차만 선택하지 않는다.

근거 경로와 SHA-256, arm별 실제 전달 여부, 물리적 표 위치와 전달된 원문 caption은 `rubric.json`에 기록했다. 수치·조건의 권위는 기존 `table_fact_budget77_offline_20261023/evaluation_contract.json`, `evaluation_supplement.json`, 원문 감사 및 `table_fact_units_offline_20261023/source_checks.json`·`projections.json`이다. 이 문서의 참조값은 평가용이며 생성 입력이나 검색·행 선택에 제공하지 않는다. 기존 파일·코드·.env·store는 변경하지 않았다.
