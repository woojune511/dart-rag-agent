# 구조 라벨 중복 TF 분리 실험

**이번 조건은 미채택한다. 삼성 배당과 셀트리온 연결 재고손실 근거를 최종 12개 안으로 복구하지 못했고, 다른 문항의 금액 근거도 새로 유실됐다.** 중복 라벨이 셀트리온 연결·별도 표의 점수 차이를 만들었다는 진단은 확인됐다. 그 차이를 없애는 것만으로 필요한 표가 선택되지는 않았다.

외부 모델 API **0회·$0**, 생성 답변 **0개**, 검색 비교 **77문항 각 1회**다. 점수 실행은 **72.22초**, 자동 재실행은 없었다. 실험 코드·자료는 이 ignored 결과 폴더에만 추가했다. 운영 소스, 기존 미커밋 파일, `.env`, v12 store, 앱 프로세스는 변경하지 않았다.

## 고정한 조건과 유일한 변경

비교 기준은 직전 실험의 **N12: Nori + 기존 IDF**다. 예전 문자 bigram A12나 positive-IDF NL12를 기준선으로 섞지 않았다.

| 항목 | 두 조건에서 고정 |
|---|---|
| 분석기 | Lucene Nori 9.12.3, MIXED, 기존 POS 제외·ASCII/숫자 처리 |
| 입력 | 같은 16,051개 청크와 77개 질문의 원문 전체; 입력 삭제·재작성 없음 |
| BM25 | 기존 IDF, k1=1.5, b=.75, 기존 문서 길이·평균 길이, 질문 토큰 중복도 |
| 검색 범위 | 기존 명시적 보고서 receipt 필터 |
| Dense | 저장된 Dense16의 후보·점수·순서 |
| 결합 | BM25 최대24 + 동등 가중 RRF60 + 기존 동점 정렬 |
| 문맥 | 최종12, 원문 전체 청크, 65,536 UTF-8 바이트, 생략 후 보충 없음 |
| 기타 | 공통 키워드 접두어, 본문, 표제·기간·단위, 출처 메타데이터 모두 유지 |

**F12에서 문서의 토큰 빈도만 아래처럼 바꿨다.**

`TF = 다른 접두어의 TF + max(본문 TF, table_row_labels 값 부분 TF, table_value_labels 값 부분 TF)`

같은 토큰이 파생 라벨과 본문에 반복될 때 세 빈도를 더하지 않는다. 본문 내 반복과 라벨에만 있는 토큰은 보존한다. 필드 이름 자체와 나머지 접두어는 그대로 집계한다. 예를 들어 본문4·행라벨2·값라벨3회는 9회 대신4회로 집계한다. 다른 접두어에1회 더 있으면 최종5회다.

Nori는 필드별로 잘라 분석하지 않고 **원래 전체 문자열**을 분석했다. 토큰의 UTF-16 위치로 필드를 배정했으며, 전체 **16,128개 토큰 목록이 저장본과 정확히 일치**했다. 두 구조 필드가 있는11,971개 청크 중11,961개에서 TF가 바뀌었다. 전체 문서 TF 합은5,583,716→4,718,474로 감소했지만, 문서별 어휘 집합은 모두 같았다.

이것은 **토큰 빈도 합산만 분리한 대조 실험**이다. 길이까지 줄여 정상 색인을 다시 만드는 실험이 아니므로 라벨이 많은 문서는 원래 길이 정규화 부담을 계속 갖는다. 또한 단어별 최대 빈도는 복제된 검색 표현의 근사 처리이지, 실제 같은 행·셀이라는 연결을 검증한 중복 제거가 아니다. 이 한계 때문에 모든 필드 분리 방식이 실패했다고 일반화할 수 없다.

## 결론의 범위

**확인된 사실:** 구조 라벨 복제가 셀트리온 대응 표의 점수 차이를 만들었고 이번 처리로 그 차이가 없어졌다. 하지만 두 타깃의 최종12 복구는 실패했다. 동일한 처리가 다른 값 표의 후보·최종 순위를 떨어뜨렸으며 원문 값 자체는 수정되지 않았다.

**해석:** 복제된 라벨은 잘못된 빈도 우위를 만들기도 하고, 긴 표의 필요한 항목이 검색 점수를 얻도록 돕기도 한다. 중복 빈도만 일괄 줄이는 것으로 항목·범위·기간의 관련성을 대체할 수 없다. 특히 이번에는 원래 문서 길이를 고정했으므로 라벨이 많은 표의 TF 감소와 길이 부담을 동시에 보정한 결과가 아니다.

**결정:** 사전 성공 기준인 두 타깃 복구와 근거 회귀 방지를 통과하지 못했다. F12를 운영 구현에 반영하지 않고 이 조건의 실험을 종료한다. 이 결과로 Nori 전체, 행 단위 색인 전체, 또는 길이 정규화를 포함한 모든 필드 분리 설계를 기각하지는 않는다. 추가 조건이나 답변 호출은 실행하지 않았다.
