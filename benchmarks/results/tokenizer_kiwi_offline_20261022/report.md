# 한국어 BM25 토큰화 대조 실험

**결론: 이번 Kiwi 전체 형태소 치환 조건은 채택하지 않는다.** 기존 문자 bigram 대비 고정 패널의 필수 근거 보존이24/26→20/26으로 감소했고, 새로 복구된 패널 항목은 없었다. 현재 앱의 코드·설정·store를 유지하고 추가 변형은 실행하지 않았다.

실행은 기존77문항의 저장된 Dense 후보와 원문 export만 사용했다. 모델 API0회, 비용$0, 답변 생성0회, 본 비교 실행112.03초다. 패키지 설치와 사전 검사·결과 검토 시간은 이 실행 시간에 포함되지 않는다. 외부 네트워크 사용은 설치할 패키지의 공개 메타데이터 조회와 다운로드에 한정했으며 문서·질문을 외부로 전송하지 않았다.

| 고정 근거 패널 지표 | 기존 bigram A12 | Kiwi K12 |
|---|---:|---:|
| 후보 합집합에 필수 근거 포함 |24/26|23/26|

| 모든 필수 근거가 문맥에 있는 문항 |9/10|7/10|

이 표는 **답변 정답률이 아니다.** 사전 고정된10개 답변 가능 문항·26항목의 원문 witness와 이전에 확인한 대체 출처를 검사했다. 나머지67문항에는 동일한 완전 정답 근거 주석이 없다. 별도2개 거절 통제 문항은 답변을 생성하지 않아 거절 성공/실패를 채점하지 않았다. 현대차 미국 판매 질문의 주체에 관한 기존 benchmark HOLD는 유지하고, 고정 진단 패널의 현대차 해석만 비교했다.

**비교 조건.** A12는 기존 한국어2글자 bigram, K12는 `kiwipiepy==0.24.1`, `kiwipiepy_model==0.24.0`, `cong` 모델이다. 기존과 동일한 정규식으로 연속 한글/영숫자 구간을 나누고, 한글 구간만 Kiwi의 모든 `token.form`으로 치환했다. 조사·어미를 포함한 모든 품사를 유지했다. 숫자·영문은 기존 소문자/분할 처리를 유지했다. 질문과 문서가 같은 분석·캐시를 사용하며 불용어, 사용자 사전, 동의어, 오타 교정, 쿼리 확장, 표 스키마 검색은 추가하지 않았다.

연속 한글 구간별 분석이므로 문장 전체의 띄어쓰기·주변 문맥을 활용하는 형태소 분석과는 다르다. 이는 사전 고정한 이번 최소 치환 조건의 한계이며, 결과를 모든 Kiwi 활용법이나 형태소 기반 한국어 검색의 평가로 일반화하지 않는다.

원문16,051개, 질문과 명시적 보고서 범위, 저장된 Dense16, BM25최대24, 동일한 equal RRF60 및 동점 순서, 최종12개·65,536 UTF-8 bytes를 고정했다. 원문 전체와 원래 메타데이터를 그대로 반환하고, 초과 청크는 통째로 생략한다. 새 청크 채움·압축·캡션 첨부는 없다. `rank_bm25==0.2.2`의 BM25Okapi 기본값은 같고, 각 어휘에 맞게 전 코퍼스의 IDF와 길이 통계를 다시 계산했다. **앱 기본 final8은 변경하지 않았다.**

고정26항목에서 새 손실은 삼성 배당1개와 셀트리온 재고손실3개다. 그 밖의 사례는77문항 출처 검토에서 추가로 확인한 것으로,26항목 지표에 사후 편입하지 않았다. 주요 손실은 문맥 바이트 초과 때문이 아니다. 과거 인용이 빠진 모든 문항이 오류는 아니며, 현대차 수익성·네이버CapEx·셀트리온 합병 목적 등의 주요 근거는 다른 출처에 남았다.

**77문항 전체의 변경 범위.** 출처 집합72/77, 순서76/77이 달라졌다.29문항은 기존 후보 합집합에 없던 출처가 새 문맥에 들어왔지만 이를 필수 근거 개선으로 자동 판정하지 않았다. 과거 인용 일부가 사라진16문항은 답변 가능10·HOLD3·거절3으로 구분해 검토했다. 과거PASS13문항에 인용 손실이 있지만 그중3개는 거절 문항이며, 이는13건의 정확도 회귀를 의미하지 않는다.

평균 문맥 크기는37,273.3→40,136.3 bytes였다. 바이트 생략은 두 조건 모두6문항이며 생략 출처는17→18개다. 문맥이 커진 것만으로 근거 충족도가 높아지지 않았다. [전체 출처 감사](all77_source_audit.json), [16문항 검토와 실제 원문 witness](source_review.json)에 기계적 차이와 의미 검토의 범위를 분리했다.

**확인된 작동 방식과 추정.**

- `판매대수의`는 `판매/대수/의`, `금융상품판매대리`는 `금융/상품/판매/대리`로 분석됐다. 우연한 `매대` 일치는 사라졌지만 이것만으로 전체 근거 보존이 개선되지 않았다.
- 질문의 `현금흐름표에서`는 `현금흐름표/에서`, 값 표의 `현금흐름`은 `현금/흐름`으로 분석됐다. 값 표에는 질문의 `현금흐름표` 토큰이 없다. 기존에 점수를 받던 유효한 부분 일치도 함께 사라졌음을 확인했다. 이 현상만이129위 하락의 유일한 원인이라고 주장하지 않는다.
- 조사·어미를 제거하지 않았으므로 `의`, `에`, `ᆫ` 등이 남는다. 현재 BM25Okapi는 음수 IDF를 `epsilon × average_idf`로 바꾼다. `ᆫ`은16,051개 중14,606개 문서에 있지만 이번 어휘에서 실제 IDF가약2.023으로 양수였다. 삼성 배당 값 표에서 이 토큰의 점수 기여8.47은 `배당금`4.16보다 컸다. 현재 라이브러리의 고정 동작이며 새로 추가된 구현 버그로 분류하지 않는다.
- 불필요한 부분 일치를 없애는 이익보다 복합어 대응 손실·기능어 점수·문서 길이/IDF 변화가 더 크게 작용했을 가능성이 있다. 각 요인의 독립 기여는 별도 ablation을 하지 않아 확정하지 않았다. RRF·문맥 선택 코드는 변경하지 않았지만 입력 순위 변화로 최종 선택도 달라졌다.

점수 항별 분해 (`score_explanations.json`, local artifact not included), 고정 결과의 토큰·IDF 진단 (`mechanism_diagnostics.json`, local artifact not included), [청크별 단계 순위](target_diagnostics.json)를 보존했다. 원문 export에서 토큰 빈도를 재집계하는 진단은 새 검색 조건이나 재실험이 아니다.

**실행 유효성과 한계.** A12의 저장된77개 문맥을 모두 정확히 재현했고 원문 BM25 점수 최대 차이는0이었다. 합성 계약 검사7개가 통과했다. 한글 구간76,744개를 공통 캐시로 분석했고, 실제 검색 비교는 고정한 한 조건으로1회 완료했다. 프로세스 heartbeat·30분 hard timeout·socket/DNS 차단을 적용했다. 새 답변·모델 판정·독립 보고서는 실행하지 않았고, 근거 검토는 같은 assistant가 비익명으로 수행했다. 기존77문항은 개발에 노출된 자료다.

사전 검사에서는 설치된 패키지에 구형 `knlm` 파일이 없어 분석기 초기화가 실패했다. 검색 점수를 계산하기 전, 패키지에 포함된 `cong`로 변경하고 조건과 runner 해시를 다시 고정했다. 최초 조건과 수정 사유는사전 검사 기록 (`preflight_receipt.json`, local artifact not included), `protocol_preflight_knlm.json`, `seal_preflight_knlm.json`에 남겼다. 결과에 맞춘 모델 변경이나 실패한 본 비교의 자동 재실행은 없었다. 주 환경에pip가 없어 기존uv로 실험 폴더의`_deps`에만 패키지를 설치했으며 주 `.venv`는 변경하지 않았다.

**보존과 종료.** 보호한1,901개 고유 파일의 해시가 동일하다(경로 표기 중복을 포함한 검사 항목1,903개). `.env`, 활성v12 store의 SQLite를 포함한 파일, 기존 소스·미커밋 변경·과거 실험 자료가 보존됐다. 앱 재시작·commit·push 없이 이번 ignored 실험 폴더에만 산출물을 저장했다. 이번 전체 형태소 치환은 미채택으로 종료하며 품사/불용어/사전 규칙을 결과에 맞춰 자동 조정하지 않는다.
