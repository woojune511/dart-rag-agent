# 현재 앱의 top8 표 근거 전달 비교 — 호출 없는 입력 준비

2026-10-24 · 상태: 입력 준비 및 오프라인 검증 완료, 답변 생성 미실행

현재 설정의 **gpt-5.6-terra / low / 최종 8개**에서 비교할 입력을 준비했다. 기존 77문항과 이전에 새로 확보했던 18문항, 총 95문항에 대해 A(기존 전달 64KiB)와 C(동일한 원문 + 기존 표 근거 보강, 상한 160KiB)를 만들었다. 앱의 구현과 설정은 바꾸지 않았다.

이 작업에서 확인한 것은 **입력과 근거의 전달 상태**다. 새 답변 정확도나 기본 경로 적용 효과를 측정한 것은 아니다. 18문항도 이미 평가에 사용했으므로, 후속 실행은 새로운 독립 평가가 아니라 현재 앱 조건으로의 전이·회귀 확인이다.

## 1. 고정한 조건과 재구성 방법

저장된 Dense 16개와 BM25 최대 24개를 그대로 읽고 현재 RRF 구현(k=60)으로 재결합했다. 95문항 모두 저장된 상위 12개의 순서·점수를 정확히 재현했으며, 그 앞 8개를 사용했다. 새 검색, 임베딩, query reformulation, Nori 실험, reranking, store 조회는 하지 않았다.

실제 `SimpleRagAgent`의 문맥 조립 코드를 사용하되 검색 경계는 저장된 후보로, 생성 경계는 입력 기록기로 교체했다. A의 원문·출처 ID·순서·기존 context를 C에 그대로 두고 검증된 표 셀/행/열 표현만 추가했다. C는 기존 실험의 projector 결과와 assembler를 재사용한다. 보고서 원문 14개의 해시를 대조했으며, 값·축·문맥 연결을 다시 조립할 때 새 값을 추정하지 않았다.

**과거 77문항의 입력 스키마 차이도 발견했다.** 저장된 과거 입력의 `context`에는 현재 앱이 전달하는 `unit_hint`, `period_focus`, `period_labels`가 없었다. 과거 12개 입력의 정확한 재생은 당시 필드 구성으로 별도 확인했다. 새 A8/C8에는 현재 앱의 동일한 필드를 양쪽에 넣었다. 따라서 과거 77문항 답변과 새 입력의 차이를 top-k 변경이나 표 보강 하나의 효과로 취급하면 안 된다. 18문항은 과거 입력도 현재 필드 구성을 사용해 이 차이가 없다. 이들 힌트는 명시적 원문 기간·단위·범위 검증을 대신하지 않는다.

표 값 단위는 출처에 연결된 값·행·열 묶음이다. 표 값 단위의 개수는 필수 사실 수나 정답률이 아니다. 위 숫자는 문항별 노출을 합한 것이며, 전체 보고서의 고유 셀 수가 아니다.

SKH_T1_060과 MIX_T3_063은 원래 문맥 조립의 문서 단위 64KiB 제한으로 각각 7개와 6개만 전달된다. C는 A에서 빠진 출처를 보충하지 않는다. C의 160KiB는 A에 실제로 들어간 출처에 표 정보를 붙이는 데만 사용한다.

전체 95문항에서 13,480개 값 단위의 값·좌표·행 축·열 축·문맥 frame·출처 소유자가 저장된 검증 결과와 일치했다. 출처 소유자, 값, 좌표, 행 축, frame을 고의로 바꾼 메모리상의 복사본 5종은 모두 검사에서 거절됐다. 이것은 **물리적 연결 검사**이며 올바른 기업·기간·연결/별도 해석을 자동으로 증명하지 않는다.

전체 95문항의 출처·표 연결은 위와 같이 검사했다. 별도 의미 검토는 18문항 전체와 기존 주요 사례에 한정했다. 나머지 77문항 전체를 다시 의미 판정했다거나, 모든 필수 항목의 회귀가 없다고 주장하지 않는다.

기존 검토에서 명시적인 셀 연결을 남긴 36개 witness 중 26개는 유지되고 10개는 8개 밖으로 빠졌다. 이는 일부 사례의 witness 목록이며 77문항 전체 필수 근거의 recall 분모가 아니다. 빠진 witness가 있더라도 같은 사실을 지지하는 다른 출처가 남는지 따로 확인해야 한다.

18문항 전체를 실제 입력·원문 XML과 대조한 별도 검토에서는 **top12에서 top8로 줄어 새롭게 확정된 고유 필수 사실 손실은 없었다.** H13은 10위 전기 연결 부문표가 빠지지만 필요한 수치는 4위 매출 표에 남는다. 다만 전기 연결 범위를 직접 뒷받침하던 중복 근거는 약해진다. 보존된 1,106개 표 값 단위의 9,237개 값·축 참조와 349개 원문 문맥 span을 XML과 대조한 결과 불일치는 0건이다.

엄격한 원문 연결 점검에서는 A8/C8 모두 10문항을 충분히 뒷받침하고, 8문항은 기간·범위·관계의 명시적 연결에 한계를 남긴다고 기록했다. 이는 **답변 점수나 새 판정 기준이 아니다.** H01의 연결 생산 범위, H07/H08의 회계기수와 연도 대응, H10의 정확한 기말 기준일, H12의 FabriX–클라우드 관계, H13/H14/H16의 연도 연결은 기존 12개에도 남아 있던 한계다. H16은 C에서 원문 `원/개`가 보강되지만 연도 연결까지 자동 해결되지는 않는다. 실제 답변 비교에서는 기존 동결된 rubric을 유지하고 이런 엄격한 연결 진단은 별도로 보고한다.

H14에서는 코스비전 표의 기존 `table_context`가 앞 표의 아모레퍼시픽 각주를 가리키는 문제도 확인했다. 본문의 실제 뒤 각주는 코스비전을 가리킨다. A와 C가 공유하는 기존 문제이며 이번 실험에서 수정하지 않았다. 표 보강의 물리적 연결이 정확하다고 해서 기존 metadata의 의미 오류까지 없어지는 것은 아니다. 문항별 근거와 한계는 `review18.json`과 `review18.md`에 남겼다.

## 4. 18문항 후속 답변 비교의 의미

18문항의 A8 크기는 13,536~28,931바이트, C8은 23,144~63,978바이트다. 평균은 각각 21,509바이트와 34,948바이트로 C가 약 1.62배다. **모든 C8 입력이 64KiB 안에 들어간다.** 그러므로 계획한 비교는 이 18문항에서 표 근거를 추가 전달하는 효과는 볼 수 있지만, 160KiB 상한의 필요성은 검증할 수 없다. 77문항 중 64KiB를 넘는 9문항의 큰 문맥 효과를 이 결과로 대신 판단해서도 안 된다.

H11은 A8와 C8의 입력 해시가 완전히 같다. 답변 차이가 생겨도 그 문항에서는 표 보강의 효과로 해석하지 않고 생성 변동으로 기록한다.

상한 산식은 `(2,476,978 × $2.50 + 589,824 × $12.00) / 1,000,000 = $13.270333`을 센트 단위 올림한 것이다. 입력은 요청 전체 UTF-8 바이트 수에 4,096을 더해 예약하고, 출력은 72회 모두 최대 8,192토큰을 사용한다고 잡았다. 캐시 할인은 추가 호출의 근거로 쓰지 않는다. 이는 provider tokenizer로 측정한 토큰 수가 아닌 넉넉한 사전 예약이며, 실제 usage가 예약을 벗어나거나 비용 기록이 불명확하면 중단한다.

예상 비용은 과거 같은 18문항의 Sol usage를 새/구 요청 바이트 비율로 환산한 근사치다. 같은 캐시 비율이면 약 $1.10, 캐시 읽기 할인을 전혀 기대하지 않고 과거와 같은 출력 길이를 가정하면 $1.90, 출력이 3배인 민감도 조건은 $2.24다. Terra의 실제 출력 길이와 캐시는 이번에 측정하지 않았으므로, $1.50~$2.50은 실행 계획용 범위이며 신뢰구간이나 보장값이 아니다. 계정의 모델 가용성을 확인하는 probe도 하지 않았다.

36개 요청 본문과 72개 실행 순서, 기존 질문·정답 근거·판정 기준을 저장했다. 실제 생성 실행은 하지 않았다.

## 6. 판정 기준과 적용 범위

기존 18문항의 정답·필수 항목·거절 기준을 유지한다. 답변 가능 문항은 조건별 30개 결과의 정확도, 필수 항목 충족, 실제 인용 근거에 대한 충실도를 각각 평가하며 세 항목 모두 PASS인 결과를 주지표로 삼는다. 거절 6개 결과는 따로 평가한다. 올바른 source ID만 제시하는 것으로 출처 충실도를 통과시키지 않고, 추가 설명·기간·단위·계산도 실제 전달된 근거와 대조한다.

모든 답변을 저장한 뒤 조건·반복을 가린 새 문맥의 검토를 수행할 계획이다. 표 표현 자체로 조건이 드러날 수 있으며, 독립 사람 평가나 다른 모델 계열 검증이라고 주장하지 않는다. 두 반복 모두 주지표가 양수이고, 3개 보고서 중 최소 2개가 비음수이며, 새로 확인된 중요한 정확도·출처·거절 회귀가 없어야 탐색적인 전이 근거로 본다는 기존 실용 판정 기준도 유지한다. 반복 결과 72개를 독립 표본 72개로 계산하지 않는다.

이 비교를 통과해도 **160KiB를 모든 질문의 기본 경로로 적용하는 결론은 별도**다. top8에서 빠진 근거, 기존 기간·범위 힌트의 한계, 큰 표의 예산 문제를 함께 해결했다는 의미가 아니다. 실패 사례를 본 뒤 질문·프롬프트·필수 기준을 바꾸지 않는다.
