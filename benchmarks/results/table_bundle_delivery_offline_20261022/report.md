## 고정한 조건과 유일한 변경

기준선은 저장된 `full77_sol_top12_20261020`의 원래 A12다. Nori/F12 조건으로 기준선을 바꾸지 않았다. Dense 16개, BM25 최대 24개, 동등 가중 RRF60의 저장 후보·점수·순서, 최종 선정 12개, 실제 전달 문서, 질문과 보고서 범위, 65,536 UTF-8 바이트 예산을 고정했다. 모델·프롬프트를 실행하거나 변경하지 않았다.

T12는 이미 실제 문맥에 들어간 청크의 저장 `table_object`에서 원문과 위치 대응이 확인된 완전한 표를 별도 필드로 추가했다. 기존 본문을 줄이거나 압축·요약하지 않았다. 같은 물리 표는 원문 SHA256와 XPath로 묶고, 기존 순서의 첫 소유자만 사용했다. 첫 소유자가 검증·예산에서 실패해도 다른 청크로 보충하지 않았다.

원문 XML은 기존 저장 셀을 검증하는 증거로만 사용했다. 저장 객체에 없는 셀을 새로 채우지 않았으며, 원문의 비어 있지 않은 모든 셀에 위치가 확인되는 저장 근거가 있어야 했다. THEAD/TH로 표시된 헤더만 선언 헤더로 취급하고, 추정 헤더 행은 문자 그대로 보존했다. 다음 표의 표제가 섞일 수 있는 `following_block`은 새 묶음에서 제외했다.

새 묶음은 값·행·열의 물리 대응과 원문 연결을 제공한다. `unit_hint`, `period_text`, 파일의 회사명·연도, 정규화 값으로 의미를 확정하지 않는다. 기간·주체·단위는 확인 가능한 원문 행·열·위치 문맥으로 전달하며, 자동 의미 검증을 수행했다고 주장하지 않는다. projector에는 질문·정답·문항 ID·목표 값·점수·실패 판정이 들어가지 않는다.

프로토콜과 77문항 판정 기준, projector 및 테스트는 평가 출력 전에 freeze.json (`freeze.json`, local artifact not included)으로 고정했다. 결과를 보고 정책을 조정하거나 두 번째 조건을 실행하지 않았다.

## 해석과 다음 우선순위

확인된 것은 **저장된 표의 축 문맥을 전달하지 않는 문제는 일부 실재한다**는 점이다. SK이노베이션에서 숫자를 새로 검색하지 않고도 누락된 화폐단위가 보충됐다. 그러나 후보·최종 선정 단계에서 필요한 값 자체를 확보하지 못한 포스코·SK하이닉스 문제는 전달 표현만으로 해결되지 않았다.

Motional은 청크 본문만 보거나 목표 UID의 존재만 검사해서는 실패 층을 잘못 분류할 수 있음을 보여준다. 같은 최종 후보가 소유한 전체 저장 표에는 필요한 행이 있다. 동시에 전체 표를 일괄 검증하는 방식은 무관한 한 행의 모호함 때문에 나머지를 모두 막는다.

**다음 설계 가설은 표 전체 대신 출처가 연결된 사실 단위를 독립 검증·예산 배정하는 것이다.** 값과 필요한 행/열, 기간·주체·단위 근거만 한 단위로 묶고, 모호한 연결은 그 단위에서 거절하는 방식이다. 질문별 정답 라벨을 주입하거나 특정 회사 규칙을 추가하는 제안이 아니다. 이번에는 이 대안을 구현·비교하지 않았으므로 효과가 입증됐다고 보지 않는다. 후보에 실제 값이 없는 경우는 이 전달 방식의 효과와 계속 분리해야 한다.

## 방법론상 제한과 실행 기록

이 데이터는 여러 개선에 노출된 개발용 77문항이다. 실제 사용자 분포에 대한 일반화 성능, 유의성, 새 정답률·거절률·출처 충실도 점수를 산출하지 않았다. 11개 통계·방법론 오류 유형은 methodology_validation.json (`methodology_validation.json`, local artifact not included)에서 점검했으며, 특히 선택 편향·반복 실험·사후 해석의 한계를 명시했다.

본 실행 전 11개 원문 객체의 호환성 probe가 있었다. probe 결과로 projector를 바꾸지 않았으며 별도 기록을 남겼다. 사전 입력 확인에서는 과거 export와 BM25 저장 본문의 끝 공백 한 글자 차이 3건을 발견했다. 746개 문서의 표 객체 동일성을 확인하고, 기존 BM25의 `strip()` 표시 방식을 사전 검사에만 반영했다. 기존 A12와 판정 규칙은 그대로이며 scored run은 1회다. probe (`projector_source_probe.json`, local artifact not included), 공백 차이 확인 (`preflight_export_differences.json`, local artifact not included), 사전 검사 보정 (`preflight_harness_correction.json`, local artifact not included).

독립 검토 중 한 번의 모델 용량 오류가 있었고 같은 검토자가 한 번 재개했다. 실험 재실행이나 외부 API 호출은 없었다. 원문 대조는 작성자 검토이고, 독립 검토는 packet 불변조건 및 checker 코드 범위임을 구분했다.

재현 자료는 [프로토콜](protocol.json), [평가 계약](evaluation_contract.json), 실행 결과 (`results.json`, local artifact not included), 묶음과 셀 대응 (`bundles.json`, local artifact not included), 문맥 (`packets/`, local artifact not included), [최종 판정](final_adjudication.json), 보존 검사 (`preservation.json`, local artifact not included)에 있다. 실제 답변 개선을 확인하려면 별도 승인된 생성 비교가 필요하며, 이번 작업에서는 호출하지 않았다.
